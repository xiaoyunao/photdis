# 这轮科学结论与决定

本轮说明了两件不同的事。此前的部分天空空白确实来自入口条件，恢复成像覆盖有明确路径；老星族的距离偏移则与光度关系和演化相位有关，不能靠一次通用平移解决。三个工作包均已实际计算，新增图和数据与生产目录分开保存。

## 一、覆盖恢复了，但模板超额还不能当作精确距离

**假设。** 原来的严格grz、E(B−V)<0.03入口删掉了Pal 5附近可用成像；放宽消光、把z留作审计，并使用共同g/r深度，有可能找回序列和沿迹超额。

**真实数据。** 固定尾段、两侧控制、参考距离和模板之后，回到40个raw sweeps重提取。Pal 5 trailing小域（包括所有on/off和辅助控制）的独立面积，从原strict的0.0684deg²增加到E<0.10的51.4692deg²；固定gr入口为51.5608deg²，共同形式深度条件后为46.2948deg²。主尾段三个角段都出现正的参考μ接受区超额，约109–148deg⁻²。leading则有一个角段没有on区覆盖，另外的角段未同时超过两个移位控制，保留为失败控制。

最后的入口核对移除了g/r路径误继承的z专属像素位4/7；原strict和加回z条件保持不变。尾段gr_complete增加3,412个PSF，独立面积增加0.036deg²；逐ROI影响在`mask_revision/gr_pixel_mask_effect.csv`，修正前完整成像试验保留在私有执行历史。

实际特殊检测核心单独按DR11发布的圆区提取：RA229.0205°、Dec−0.1202°、半径0.0641667°。其中568个PSF全带CLUSTER bit13，567个有G3引用。这对应巡天在核心关闭常规检测、保留Gaia强制测光的处理。依据见[DR11外部目录](https://www.legacysurvey.org/dr11/external/)与[bit定义](https://www.legacysurvey.org/dr11/bitmasks/)。核心不能承担独立星数完整率验证。数据中的历史键名`Pal5_core`实际是邻近轨迹条带，真正的检测圆区在`core/`，两者没有混用。

Sgr固定北段和亮南段均有参考μ下的on/off超额。北段在完全相同的gr入口与面积上，完整MS+SGB/RGB接受23,295个on源、29,205个off源；MS/TO-only为12,125和10,018。除去RGB兼容分支大幅减少背景，也保留了大部分沿迹超额。接受区本身可以重叠，互斥的MS-only/RGB-only/both计数另存，并没有把模型接受区当成光谱类别。

**支持与限制。** 入口扩展、形式深度匹配和固定μ沿迹对照得到支持，但过滤器的响应仍然很宽。Pal 5 trailing的FOS MS/TO响应峰在μ=16.0，物理对照模板在16.4，参考尺度约16.706；Sgr北段MS/TO峰在17.1，参考约18.409，而完整MS+SGB/RGB峰在18.8。这些是背景相减后模板接受数的峰，未作LF/相位数目归一化，不能直接当作距离后验峰。模板星族、容许宽度和残留前景都会改变它们。Pal 5对照还同时改变了MIST版本（1.0→1.2），不能把差别全归因于FeH。

因此，预先登记的“固定角段正超额并超过相邻控制”操作判据通过，与“星流距离已精确恢复”是两种结论。新图用来展示成像与筛选响应；本轮没有据此发布纯星流成员或新的单星距离。

**全足迹决定。** 为保持定义一致，用Pal 5预CMD源的冻结误差宽度曲线在两个系统重放；相同操作判据仍通过，随后累计了同定义全足迹。结果如下：

| 同一固定gr_complete / MS_TO定义 | 实测 |
|---|---:|
| 几何候选native sweeps | 1,339 |
| 这些sweep中的原始记录（尚非唯一恒星） | 2,523,727,695 |
| TYPE=PSF | 1,206,090,243 |
| native ownership后 | 1,192,921,959 |
| 高银纬、0≤E(B−V)<0.10后 | 965,960,557 |
| 完整g/r质量和g0/r0<23后 | 95,683,025 |
| 共同形式g/r深度≥23后，唯一PSF | 74,913,378 |
| 进入至少一个MS/TO节点的源 | 25,423,822 |
| 61节点接受次数 | 502,901,006 |
| 每个并集源平均进入节点数 | 19.78070 |
| 独立成像有效面积 | 14,155.7044deg² |

完整逐项流失与南北分别计数在`full_inventory`、`full_validation`。这74,913,378个源是新的成像筛选母样本，与旧生产目录的母表不是同一批。原4,334万条距离PDF没有被替换。

南北不均匀有直接的选择证据：北天在g0/r0<23时有15,369,842个源，要求共同23等形式深度后只余1,368,278个；南天对应80,313,183→73,545,100。不能把这种差别直接解释成银河系恒星密度差。北天native模板继承既有有限支持的颜色变换，本轮局部星流恢复检验在DECam完成。

新增全域RGB与旧cube重绘均保留真实mask、标量密度色条、signed残差和各通道数值。它们展示的是可重现的CMD响应，仍受模板可见性、源检测和survey选择影响。

## 二、一个光度零点可以改善低主序，不能修好全部老星族

**假设。** 先保留原演化顺序中的多值分支，再检验一个最小光度标定能否迁移到别的系统。

**真实数据。** 新序列沿原phase0折线积分，用gr/rz联合颜色似然保留共有r误差协方差。它同时改变了颜色投影和分支权重，不能把全部结果变化都称为“折返排序bug的影响”。逐星折返扰动频率、旧/新d50和共同成员交集均已导出，原209/65等旧口径结果保留并列。

仅用M13的166个低主序共同成员标定一个灰光度零点，得到ΔMg=−0.323614mag，没有增加颜色项。在预先固定的低主序范围（0.30≤gr≤0.85，参考Mr4.5–8）上：

| 本次零点未使用的系统 | 共同成员N | 标定后中位距离偏差 |
|---|---:|---:|
| M5 | 397 | −7.32% |
| M30 | 32 | +3.94% |
| GD-1 thin | 36 | −0.16% |
| GD-1 cocoon | 13 | −2.78% |
| M92 | 6 | −4.53% |

N<30的组保留定量结果，不能与大组同等解释。M5/M30提供了本次零点以外的系统迁移证据；GD-1距离曲线仍有理论标尺/教师关联，且联合曲线误差未给出。所有系统都在以前开发中查看过；“未参与此次零点拟合”不表示整套项目的全新盲验证。

转折区没有一起变好：标定后M13/M5/M30/GD-1 thin的中心偏差仍约−21.3/−24.8/−12.2/−17.5%。低主序区间的可靠性也不足，例如M5的中心68%区间仅包含约27%的参考中心；偏差与区间宽度都会影响这个比例。单星区间条件于点估计零点和参考中心；组间偏差CI另外传播了共享零点与共同参考尺度。每个系统只有一组距离扰动和成员重采样，所有方法、星等、相位和mask组共同使用。

普通矮星对照也不支持普遍替换：排除直接fit/calibration角色后，固定低主序域南/北有134/142个对照，理论分支仅支持3/8个；这批稀少支持对象的标定后偏差仍约−31.7/−21.5%。它说明该贫金属模板不适用于整个普通矮星人群，不能以其少数支持对象代替全域性能。

**物理含义与决定。** 当前得到的是相位依赖的光度失配。年龄、化学组成、alpha增强、转折/次巨星混合和未分辨双星都可能改变颜色相近对象的光度。作为量级参照，等质量双星比单星亮0.753mag，按单星光度解释时距离会偏近29.3%；本轮没有据此测出双星比例。文献中的系统化学/年龄跨度和各自native在`sequence/system_populations.csv`，固定模板alpha=0，与真实老星族并非完全匹配。

保留这一标定作为已确认老星族低主序的开发结果，不采用通用平移，不替换生产QRF，也不把区间称为已经校准。

## 三、小的“金属丰度差”可能是条件化造成的

**假设。** 同时固定视星等、颜色、消光和参考距离，会限制结果变量Mg_ref本身，因此较小的距离残差组间差不一定表示模型消除了化学偏差。

本轮固定参考角色排除、独立光谱logg/Teff相位、颜色/星等域和两设计共同支持的源身份。先登记共同交集，再在交集内重拟合两套点权重和每个天区bootstrap；截取前的权重没有继续直接用于截取后人群。此前的临时表与失衡诊断保留在执行历史中。

同一批3,230个SpecDis 2–5kpc对象，用同一种加权mean：

| 统计量 | 不含参考距离的权重 | 含参考距离的权重 |
|---|---:|---:|
| 距离模数残差的贫金属−普通组差 | 0.2692mag | 0.0149mag |
| 天空bootstrap 95%区间 | [0.2524,0.2883] | [−0.0030,0.0323] |
| Mg_ref组间差 | 0.2610mag | 0.0008mag |
| 控制变量最大绝对SMD | 0.00049 | 0.00158 |
| 普通组ESS | 1,656 | 1,075 |
| 贫金属组ESS | 1,229 | 899 |

对象没有改变，权重和所代表的重叠人群会改变。含d_ref时Mg_ref几乎被条件变量固定，小差值不是“没有金属丰度依赖”的证据。同权重的mean/median比较另存，未与条件变量改变混在一起。

参考精度/亮度受限域，以及r16–18内的窄Mr4.5–5.5、mu11.5–12.435矩形也给了结果。精度入口按来源分开：Gaia用已存95%距离区间的相对半宽≤0.15，SpecDis/SPDist用其原生模数散度转换的相对一倍散度≤0.15；这不是统一的一倍标准差，结果也没有跨参考混合。后者对已声明的r限和形式测光深度完整，仍是被参考目录与Mr截断选中的人群；不能把其中的亮度差升格为无选择偏差的全银河系FeH系数。光谱FeH与光谱距离共享信息的影响继续单列。

独立标尺方向来自signed-Gaia观测空间：3,900个普通对象、819个贫金属对象，分别保留368/99个负视差。对冻结完整PDF施加−0.2mag的试验尺度变化，贫金属组的平均预测log score增益为+0.02397nat，天空95%区间[0.01495,0.03429]；普通组反而降低−0.00932nat。这支持尺度差具有星族依赖，但不是对全目录拟合出的通用修正。似然按实际视差S/N窗口归一化，没有反演弱/负视差。

## 四、收尾决定

覆盖扩展和图像交付完成；已知系统中的低主序迁移得到有限而明确的支持；通用理论序列、通用零点、精确星流距离以及无选择偏差的FeH系数都没有据此成立。保留全部生产模型、旧数据和负结果。

**下一项最有价值的单个实验**是：在同一批参考成员、相位区和共同标尺draw上，比较按文献年龄/FeH/alpha匹配的native序列及其参考CMD残差形状，并检查可能的双星序列。先据此辨别星族失配与相位/双星混合，再决定经验模型需要怎样的population条件。没有自动开始新森林、全目录替换或论文编辑。
