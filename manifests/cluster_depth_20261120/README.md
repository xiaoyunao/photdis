# 暗端星团距离偏差的 CMD 与成像诊断

**偏差在低主序的 (M_{r,0}simeq5)–5.5 已经出现，也在两个主星团的外围低拥挤成员中保持。** 对同一批成员改用独立的颜色–光度关系后，距离误差明显减小，但概率区间仍偏窄。结果支持优先检查 QRF 对低主序颜色所分配的绝对光度和分支概率。最严格的跨星团质量对照缺乏共同样本，其预设检验未通过。

## 偏差沿真实 CMD 怎样变化

实验逐一恢复上轮冻结的 20,875 个 DR11 原生 PSF 与完整 QRF PDF。全部成员同时映射到 ((g-r)_0)–(M_{r,0}) 和 ((r-z)_0)–(M_{r,0})。在亮端和暗端应用同一低主序代理后，原先把各种演化相位一起比较所得到的亮暗差大幅缩小。

| 星团 | 亮端低主序 (r<20) | 暗端低主序 (20le r<22) | 暗端 68%／95% 区间包含共同参考 |
|---|---:|---:|---:|
| NGC 6362 | +0.439 mag，488 颗 | +0.612 mag，1,336 颗 | 48.1%／98.7% |
| NGC 6723 | 0 颗 | +0.804 mag，44 颗 | 29.5%／100.0% |
| M55 | +0.714 mag，1,970 颗 | +0.892 mag，1,400 颗 | 17.4%／84.0% |

全成员按绝对星等分箱时，两个主星团的中位残差从 (M_{r,0}=3.5)–4.0 的 −0.45、−0.24 mag，变为 (M_{r,0}=4.5)–5.0 的 +0.38、+0.52 mag。这一跨序列变化包含演化相位差异。NGC 6362 和 M55 在同一低主序定义下的亮暗差约为 **0.17–0.18 mag**。在预先定义的低主序范围内，两团首先满足固定偏差增长判据的绝对星等箱均为 (5.0le M_{r,0}<5.5)，其中分别有 713 和 601 颗星，模数残差中位数分别为 +0.469 和 +0.603 mag。对应的视星等起点分别落在 19.5–20.0 和 19.0–19.5，说明相同 (r=20) 阈值会在两个星团切到不同位置。半星等分箱保留了完整 PDF 宽度与严重离群比例。 [连续分箱及参考包含率](results/continuous.csv) · [首个支持的残差范围](results/growth.csv)

## 成像质量与外部标尺

| 对照 | NGC 6362 | M55 |
|---|---:|---:|
| 外围、低拥挤、测光精度与深度达标 | +0.620 mag，68 颗 | +0.843 mag，344 颗 |
| 上述外围样本再匹配三维 CMD | +0.623 mag，33 颗 | +0.790 mag，13 颗 |
| 低拥挤、精度与深度达标，匹配三维 CMD | +0.683 mag，391 颗 | +0.814 mag，653 颗 |
| 最严联合条件 | 1 颗 | 5 颗 |

“外围”指半径至少 8′。三维匹配使用固定 ((M_{r,0},g-r,r-z)) 单元，并给两个主星团相同的单元权重。外围同时匹配的 33 与 13 颗只覆盖一个共同单元，低拥挤共同样本则提供支持较好的补充证据。预设最严条件还要求光学掩膜、像素覆盖和成员概率 >.99，其共同 CMD 单元为零；NGC 6723 的外围暗端对照也为空。

第一版把所有原生 `MASKBITS` 标记当作光学坏点，产生了空样本。DR11 的 `CLUSTER` 位表示星团处理区域，WISE 和 (i) 位也不对应本实验的通带。保留了第一版结果，再使用 (grz) 相关的光学掩膜和实际坏像素列核对；最终严格选样仍远低于预设样本量。 [DR11 位掩膜定义](https://www.legacysurvey.org/dr11/bitmasks/) · [第一版计数](initial_allmask_quality.csv) · [逐位计数](results/mask_audit.csv)

采用 W1 RR Lyrae HST 标尺，外围低拥挤的分砖块与共同参考误差区间分别为 [+0.409,+0.828] 和 [+0.638,+1.068] mag。更换到 Baumgardt–Vasiliev 合并标尺或另一发表标尺之后，两团仍偏远。将 W1 参考统一上移 0.32 mag，外围的中位偏差仍分别为 +0.300 和 +0.523 mag。Dambis 原文标尺引文已核对为表 6。参考误差在每个星团内整体传播，三套标尺分别列出，保留其共享标定和样本依赖。 [分组与标尺敏感性](results/scales.csv) · [Dambis 等人，表 6](https://doi.org/10.1093/mnras/stu226)

## 同源独立颜色–光度关系

采用独立定标的先前 DECam 经验星团序列，以及按文献年龄和金属丰度固定的 MIST v1.2 主序。两种比较在同样的 (grz) 测光及模型支持身份上与 QRF 配对，目标的参考距离仅用于评分和分组。

| 星团 | MIST 与 QRF 同源数 | QRF → MIST 中位模数偏差 | MIST 减 QRF 的平均 CRPS |
|---|---:|---:|---:|
| NGC 6362 | 1,328 | +0.612 → −0.213 mag | −0.363 mag |
| NGC 6723 | 42 | +0.774 → −0.238 mag | −0.315 mag |
| M55 | 1,395 | +0.894 → −0.224 mag | −0.702 mag |

独立 M5 经验序列在有支持的 NGC 6362 暗端成员中，将中位残差从 +0.646 改为 −0.064 mag（984 颗），在 M55 从 +0.971 改为 +0.221 mag（731 颗）。M30 经验序列的红端覆盖不到固定暗端样本。MIST 的暗端 68% 区间仅包含约 30%–36% 的共同参考，且三团中心仍偏近约 0.2 mag。其固定太阳比例丰度只近似这些系统。正负残差和区间表现提示，光度位置与 PDF 校准都需要检查。 [同源距离与概率评分](results/paired.csv) · [模型支持范围](results/model_support.csv)

现有证据将主要疑点集中到冻结 QRF 的低主序颜色–绝对光度对应关系和分支概率。成像和消光仍可能解释一部分差异。下一步优先检查两个主星团相应 CMD 区域在 QRF 训练集中的覆盖，以及 QRF 把多少概率分配给更亮的光度分支。星团间的残差差异仍是三个物理系统上的比较，缺少把金属丰度、消光和其他系统差别分离的独立重复。
