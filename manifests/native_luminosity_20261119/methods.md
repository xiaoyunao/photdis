# 统计定义与可复现方法

## 样本与唯一候选

保留M5/M30/M13原始PSF成员585/99/249。E支持分别565/97/230，支持条件不由新结果改变。M5已有lower_MS及turnoff框中的525颗E支持成员进入校准设计。固定ID哈希与观测颜色分层提前分成263/262颗两折；每颗M5预测使用另一折的参数。最后全525颗再拟合一次，只为固定迁移提供参数。QRF直接复用原始完整分布，没有重训。

每个原E节点、原生波段采用相同修正：

`M'_bj = M_bj + a0 + a1*(native_node_gr - .30)`。

只有a0、a1两个自由度。原节点身份、邻接、初始质量权重、相位、原Mr3–8入选集合、支持条件、0.001mag误差下限、0.10mag灰散布和平坦mu测度固定。修正后不按新Mr重新裁节点。模式的相对距离可以改变，原有颜色权重与后主序质量保持不变；没有额外宽度伸缩。

两色几何使用原始物理线段，不以离散积分节点代替线段。颜色协方差非对角元为`-sigma_r^2`。保存加权最近线段、垂直和切向残差、端点、分支以及DeltaChi2<=4竞争线段。相接端点可能对应两个竞争线段，记录不能解释为两个独立物理解。内部最近投影的白化切向残差按定义为零。几何诊断没有替换既有E支持条件。

## 一个系统参考及共同抽样

拟合目标为`R(mu_M5)*product_i p_i^cal(mu_M5)`，完整混合PDF进入似然。令`theta0=a0+mu_M5-mu_ref`，单位Jacobian变换使目标分解为`L(theta0,a1)*R(mu_M5)`。所以联合MAP位于`mu_M5=mu_ref`；每次成员重采样得到theta参数后，使用**一个**系统参考draw作`a0=theta0-delta_mu_M5`。真实成员数据的平移恒等重放保存在`fit/shared_reference_identity.csv`。外部参考没有逐星重复计入拟合。

每个折及全M5均执行256次成员重采样重拟合，共771次点／bootstrap拟合；固定多起点只是优化同一个目标。全部返回成功，最大全分量梯度约1.36e-4。保存观测Hessian、bootstrap参数协方差、所有起点、目标值及参数draw。沿用v7整个母样本的成员multiplicities，新增固定种子的高斯系统mu draw，其sigma来自既有距离draw的对数尺度散布；原v7非高斯draw与旧评分不改。新表中所有相位、颜色和方法复用同一次系统draw。

## 条件预测、参数混合和评分

主表CalE是点参数条件PDF。M5使用对应训练折参数；M30/M13使用全M5参数。尺度、评分和宽度的区间来自每次重新拟合的共同bootstrap。

M5留出评价条件于同一个系统参考中心；训练截距和留出参考在bootstrap中共享同一个M5距离draw。校准PDF的位置与共同参考一同平移，不再额外卷积独立M5参考核。原E和QRF也使用同一系统draw。`raw_coupled_reference_CDF_C68/C95`先沿相应共同draw平均逐星CDF，再汇总中央概率区间诊断；`raw_CDF_C68/C95`是点条件定义。它们与旧v7独立参考卷积评分的定义不同，旧表保留原值。

外部评分将目标系统的独立高斯mu参考核卷积一次。目标共同draw用于统计区间，不是给预测再次加散布。完整PDF在mu坐标计算logscore与CRPS，CRPS越小越好。中心化只作诊断，不能代替原始尺度结果。零QRF密度保留负无穷，不加密度地板。

外部另列CalE_marg：把全M5的256个bootstrap参数向量等权混合，一次参数索引由所有目标成员共享。保留多峰及所有原始成分；实际应用的预测不含目标参考核，评分时再加一次。其区间条件于冻结参数ensemble，对目标成员和共同参考重采样；训练参数影响已进入预测宽度。对比条件PDF与混合PDF的区间定义分别保留。没有另行构造M5独立参数混合PDF。

两色域按相应训练折／全M5实际观测gr范围登记；按原节点后验在范围外的质量<=.05、(.05,.5]、>.5分为overlap、transition、extrapolation。标签不改变支持条件。未知场星的年龄、丰度或分支混合不由本实验给出。

## 数值与交付

条件logscore直接求完整logsumexp；外部参数混合采用相对遗漏和小于exp(-40)的有界求和及三次插值，所有原成分保留。CDF积分最多忽略机器精度级总质量，CRPS网格0.0025mag，参数混合0.00125mag。42项真实源直接求和／半步检查与独立根求解通过预设精度；细节见`validation/direct_halfgrid.csv`。外部完整参数混合及每次条件PDF均归一化，原始参数与私有路径有哈希。

本轮五个独立数学测试、原v3.8 F02/F03像素回归、五张新图独立同环境逐像素重画及所有PDF页目视检查通过。图面文字全英文。完整预测和缓存留在分配节点的NERSC工作区，公开紧凑表与重绘数据有`release.json`文件级绑定。
