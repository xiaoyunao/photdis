# 六个真实 DECam 视场的低纬测距实验

两个低纬场 L233 和 L240 的冻结 QRF 距离，在可比较恒星中比高纬对照偏远。使用 Bayestar19 的有限距离消光后，配对样本的距离尺度在这两个场接近 Gaia，完整分布的 CRPS 也降低。消光更重的 L219 在迭代后仍有明显偏差，而且成功率明显较低。因此，这一结果支持把有限距离消光列入低纬应用的验证，但不足以支持统一改正或直接扩展生产目录。

## 真实可用范围

六场实际共有约 19.68 平方度的 gr 成像几何覆盖，取得 527,156 个三带误差均低于 0.10 mag 的原生点源。466,979 个通过冻结 QRF 的名义支持条件。25,605 个通过 Gaia 几何参考质检。其中 23,151 个同时具备 QRF 支持并可用于条件比较，按固定身份抽样实际评价 9,870 个。纳入六个场的精确测光对象在所盘点的 QRF 训练身份和历史父表中均无身份重叠。这个检验仍是有限视场的生产模型重放。

| 视场 | 实际 gr 面积 (deg²) | 精确 grz | QRF 支持 | Gaia 几何 | 实评 Gaia |
|---|---:|---:|---:|---:|---:|
| L219 | 1.55 | 43,227 | 30,481 | 2,180 | 870 |
| L233 | 2.32 | 101,138 | 90,460 | 3,396 | 1,800 |
| L240 | 2.25 | 105,367 | 95,315 | 5,186 | 1,800 |
| M240 | 4.80 | 68,667 | 61,504 | 5,023 | 1,800 |
| M037 | 3.87 | 180,600 | 166,443 | 7,359 | 1,800 |
| H240 | 4.89 | 28,157 | 22,776 | 2,461 | 1,800 |

精确 grz 样本中按每场 3,000 个对象固定抽样，5,055/18,000 个通过既有工作选样规则。各场比率约 14.2%–35.4%，对应所选窗口中的观测保留率。SpecDis、SPDist、APOGEE astroNN 均未提供这些已登记精确 grz 样本中的合格距离。高质量 Gaia 检验中，9,864/9,870 个亮于 r=20，2–5 kpc 有 1,260 个，5–10 kpc 为零。低纬尤其暗端和远端的距离精度仍无法从这些窗口外推。Gaia CMD 的保守类别代理用于匹配检验，无法替代完整的光谱分类或化学组成控制。

## 哪些环境差异有实测支撑

下表是目标场减 H240 的同类恒星中位距离模数残差差。每个对照独立平衡颜色、观测 r、参考距离和类别，区间为场内空间块自举。这里的条件比较保留消光、拥挤和天空位置的综合差异。

| 视场 | 尺度差 (mag) | 95% 区间 (mag) | 达到 0.10 mag 估计精度 |
|---|---:|---:|---|
| L219 | −0.721 | [−1.036, −0.125] | 否 |
| L233 | +0.233 | [+0.207, +0.271] | 是 |
| L240 | +0.186 | [+0.159, +0.227] | 是 |
| M240 | −0.020 | [−0.047, +0.003] | 是 |
| M037 | −0.046 | [−0.075, −0.020] | 是 |

L233 和 L240 的偏远在保守矮星代理组中仍出现，约 +0.239 和 +0.180 mag。若另外同时平衡 SFD 与拥挤，低、高纬场之间没有共同单元可估计，而高、中纬对照仍有覆盖。单独测试高拥挤时，共同单元的高拥挤一侧只剩四颗。可比单元中的高、低 SFD 柱差为 −0.029 mag [−0.067, +0.037]，仅代表有匹配支持的子域。不能由上表推断偏差由某一个环境因素引起。L219 的原始总体有 40.9% 的对象出现大于 1 mag 的残差，且匹配后尺度会随类别改变，应优先视为极端环境的失败域。

## 3D 消光能改善什么

地图在 3,000 颗 Gaia 对象中为 2,305 颗提供连续可靠距离区间。纯测光迭代收敛 1,747 颗，最终有 1,691 颗同时满足事先指定的地图参考覆盖条件。L219 的测光收敛率为 198/500，H240 无可靠 Bayestar 路径。下表在每行完全相同的源和地图有效距离区间内比较。

| 视场 | 同星 N | 全柱 SFD 偏差 (mag) | 有限距离偏差 (mag) | 平均 CRPS 变化 (mag) |
|---|---:|---:|---:|---:|
| L219 | 188 | +0.662 | −0.414 | −0.114 |
| L233 | 438 | +0.283 | +0.009 | −0.052 |
| L240 | 435 | +0.244 | −0.018 | −0.037 |
| M240 | 198 | +0.008 | +0.022 | +0.003 |
| M037 | 432 | −0.110 | −0.098 | −0.006 |
| 合计 | 1,691 | +0.146 | −0.056 | −0.037 |

L233 与 L240 的 CRPS 改善 95% 区间均低于零；M240 和 M037 的区间跨零。L219 虽然评分改善，仍有约 0.41 mag 的偏近残差。其用已知 Gaia 距离查询 Bayestar 的对照也偏近，说明仅换消光输入无法恢复该区域的尺度。该对照的表格只记录尺度和严重残差，预测评分留空。迭代解是收敛点的条件 QRF PDF，以地图覆盖和共同支持为前提，不能囊括地图不确定度和多解。分场地图覆盖、每阶段退出以及不限距离的 SFD 比较见随附表格。

本轮对论文最直接的贡献是：在两个实际低纬窗口复现了绝对尺度偏差，并用同一批恒星显示其中一部分可以通过有限距离消光改正降低。要把它写成目录适用域的证据，应保留每个窗口的通带、星等和 Gaia 几何覆盖，并把高拥挤、极端消光、暗端和 5–10 kpc 的结论留在实际证据边界内。已经保留完整 V8、先前生产距离和全天 RGB，NGC1851/NGC5053 仍等候将来的物理模型检验。
