# Registered DECam conditional RGB experiment

Registered against the repository at `7256423`, before reading NGC 5466 Legacy member photometry or fitting the new model. Configuration: `configs/cluster_rgb_conditional_v1.json`. The pooled A/B models and their once-only NGC 7006 result remain historical records. For this new experiment, NGC 7006 is a development cluster.

## Samples and reference scale

Use only natural DECam DR11 measurements. Development stages are M3 lower RGB, M53 upper and lower RGB, and NGC 7006 upper RGB. M3's upper edge and NGC 7006's lower/RHB overlap are diagnostics. The northern NGC 2419 sample remains a separate camera-system diagnostic. Membership requires the existing Vasiliev–Baumgardt `Pmember>0.9` and the already registered Gaia-CMD phase screen. Use the established per-band `gr_clean` tier for a gr relation and `grz_clean_same_row` for a grz relation. Report the extra gr-only range without confusing it with a same-source band comparison.

The new whole-cluster test is NGC 5466. Its independent RR Lyrae true modulus is `16.02 ± 0.09 mag` from [Arellano Ferro et al.](https://arxiv.org/abs/0711.4027); this paper adopted `E(B-V)=0.00`. The member file is present in the existing Vasiliev–Baumgardt archive. The cluster is within the DR11 southern DECam footprint. Its Gaia phase screen is the already frozen M53 screen, copied before inspecting its Legacy measurements. The entire NGC 5466 source identity is excluded from development, selection of functional form, fitting, calibration, model choice, and prior choice. Its actual Legacy quality and supported luminosity range will be disclosed at final scoring; if these are insufficient, report that outcome without changing the test.

Use the [homogeneous RR Lyrae compilation](https://arxiv.org/html/2306.01175v1) for one explicitly named iron scale: RRab Zinn–West abundance transformed to the Carretta UVES scale by `-0.413 + 0.130 ZW - 0.356 ZW²`. The adopted rounded values are M3 −1.46, M53 −2.00, NGC 7006 −1.40 and NGC 5466 −2.16 dex. Carry their quoted RRab uncertainties through the transformation and add a scale sensitivity. NGC 5466's RRc value on the same reported UVES scale is −1.89; score that as a predeclared metallicity sensitivity, not as a tuned alternative. The older NGC 7006 RR study gives Zinn–West `−1.53 ± 0.15`, not a directly interchangeable UVES number.

## Model and uncertainty

First measure each development cluster's stage-matched gr/grz sequence, local residuals, radial and image-quality trends, and overlapping absolute-magnitude range. Report the observed M3–M53 gr/rz offsets and the amount that plausible common dust or distance shifts can explain. Fit a low-parameter forward relation `p((g-r)0,(r-z)0 | Mg, [Fe/H], RGB, DECam)` only in genuinely overlapping magnitude cells. The gr-only variant uses `(g-r)0` alone. The fixed basis for each color is `1, (Mg−1), (Mg−1)², ([Fe/H]UVES+1.7)`, without a luminosity–metallicity interaction. Give each development cluster equal total weight and penalize the metallicity coefficient with ridge strength 4. Use a 0.01-mag intrinsic color floor. Include the shared-r measurement covariance `Cov(g-r,r-z) = −σr²` and the shared-g `Cov(Mg,g-r)=σg²`. Treat externally measured modulus, dust scale and 0.01-mag-per-band zero-point uncertainty as whole-cluster nuisance parameters with 48 fixed-seed Monte Carlo draws; they cannot be unconstrained cluster intercepts. Support is checked in 0.5-mag bins over `Mg=−1.5` to `3.0`, requiring at least five M53 members and five members of the other development cluster in the same Gaia stage. The posterior integration step is 0.02 mag. Do not optimize the relationship against the test cluster.

Invert using a uniform absolute-magnitude prior over the registered supported range, not the selected training sample's brightness histogram. Compare gr and grz using the same grz-clean sources and common magnitude support. First score with the cluster's known [Fe/H]. Then marginalize over two fixed UVES components `−1.46, −2.00` with weights `0.5/0.5`, `0.8/0.2`, `0.2/0.8`; do not use the blind cluster to choose weights. Report posterior width and shift under these priors. This is an explicitly conditional RGB experiment, not a fully classified field-star distance catalog.

Freeze all model choices and development outputs before opening NGC 5466's Legacy label. Score NGC 5466 as a whole cluster in supported magnitude bins, with median `Δμ = μpred − μRR`, NMAD, fraction `|Δμ|>0.5 mag`, 68/95% coverage, and mean predictive log density **in distance-modulus space**. A separate color likelihood is descriptive because gr and grz have different color-space dimensions. Report the cluster's shared 0.09-mag modulus uncertainty separately from star-to-star scatter. A successful known-abundance test does not establish photo-only abundance or RGB stage classification.

The two-color near-degeneracy already seen at `Mg≈1.67` in M3/M53 is a model-design constraint. Its approximately 0.5-mag interpolated luminosity difference is not an observed prediction error. Local color residual widths are likewise not distance precision. Report test metrics by luminosity and stage.
