# Photdis v3 final science figures

The figure paths identify versioned products. The existing figures retain
their Pal 5 rendering at v3.8. The final Aitoff plates add a calibrated
surface-density color scale to the same Galactic orientation. All figure
labels are in English. Each new plate has PNG, PDF and a numeric bottom table.

| Figure | Content |
|---|---|
| [F18](../figures/final_catalogue/F18_catalogue_flow.png) | Native DR11 sweep records through owned parents, full PDFs and science sources |
| [F21](../figures/v3_final/F21_full_density.png) | Owned PSF, full PDF and science-core surface densities |
| [F02](../figures/final_science/F02_direct_distances.png) | Direct distance comparisons with Gaia, SpecDis and SPDist |
| [F03](../figures/final_science/F03_same_star_cmd.png) | Same-object reference and Photdis absolute-magnitude CMDs |
| [F15](../figures/final_catalogue/F15_independent_distances.png) | Photdis and Bailer-Jones photogeometric comparison on identical weak-Gaia dwarfs |
| [F20](../figures/v3_final/F20_population_physics.png) | Retention, distance residuals, severe errors and true distance layers by stellar class |
| [F22](../figures/v3_final/F22_pdf_density.png) | Full PDF source surface density in four predicted median-distance ranges |
| [F16](../figures/final_catalogue/F16_catalogue_xyz.png) | Heliocentric XY, XZ and YZ projections for full PDFs and the science core |
| [F10](../figures/final_science/F10_distance_residuals.png) | Distance residuals by stellar population and distance |

Additional figure plates include [F23](../figures/v3_final/F23_core_density.png)
for the corresponding science-core layers, [F24](../figures/v3_final/F24_reference_density.png)
for the held-out spectra and dwarf/giant labels, and
[F25](../figures/v3_final/F25_native_density.png) for the north/south native
systems. The prior [catalogue atlas](final_catalogue.md) and [Final Science
Analysis](final_science.md) document the original comparison and
space-density surfaces, the Gaia increment, stream/cluster cases and the
conditional LF experiment. For the new plates use the [numeric tables](../manifests/v3_final).
