### 这轮还解决了两项会影响物理解释的统计问题

**第一，金属丰度比较现在使用同一批源和同一种统计量。**

在固定的 3230 个 SpecDis 对象上，贫金属组相对较高丰度组的模数残差均值差：

- 不加入参考距离条件：**+0.2692 mag**；
- 加入参考距离条件：**+0.0149 mag**。

SPDist 的 2408 个共同对象给出 **+0.1948 → +0.0063 mag**。这次两种设计都在固定支持集内重新拟合，并在空间重采样中重复这一过程。[对应结果已替换论文 Table 5。](https://github.com/xiaoyunao/photdis/blob/6538df7624bfa3a53b12b83326596b712204f12a/manifests/stream_response_20261119/conditioning/estimands.csv)

物理解释来自：

\[
\Delta\mu=M_{g,\mathrm{ref}}-\widehat M_g.
\]

在表观星等和颜色已经受到约束时，参考距离条件会进一步约束参考绝对星等，也改变加权后代表的人群。论文现在把这一结果写成**条件化如何改变丰度相关残差**，并结合独立测量空间中的信息解释。

signed-Gaia 的预定义试验提供了补充证据：把完整距离 PDF 平移 \(-0.2\) mag 后，贫金属组的平均预测 log score 提高 **0.02397 nat**，较高丰度组降低 **0.00932 nat**。这支持两类人群需要不同的尺度处理方向。[相关试验记录。](https://github.com/xiaoyunao/photdis/blob/6538df7624bfa3a53b12b83326596b712204f12a/manifests/stream_response_20261119/conditioning/signed_gaia_anchor.csv)

**第二，折返检查已经给出了清楚结果。**

1160 个无掩膜序列母样本对象，在每源 128 次扰动中，折返命中数为零。因此，当前星团偏差的解释重点回到观测序列与模型的光度、颜色和相位关系。论文已经据此调整了相关叙述。[本轮方法与判断记录。](https://github.com/xiaoyunao/photdis/blob/6538df7624bfa3a53b12b83326596b712204f12a/manifests/stream_response_20261119/science_decisions.md)

## 3. 从整个项目看，当前真正需要解决的科学问题

### 3.1 光度零点与序列形状，需要用实测序列直接分开

M13 一个零点能改善其他系统的低主序，同时在转折区出现较大的偏差，这说明**序列位置本身是关键变量**。接下来最有效的实验，是直接画出成员的经验 ridge，并比较两个 native CMD：

\[
(g-r)_0\!-\!M_{g,\mathrm{ref}},
\qquad
(r-z)_0\!-\!M_{g,\mathrm{ref}}.
\]

我在 prompt 中安排了 M13、M5 为主要样本，M30 为较贫金属对照。用现有成员和外部距离，比较原固定序列与少量按文献年龄、丰度预先选定的序列，测量：

- 整条序列的灰光度位移；
- 颜色残差随序列位置的变化；
- 低主序到转折区的残差形状；
- 更亮侧翼及其与等质量双星轨迹的关系；
- 模型支持区内外的成员分布。

这张图会直接决定后续校准方式。如果残差主要是近似恒定的光度位移，简单零点标定就有明确意义；如果残差随颜色弯曲，则应处理颜色关系或相位依赖。**当前最缺的是这张实测 ridge—模型比较图。**

### 3.2 中位尺度改善之后，单星预测区间仍需要检验

M5 低主序经过标定后，中位距离偏差为 −7.32%，但其参考距离中心落入名义 68% 区间的比例只有 **27.5%**。M30 和 GD-1 thin 的对应比例为 **56.3%** 和 **44.4%**。这些结果表明，尺度和区间宽度需要分别度量。[同源结果表。](https://github.com/xiaoyunao/photdis/blob/6538df7624bfa3a53b12b83326596b712204f12a/manifests/stream_response_20261119/sequence/distance_scale.csv)

下一轮应在相同成员上同时保存四项量：系统中位残差、去除该中位后的散布、预测区间宽度，以及传播共同参考距离和标定误差后的概率指标。这样可以判断 M5 的低包含率中，中心偏移与区间宽度各占多大作用。

目前组尺度的置信区间已经传播了共同距离和 M13 零点的不确定性；单星 PDF 仍条件于点估计零点，并采用固定的序列散布。V6 将这两类不确定性的定义分别写清楚了。

### 3.3 论文的贡献应落在 native 标定与人群迁移上

原有同源比较中，QRF 对 SpecDis/SPDist 的 NMAD 为 **9.77%/10.38%**，使用同一套光度标签的简单颜色网格为 **10.22%/10.87%**。两者相差约半个百分点；Bailer-Jones 光度几何距离在相同对象上的数值为 **13.27%/14.06%**。这些结果在 V6 的 Table 3 和 Figure 2 中保留。

这组比较使贡献的层次更明确：**native 深测光中的经验光度信息贡献了主要改善，QRF 的表示方式提供了进一步收益。** 结合本轮结果，论文最有分量的内容是：

- 对明确恒星人群，可以得到怎样的条件精度；
- 同一光度关系向老年星族和不同序列位置迁移时，尺度怎样改变；
- 这种改变怎样影响概率分布和最终选出的银河系样本。

同时，南天训练标签与 SpecDis/SPDist 的标尺有密切联系。因此，已知系统、signed-Gaia 和 native 实测序列承担着进一步检验绝对尺度的重要作用。V6 将训练标签来源与评估参考之间的联系放在数据和讨论部分直接说明。

### 3.4 深度与人群范围决定下一步能够提出多强的银河系结论

当前低主序框的登记范围延伸到 \(M_r=8\)，实际主要成员覆盖约 **\(r=19\)–20.8、\(M_r=4.6\)–6.4**。论文已经按实际覆盖描述验证范围。更暗部分的尺度约束，之后需要由相应深度的外部序列或其他参考来扩展。

人群选择同样重要。现有工作选择保留约 **68%** 的较高丰度矮星和约 **8%** 的贫金属矮星，说明最终距离样本的化学组成对选择条件非常敏感。这个结果已经放进主文 Table 6 和 Figure 5。将来利用距离星表测量银晕密度、径向梯度或结构对比度时，需要把这类保留率和相位迁移纳入解释。

这些问题与全天 RGB 展示可以分别推进。低纬、高消光的图能够立刻帮助我们看清观测覆盖和天空纹理；定量距离分析则继续由相应人群的尺度与概率检验支撑。
