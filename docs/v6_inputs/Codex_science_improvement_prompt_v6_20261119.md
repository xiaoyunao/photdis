## 用户这次明确的方向

项目科学主线是：native grz 能为哪些恒星给出可迁移的距离标尺和可靠的预测分布？需要解释颜色—光度关系、星族与相位差异、参考样本选择和实际应用范围。

固定 CMD 的 Aitoff/RGB 是用户希望查看的漂亮天空展示。用户明确授权把全部可用天空中的低银纬、高消光区域纳入展示，并允许这些区域保持在论文定量距离样本之外。用户喜欢 V5 `halo_rgb_overview` 的布局与色彩。

**本轮先直接交付全可用天空图。图像任务与距离科学实验分别推进。** 旧配置的“局部星流恢复通过后才累计全足迹”规则属于上一轮实验，本轮展示按用户的新指令执行。Pal 5/Sgr 的恢复、距离响应峰、注入实验或论文科学结论都不作为这次出图的前置条件。

## 任务 A：全可用天空的固定 CMD / RGB 展示

### A1. 为什么要重新取展示输入

当前名为 full 的图仍是以下入口的全范围：

- `abs(b)>30`；
- `0<=EBV<0.10`；
- gr 两带误差<0.10，去消光 g0/r0<23；
- 两带共同形式深度均达到23。

`stream_full.tasks()` 在 sweep 几何预筛时已删除低纬文件；源筛选和 randoms 又执行了同样的地理/消光限制。现有 cube 与公开网格已经压缩为这套范围。新的全天展示要从原始 native sweep 清单和实际 gr 覆盖提取。

共同深度23还删除了大量有测光的北天区域：北天满足 gr 质量及 g0/r0<23 的15,369,842个源，进入该深度域的为1,368,278；南天为80,313,183→73,545,100。展示中直接保留实际深度变化。

### A2. 本轮明确授权的展示选择

在独立目录和配置中建立全可用天空展示，不重拟合生产距离模型：

1. 扫描本地可用的全部南北 native sweep 清单，保留现有唯一源身份和 native ownership。取消 sweep/源/randoms 路径中的银纬阈值、EBV上限及共同23等深度掩膜。逐项检查这三个限制在各路径均已移除。
2. 展示对象显式要求 `TYPE=PSF`。使用有至少一次有效 g/r 观测、有限正通量及逆方差的源；采用两带 S/N≥5，继续使用现有 g/r 像素质量位、FRACMASKED<0.4、FRACIN>0.7。保持 z 独立于展示入口。
3. 保留原有去消光 g0/r0<23 的显示上限。主图采用当前已经定义的固定 native CMD 和误差宽度曲线，冻结后直接累计。将FRACFLUX与ANYMASK等更严格成像质量条件作为伴随计数，先报告它们在低纬/高消光区的影响；不要用距离模型支持、dwarf score或spectroscopic class筛选这批展示源。
4. 消光沿用目录 `MW_TRANSMISSION_G/R`，只对有效的透过率计算 m0。保存 EBV 及改正量伴随图。图注明确采用二维全柱修正。此展示任务无需建立新的三维消光模型。
5. 几何有效面积由有真实 g/r 观测的 native randoms/覆盖给出，采用对应波段质量规则；不加统一深度、银纬或高消光掩膜。源级的信噪比或形态筛选与random几何面积分别记录。
6. 有效观测像素中，CMD接受数为零就显示零；真实缺测/缺带区域使用掩膜。原始PSF数、有效gr数、固定CMD接受数保留三个简单的计数层，便于看清低纬纹理和实际缺测。

对新增全域输入先完成一次有限块的读入、坐标、计数与面积核对，然后继续全足迹累计。这是数值/数据完整性检查；不需要新的天体恢复判据。所有大扫描、累计和数组处理在已分配计算节点完成。

### A3. 用户要看到的图

沿用 V5 上下两幅 Aitoff 布局、英文坐标和清楚的距离图例：

- **主展示：全可用天空 RGB overview**，B=10–15、G=15–26、R=26–100 kpc。上图density，下图positive residual；让新增低银纬和高消光区域实际进入图中。
- **五个宽距离区间内部的RGB**：6.3–10、10–15、15–26、26–50、50–100 kpc各自近/中/远子层映射B/G/R。内部边界沿用 `d_j=a(b/a)^(j/3)`，并以细μ节点的实际单元重叠宽度累计。已有channel代数可复用。
- **一张简洁覆盖伴随图**：全PSF/有效gr密度、g/r深度、EBV，或其中最能解释实际覆盖的四面板。已有高纬定量样本边界可用细轮廓标明。

主图优先保持用户喜欢的 V5 色彩层次。图像拉伸与物理数组分开保存：可用逐通道percentile/asinh压缩银盘的高动态范围；低纬亮区饱和时先调整显示stretch。每张RGB写清通道范围，保存stretch参数和饱和比例。无需为漂亮展示搜索新滤波模型或重建距离PDF。

同一配置产出全可用天空版及旧定量域对照。图题直接写“CMD-selected sky / template-distance RGB”，附上展示选样说明。所有颜色来自实际CMD通道；额外的普通PSF背景图应保持自己的名称与图例。

### A4. 展示完成标准

- 程序实际读入低银纬、高EBV和浅于共同23等的已有成像；提供这些域的输入/有效gr/CMD计数与面积。
- 全可用天空overview及五个内部RGB均已生成并目视检查，坐标方向、0/360跨越、mask、通道顺序正确。

### B2. 本轮唯一优先的测距科学实验

问题：**同一系统的观测恒星序列与模型，主要相差一个灰光度零点，还是随颜色/序列位置变化的形状？**

先用已有M13、M5低拥挤成员，M30作较贫金属对照。沿用外部成员、native测光和共同参考距离draw。显示支持与不支持成员，保留现有相位框的诊断身份；参考Mr参与定义这一点写入说明。

在native `(g-r)0–Mg_ref`、`(r-z)0–Mg_ref` 两个CMD中：

1. 从成员提取简单、可重复的经验ridge及散布，显示原始点、测光误差和成员数。外部参考距离给纵轴尺度，消光采用已明确的约定。使用全部可用序列范围，单列模型support，不只画被模型接纳的成员。
2. 并列原固定12Gyr/Z=.0001序列，以及在同一模型版本/通带中按文献年龄、FeH预先选择的少量对应序列。先固定文献值再看残差；参数来源写入表。当前M13/M5/M30的年龄与化学信息可从`sequence/system_populations.csv`开始核对。
3. 测量两颜色方向和灰光度方向的残差随序列位置的变化，给出共同距离/消光敏感性。每个系统在自己的native系统中比较。北天经验颜色转换的散布与支持单独记录。
4. 在图上给等质量双星亮移0.753mag的参考轨迹；若数据存在更亮侧翼，直接保存其形态。第一轮不拟合双星比例，也不同时搜索年龄、FeH、alpha和距离。
5. 如果现有同模型族支持固定alpha对照，可以加入一个明确的物理对照；模型族同时改变时标注整体模型比较。不要为本轮诊断建立庞大等龄线网格。

### B3. 区间宽度的最小核查

在相同成员上同时保存：系统中位残差、去除系统中位后的残差散布、预测区间宽度，以及含共同参考/校准抽样的指标。中心化后的包含率只用于诊断“偏移贡献多少”；原始外部标尺指标同时保留。

如果据上述ridge诊断形成一个简单修正，只用预定校准系统选择参数，再在其他系统上评估。预先规定改善目标，例如转移系统残留模数尺度约0.1mag（约5%距离），并同时查看散布、颜色趋势和reference-convolved概率指标。结果决定采用局部经验标定、调整相位混合，或明确适用域。无需为完成本轮图像或论文而强制达到正结果。

### B4. 金属丰度统计沿用已完成结果

已有固定IDs、同一统计量的比较清楚表明：SpecDis N3230的Δμ组差在有/无d_ref条件下为0.014884/0.269174mag；Mg_ref组差同步变化。signed-Gaia预定义−0.2mag试验对贫金属组log score增益0.02397nat，对普通组为−0.00932nat。
