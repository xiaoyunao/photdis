# 一、最新 v2.6 已经解决了什么，真正的大问题还在哪里

## 1. 逐星后验和目录人数推断已经接通，可以作为正式基础保留

v2.6 已经实现：

- 每颗星的星族 × 距离联合概率；
- 共享总体参数下的潜在目录人数抽样；
- 人数之间的协方差；
- 按目标数据证据加权的响应不确定度；
- 对“总体组成比例”和“这批实际观测对象的潜在人数”分别评价。

这些环节在我检查的实现中，没有发现新的明显归一化或组分索引错误。**下一轮不需要重新提出“加入逐星概率”“考虑人数协方差”，而应把现有实现抽成可复用核心。**  
来源：[核心推断代码](https://github.com/xiaoyunao/photdis/blob/b59e18b/src/photdis/population_v2_6.py)、[v2.6 结果](https://github.com/xiaoyunao/photdis/blob/b59e18b/docs/v2_6_result.md)。

## 2. 距离总人数改善，还没有解决星族组成偏差

这一点直接关系到老板问的“10 kpc 内究竟有多少巨星、多少矮星”。

例如，按最新人数表重算：

- 在接近参考组成的模拟目录中，实际抽取的贫金属矮星比例约 **14.13%**，扩大模板并边缘化后的估计仍为 **25.91%**。
- 在巨星富集目录中，实际巨星参考组比例约 **25.78%**，固定响应估计为 **26.15%**，扩大模板并边缘化后变成 **32.13%**。

因此，最后一组虽然距离人数误差从 14.66% 改善到 13.27%，巨星人数均值却偏得更多。**后续必须同时验收距离人数、类别人数、区间宽度和逐星概率，不能用一个总人数指标代表整体成功。**  
来源：[原响应人数](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/observed_counts.csv)、[响应边缘化人数](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/uncertain_counts.csv)。

## 3. 主要失配已经定位到模板迁移，而非单纯的积分精度

2–5 kpc 的总体比例区间，在已知响应、同模板独立噪声对照中表现明显更好；换成独立校准模板到测试模板的迁移后，接近参考组成和普通矮星主导两组的覆盖分别降到 **1/12、0/12**。这支持“组内光度／SED 分布及其选择响应发生迁移”的解释。  
来源：[响应对照](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/response_controls.csv)。

扩大到 2,048 个校准源也没有自动消除差别。比如 `other` 参考组的 \(M_g\) 中央 95% 范围：

- 校准模板约为 **1.43–12.34 mag**；
- 测试模板约为 **2.51–8.66 mag**。

这不能直接说明哪边代表真实目标总体——测试端本身也只有少量独立源——但已经说明：**固定四个粗类别，再让每类内部的整套光度分布原样迁移，限制很大。** 多抽一些 bootstrap 不能创造缺失的物理支持，也不能自动修正参考选样。  
来源：[模板分布](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/template_shapes.csv)、[模板图](https://github.com/xiaoyunao/photdis/blob/b59e18b/figures/v2_6/08_template_color_luminosity.png)。

## 4. 光度校准还不能转成统一的距离修正

最新结果中：

- SpecDis 条件下，校准后的纯 grz 核预测 log score 改善约 **+0.0081**；
- SPDist 条件下，却变差约 **−0.0030**；
- 在相同贫金属评价对象上，新核校准后的平均 log score 仍低于冻结 QRF。

两个来源的 `poor_offset` 都接近 −0.15 mag，但按当前模型公式，它们对应的贫金属教师净距离调整约为 **+3.7% 和 +7.0%**。这不能拿来作为“把 QRF 偏远的贫金属距离缩短”的统一修正。  
来源：[光度变化](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/luminosity_changes.csv)、[同对象 QRF 比较](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/luminosity_QRF_same_objects.csv)、[校准参数](https://github.com/xiaoyunao/photdis/blob/b59e18b/manifests/v2_6/luminosity_parameters.csv)。

# 二、我建议的 v3.0 主架构

## 1. 采用一条明确主线：连续的经验 SED 前向模型

我建议以现在的经验模板基础为起点，建立：

> **参考观测约束绝对 SED 与光度分支；原生多波段观测产生逐星似然；目标总体先验决定分支与距离权重；共同校准和总体参数的不确定度进入逐星后验及目录统计。**

这一轮可以确定这个主方法方向。QRF 保留为固定基准；已有 XD32 及各阶段原型保留为历史对照。开发资源集中到这一套统一模型上。

前向关系可以写成：

\[
m_b^{\rm model}
=
M_b(\zeta;\phi)+\mu+A_b+\delta_b ,
\]

其中：

- \(\zeta\)：恒星的潜在 SED、光度分支、丰度等状态；
- \(\phi\)：光度关系、内禀散布和参考来源校准参数；
- \(\mu\)：连续距离模数；
- \(A_b\)：消光；
- \(\delta_b\)：测光系统项。

随后在**原生通量空间**比较模型和观测。目标的距离、类别、丰度分支可以不确定，也可以多峰。

这种前向似然、恒星模型与总体先验分层处理的路线已有成熟方法先例，例如 BRUTUS；Photdis 的具体实现应根据现有经验参考、Legacy 测光与目标科学问题来设计。:chatgpt-content-reference{index="0"}

## 2. v3.0 应当一次完成的结构变化

| 部分 | v3.0 的处理 |
|---|---|
| 距离 | 从五个固定节点改为连续距离模数的数值积分 |
| 测光观测 | 从硬观测格改为逐对象原生波段似然 |
| 光度分布 | 从四类固定整体分布改为能表达组内结构的经验 SED 模型 |
| 金属丰度 | 补齐中间丰度，作为可缺失、可边缘化的潜变量 |
| 参考距离 | 保留来源、误差与依赖关系，进入参考观测层 |
| 目标组成 | 与参考光度模型分开，允许随距离、天区和粗 SED 分组变化 |
| 不确定度 | 同时传播观测、参考尺度、有限参考源和总体参数不确定度 |
| 科学输出 | 连续多峰后验、类别×距离联合质量、目录人数及协方差 |
| 验证 | 本轮完成真实样本评价和一个实际应用示范 |

**五个距离节点和 270 个观测格可以保留为回归检查或压缩工具，但不再定义主科学模型。**

# 三、光度模型和参考数据：这是 v3.0 最值得投入的部分

## 1. 学习条件光度关系，并把模板位置和模板权重分开

我更倾向于采用**误差感知的局部经验核或模板混合**，表达同一颜色附近的多个光度分支。模板可以压缩，但压缩必须保留主序、巨星和低光度尾部的概率质量。

这里有两个不同任务：

- **光度关系**：在给定真实颜色、丰度或光度分支后，绝对星等如何分布。
- **总体组成**：某个目标天区中，各颜色、丰度、光度分支和距离出现多少。

参考目录的模板密度不能直接变成目标目录的固定先验。尤其是 v2.6 已经暴露出的组内迁移，不能只靠调整“四类各占多少”处理。

具体建议：

- 用参考数据约束光度分支的位置、宽度和相关性。
- 对组内 SED 组成引入有限、受约束的变化，例如少量颜色／SED 基函数与来源层次项。
- 对目标天区的权重进行正则化和跨天区收缩，避免每个模板权重都自由浮动。
- 对没有参考支持的区域明确标记外推，不用任意增加尾部权重制造“可解释性”。

**连续经验模型仍然依赖参考数据；它不会自动消除参考选样偏差。** 来源之间、天区之间、颜色范围之间的迁移验证仍是主验收内容。

## 2. 补齐中间金属丰度，不再让 `other` 承担所有未描述对象

至少需要处理这几类情况：

- 普通与贫金属矮星之间的中间丰度；
- 转折区、次巨星等光度过渡区域；
- 巨星参考组内部的颜色与光度变化；
- 低光度对象、未分辨双星及明显模型异常；
- 有距离信息、但没有可靠光谱类别或丰度的对象。

我建议优先使用连续丰度条件关系。若实现上先离散化，也应覆盖连续的丰度范围，并传播标签误差。

还要在数据结构中区分：

1. **缺少类别标签**：数据没有给出类别；
2. **类别无法确定**：测光后验支持多个类别；
3. **模型无法解释**：对象可能处于参考范围之外，或属于污染源。

这三者不能都塞进一个 `unknown/other` 标记。

应用阶段不需要输入评价对象的真实 FeH 或类别。它们应作为潜变量积分掉。对弱信息对象，允许输出“丰度或类别主要由先验决定”。

## 3. 参考源本身的测量误差必须进入训练

不要把

\[
M_g=g-\mu_{\rm teacher}
\]

算出来后，就当作没有误差的物理标签。

距离误差会同时移动所有绝对星等；共享波段会让颜色与绝对星等误差相关；消光和测光系统项也会造成相关偏移。v3.0 应在参考层处理这些误差，避免把测量散布全部学成真实光度宽度，再在目标推断时重复加入。

已有的共享 \(g\) 协方差修正和原生波段检查应直接保留。

## 4. 把 Gaia、SpecDis、SPDist 的角色正式写进参考模型

建议每个参考对象保留完整来源信息，而不仅是一个 `chosen_distance`：

- 原始 Gaia 视差、误差、零点及质量字段；
- 各 VAC 的距离或绝对星等摘要、误差、版本和资格；
- 光谱参数及其来源；
- 哪些信息参与了上游预测、筛选和训练。

Gaia 继续使用有符号观测似然：

\[
\hat\varpi_i
\sim
p\!\left(\hat\varpi_i\mid 1/d_i+z_i,\sigma_{\varpi,i},\ldots\right),
\]

其中单位须一致。弱、负视差都可以进入，不以求倒数制造距离标签。

VAC 的尺度偏移、额外散布和异常尾部，应与真实恒星的金属丰度—光度关系分别建模。最初用低维、受正则化约束的来源校准即可，不要让任意灵活的来源偏移函数吸收全部物理问题。

**若无法恢复多个参考来源的联合依赖，主分析可以为每个对象预先指定一条主要距离证据通道，其他来源用于敏感性与一致性比较。** 这比把几个共享信息的误差条按独立观测相乘更可靠，也不要求退回“点标签就是真值”。

官方说明中，SpecDis 从光谱预测距离；SPDist 使用 Gaia 测光及 DESI 光谱参数，因此来源间的独立性不能仅凭目录名称判断。:chatgpt-content-reference{index="1"}

## 5. 特别需要改：SpecDis 的 `BINARY_FLAG` 与 Gaia 选样依赖

这是这次核实到的一个具体问题。

仓库当前 SpecDis 准入要求 `BINARY_FLAG=1`。官方说明指出，这个双星标记利用了**神经网络预测绝对星等与该对象 Gaia 测光、视差得到的几何绝对星等之间的差异**。因此，先按这个标记筛出单星，再用 Gaia 残差做校准或 PIT 检查，已经条件化于一层使用了 Gaia 残差的选择。  
来源：[当前参考准入](https://github.com/xiaoyunao/photdis/blob/b59e18b/docs/v2_0_methods.md)。:chatgpt-content-reference{index="2"}

我建议 v3.0 这样处理：

- 保留现有 `flag=1` 结果，作为历史基线。
- 新建校准母样本时，保留必要的匹配、光谱质量和原生 PSF 条件，但不把这个标记当作与 Gaia 评价独立的准入条件。
- 将该标记用于事后分层诊断；剩余双星和异常对象由受约束的混合／重尾模型处理。
- 如必须限定 `flag=1`，就需要显式处理这层选择；若无法可靠复原，只能声明结果针对该条件参考子样本。

取消这层截断不意味着把所有对象当可靠单星。**参考观测的异常处理，与目标光度模型对未分辨双星分支的容纳，都要同时接入。**

# 四、多波段、连续距离、消光和观测范围一次统一

## 1. 以原生通量为统一输入，明确区分弱测量与缺测

建议主模型统一支持：

- grz；
- 可用的 \(i\)；
- 可用的 W1、W2。

有合法通量和误差的低信噪比、负通量观测，应通过观测似然使用。真正缺失的波段通过掩码处理；若只有上限，则使用相应的删失概率。

具体实现中应做到：

- 每个波段只使用一次原始观测信息；
- 缺测不填平均颜色，也不填零通量；
- WISE 混叠、伪迹等质量问题与低 SNR 分开处理；
- 不要求“所有对象都有好 WISE”才进入主样本；
- 多波段共同系统项与逐对象随机误差分开。

## 2. 南北测光系统要进入数据模型

DR11 官方说明是：新增数据位于南部 DECam 区域；北部使用 DR9 已包含数据的处理结果，且北部没有 \(i\) 波段。v3.0 应记录真实 survey、滤光片及处理版本，不能把北天当作缺一个波段的 DECam 数据直接套用。:chatgpt-content-reference{index="3"}

我建议：

- DECam 作为主产品范围先完整做好。
- 同一程序支持北天原生系统和相应校准接口。
- 北天是否进入正式科学范围，由参考覆盖和迁移验证决定。
- 当前既有天区与全部 DR11 的覆盖范围分别报告。

## 3. 距离必须连续，10 kpc 只用于评价和选样

距离模数可以采用自适应网格或其他稳定数值积分。需要自动检查：

- 主模式和次模式是否被解析；
- 近远尾部是否被截断；
- 边界质量是否需要扩展积分范围；
- 网格细化后模式权重和区间端点是否稳定。

**不要把后验截在 10 kpc。** 一颗星可能同时支持近端矮星和远端巨星解，截断远端分支会人为提高近端置信度。

建议统一输出这些距离范围的概率质量：

\[
0\!-\!2,\quad 2\!-\!5,\quad 5\!-\!10,\quad
10\!-\!20,\quad 20\!-\!50,\quad >50\ {\rm kpc}.
\]

它们是输出分箱，不是推断节点。

## 4. 消光和双星进入模型，但范围要收得住

v3.0 主科学范围可以继续保持高银纬、低消光。即使如此，也应传播消光不确定度，并检查近距离对象使用整条视线消光是否合适。

建议选择一个一致方案：

- 原始测光加消光潜变量；或
- 消光校正测光加相应误差传播。

不要同时重复校正，也不必在本轮用 grz 为每颗星自由拟合距离、消光和消光律全部参数。

未分辨双星至少需要有受约束的较亮光度分支或合理散布通道。精确求质量比可以后置；完全忽略它们对距离分支的影响则不适合留到以后。

# 五、老板提出的“可辨识信息”要变成一个固定验收模块

这一部分不能只靠看颜色图，也不能仅靠“后验更窄”判断模型更好。

我建议本轮完成一个范围固定的小实验，回答三个连续的问题：

1. 这些波段在当前误差条件下，包含多少已经能被利用的类别信息？
2. Photdis 是否表达出了这些信息？
3. 这些信息是否改善了距离后验？

## 1. 固定一个概率分类探针

可以复用已有概率分类器，作为信息探针；不用它硬分巨矮后再测距。

在同一批身份、同一数据划分、同一目标组成权重下比较：

- 基准：表观星等、天区、误差等变量，不使用颜色；
- 加入 grz 颜色；
- 在相同对象上再加入 \(i\)、W1、W2；
- Photdis 对距离积分后得到的类别概率。

主要看类别 log score、Brier score、概率可靠性，以及各类别单独的结果。

例如：

\[
G_B=
\left\langle
\log q_B(K)-\log q_{\rm base}(K)
\right\rangle .
\]

这个量可以说明：加入某些测光信息后，固定方法在未参与拟合的对象上获得了多少预测收益。

解释要准确：

- 探针有明显收益，说明数据里存在可利用信息。
- 在相同先验和评价条件下，探针明显优于 Photdis，提示 Photdis 的表达或校准仍有损失。
- 探针表现差，不能证明物理上没有任何信息。
- 不能把两个模型的分数比值称为“保留了百分之多少的信息”，也不能把它们直接当作精确互信息。

另外，**参考绝对星等图上的分离，不等于纯测光输入中的可辨识性**。评价时不能把用参考距离算出的 \(M_g\) 偷放进分类输入。

## 2. 波段收益必须在同对象上比较

建议至少分清：

- **v3 grz 与 QRF grz**：方法改变带来的收益；
- **v3 多波段与 v3 grz**：新增波段带来的收益；
- **固定参考先验与目标总体先验**：总体信息带来的收益。

然后在自然父样本中报告不同波段掩码的覆盖率和实际收益。共同样本上的提升，不能直接套到没有 WISE、WISE 很弱或参考标签缺失的暗端。

## 3. 把类别收益和距离收益接起来

同对象比较纯测光距离后验的 Gaia 观测预测：

\[
p(\hat\varpi_i\mid x_i)
=
\int p(\hat\varpi_i\mid d_i)\,
p(d_i\mid x_i)\,{\rm d}d_i .
\]

评价对象的 Gaia 视差不能同时进入其纯测光推断。

再在具有适当距离真值的模拟或独立尺度样本上，检查距离评分、覆盖和灾难尾部。这样才能区分“分类更确定”和“距离确实更有用”。

# 六、总体先验和 10 kpc 内巨矮人数应该怎样做

## 1. 目标总体先验允许变化，但控制自由度

当前共同距离倾斜加四类权重，可以升级为：

- 少量距离模数基函数；
- 粗光度分支各自的距离分布；
- 必要的组内 SED 权重调整；
- 天区之间的分层收缩。

这样可以表达类别与距离的相关性，又不会让每个小天区自由拟合大量不受约束的参数。

参考光度尺度应由参考证据锚定，不能让每个天区各自随意移动一套绝对星等关系。否则，距离分布变化、光度尺度变化和星族组成变化会互相替代。

## 2. 保留可重加权的基础产品

针对你后续的星流和银河晕研究，我建议同时保留：

1. **固定、明确参考先验下的逐星后验及重加权所需信息**；
2. **结合目标总体推断后的逐星后验**。

后续若要拟合某条星流的距离轨迹，可以使用第一套产品构造自己的科学似然，避免把已经加入平滑银河先验的后验再次当成独立似然。

需要保存的参考先验应覆盖实际要重加权的联合潜变量；只保存一个距离先验数值，未必足以调整星族分支。

同时必须说明：即使目标总体先验可替换，经验 SED 关系仍来自参考样本，不能把产品称为完全“无先验”的距离信息。

## 3. 直接计算类别×距离联合人数

对每颗星保存：

\[
Q_{ik}^{<10}
=
P(d_i<10\,{\rm kpc},K_i=k\mid D).
\]

目录中某类近端对象的期望人数为：

\[
E[N_{k,<10}\mid D]
=
\sum_i Q_{ik}^{<10}.
\]

如果使用分层抽样代表母样本，再加入对应设计权重，并传播抽样不确定度。

这里不能用

\[
P(K_i=k)\,P(d_i<10)
\]

代替联合概率。近端矮星与远端巨星的退化，恰恰使二者相关。

**给老板的最终表，应当至少包括：**

| 结果 | 需要报告的内容 |
|---|---|
| 全部合格父样本 | 实际对象数、天区、可用波段、参考支持 |
| 10 kpc 内 | 总人数、矮星人数、巨星人数及其他分支贡献 |
| 距离分层 | 0–2、2–5、5–10 kpc 的上述结果 |
| 高近端概率子样本 | 选中数量、模型预期远端泄漏、近端保留率 |
| 10–50 kpc | 分距离范围的数量、分支组成和支持程度 |
| 不确定性 | 人数区间、类别与距离格之间的协方差、先验敏感性 |

“模型预期污染率”与“在独立样本上实测的污染率”要分列。当前参考样本里得到的污染率不能直接当作真实应用的保证。

## 4. 继续保留共享参数带来的相关性

v2.6 已经做对了这一点，v3.0 要扩展到光度校准和测光系统项。

例如人数方差可以分解为：

\[
\operatorname{Var}(N_B\mid D)
=
E_\Theta\!\left[\sum_i r_{iB}(1-r_{iB})\right]
+
\operatorname{Var}_\Theta\!\left[\sum_i r_{iB}\right].
\]

第二项就是共享总体和校准参数带来的额外不确定度。样本变成几百万颗后，这部分不能因为逐星平均而消失。

还要区分两种科学目标：

- 观测目录中有多少近端巨星、矮星；
- 银河系本征空间密度是多少。

后者还需要有效面积、探测和形态选择等信息。v3.0 可以先把第一件事完整做成，并为第二件事准备选择接口；不必把完整银河密度恢复设为本轮完成的前提。

# 七、验证在这一轮完成，预留样本要有明确开启时间

## 1. 数据角色一次定义清楚

建议统一维护以下角色：

- 光度模型训练；
- 来源尺度和散布校准；
- 模型／超参数选择；
- 已经看过的 development 诊断；
- 最终未查看的真实验证。

同一颗星的多个目录记录、多个参考来源、距离平移和噪声副本属于同一角色。复用对照组也要整体隔离。

所有新科学样本继续严格要求**核实原生 `TYPE=PSF`**；缺失或未核实者不进入新模型。历史例外只服务冻结基线比较。

## 2. 验证分成四层，并由同一套程序运行

| 验证层 | 核心目的 |
|---|---|
| 已知模型与数值检查 | 检查归一化、连续积分、多峰、选择处理和共享参数传播 |
| 独立经验 SED 迁移 | 检查跨参考源、跨颜色／丰度／天区的迁移 |
| 真实 Gaia 观测预测 | 检查纯测光后验对有符号视差观测的预测 |
| 独立距离尺度 | 检查真实距离尺度、区间和科学应用 |

模拟部分应加入：

- 不落在旧五节点上的连续距离；
- 中间金属丰度；
- 类别与距离相关的组成；
- 窄距离峰或子结构；
- 双星、缺测、弱 WISE、消光和测光系统扰动。

保持已有 known-response、same-template 和 independent-transfer 对照作为回归检查即可。新增真实源比继续复制同一套噪声更重要：现有 24,576 个模拟观测仍只依赖 **224 个独立测试 SED**。  
来源：[v2.6 样本与限制](https://github.com/xiaoyunao/photdis/blob/b59e18b/docs/v2_6_result.md)。

## 3. 3250 个预留身份在本轮方法冻结后正式打开

我的建议是明确安排：

> 完成模型、主要先验、输出格式和主评价指标的冻结后，在本次 v3.0 工作内一次性评价预留 3250 个对象。

不需要等所有开发诊断都完美才开始真实评价。

但这批对象仍来自原有 13 个场，且历史参考排除可能涉及 Gaia 条件。它们代表的是已定义的预留子总体，不能被包装成全天区随机验证。  
来源：[预留样本定义](https://github.com/xiaoyunao/photdis/blob/b59e18b/docs/v2_5_result.md)。

同时建议加入一个更直接的真实验证层：从未用于开发的天空块，先按测光条件和身份随机顺序确定对象，再关联参考；保留没有参考的对象及缺失原因。这样可以评价参考可获得性，而不会只留下“有好距离标签”的对象。

已有星团、星流或其他独立尺度可以加入，不需要把某个指定星团或固定成员数设为所有工作完成的前置条件。

## 4. 验收同时看准确性、概率校准和可用性

主结果至少包括：

- 距离偏差、NMAD、灾难错误；
- 完整后验评分；
- 68%／95% 区间及宽度；
- 两侧 PIT 尾部；
- 类别概率可靠性；
- 距离人数和类别人数恢复；
- 天区、星等、颜色、参考来源和波段掩码分层；
- 先验敏感性与支持范围。

2–5 kpc、红端、贫金属和 `other` 混淆这些已知问题必须固定出现在主评价里。

数值验收则可以预先设定起始容差，例如：关键近端概率细化后变化小于约 0.005，人数抽样误差明显小于后验标准差。具体容差在开发阶段确认并冻结，不能靠无限增加积分点代替科学误差评估。

# 八、工程和产品也在这一轮收整，避免继续积累平行脚本

## 1. 建立一个统一工作流

建议把现有版本脚本中的核心功能收成：

**数据构造 → 参考校准 → SED 拟合 → 逐星推断 → 总体推断 → 验证 → 产品输出。**

各环节共用：

- 数据角色和身份登记；
- 波段、质量及选择定义；
- 距离和类别积分实现；
- 模型、参考与先验版本；
- 统计和画图入口。

不要再让不同脚本各自实现一套略有差异的距离积分、颜色误差或类别统计。

## 2. 大目录计算需要专门设计

当前 128 对象原型不能原样扩大到百万级目录。

建议：

- 分块计算，缓存可复用的逐星似然表示；
- 模板压缩和候选筛选要检查是否漏掉次峰；
- 在固定诊断子集上比较压缩计算与更完整计算；
- 人数均值和协方差尽量解析累加，抽样主要用于复杂区间；
- 所有分块共享全局校准／总体抽样索引；
- 响应或校准样本数由收敛决定，不固定认为 16 个就足够；
- 先在代表性样本上测算运行时间、内存和输出量，再在本轮内扩展至既有天区的合格母样本。

两处具体代码问题可以顺手清理：

- `latent_counts()` 目前使用 `int16`，大目录人数应改为 `int64`。
- 响应边缘化后的 `marginal_half_delta` 应直接衡量最终联合边缘结果的误差，避免由某个低权重、少抽样响应的条件最大差主导。

来源：[人数抽样实现](https://github.com/xiaoyunao/photdis/blob/b59e18b/src/photdis/population_v2_6.py)、[当前边缘化诊断](https://github.com/xiaoyunao/photdis/blob/b59e18b/scripts/v2_6_population.py)。

## 3. 产品不能只有三个距离分位数

逐星至少保存：

- 精确源身份、原生测光系统和波段掩码；
- 距离分位数；
- 主要模式位置与概率质量；
- 类别×距离联合质量；
- \(P(d<10\,{\rm kpc})\) 及远端分箱概率；
- 可重加权的联合后验样本或可靠压缩表示；
- 参考先验及必要的重加权信息；
- 模型支持、外推、多峰和先验敏感性标志；
- 模型、校准和先验版本。

另保存共享总体／系统参数抽样，以便恢复目录相关性。

一个近端矮星峰加一个远端巨星峰的对象，单独的 \(d_{50}\) 可能落在低概率区。这样的对象依然可以服务边缘化分析，但不适合被当作一个精确点距离。

# 九、建议给 Codex 的一次性执行顺序

可以把下面六个阶段放进**同一个 v3.0 任务**。阶段是内部里程碑，常规实现和数值问题在范围内继续修复，不必每完成一项就结束整轮。

| 阶段 | 主要工作 | 完成标志 |
|---|---|---|
| **A. 统一数据与证据** | 原生 PSF、身份、数据角色、参考依赖、完整丰度和波段信息 | 每个对象的准入、来源、用途可追溯 |
| **B. 完成连续前向核心** | 经验 SED、多峰、连续距离、原生通量、缺测、消光和异常通道 | 同一接口能输出完整逐星联合后验 |
| **C. 接入校准与总体推断** | 来源尺度、有限参考不确定度、目标组成、共享参数 | 逐星和目录统计来自同一个联合模型 |
| **D. 完成固定开发评价** | 同对象 QRF 比较、波段消融、信息探针、连续模拟、迁移检查 | 清楚区分方法、波段和先验带来的收益 |
| **E. 冻结并评价真实样本** | 打开预留样本，加入新天空或独立尺度验证 | 得到适用域及通过／受限／未验证结论 |
| **F. 形成 v3.0 产品** | 既有天区候选目录、近远端统计、科学示范、核心图表 | 可以直接进入论文结果组织与后续精修 |

这一轮应当完成 A–F 的整条链。若某个范围科学表现不佳，保留失败结果、限制对应科学主张，仍然交付完整的 v3.0 研究版本。

可以留到之后精修的内容包括：精细银河结构参数、稀有星族专用模型、双星质量比分布、多种三维消光图的全面比较，以及所有暗端和远端都达到相同精度。这些不必阻塞主系统。

# 十、做到什么程度，才会真正接近论文

我认为 v3.0 最有价值的论文主张可以是：

> 在 Legacy 多波段测光中，定量识别不同恒星光度分支的可辨识范围，在参考来源和目标组成不一致的条件下提供可校准的多峰距离后验，并验证它对近端样本组成及更远距离统计的科学用途。

这个主张同时容纳老板的两个重点，也保留你的远距离方向。

为此，v3.0 最终需要交出三组实质证据：

1. **10 kpc 内的可用范围与数量。**  
   明确多少对象有参考支持，巨矮联合人数及不确定度是多少，哪些类别或颜色仍然失配。

2. **10–50 kpc 的独立结果。**  
   展示哪些光度分支、波段条件和参考来源支持远端推断；证据不足的范围保留完整概率并标明状态。

3. **一个真实科学示范。**  
   选择已有足够数据的系统或天区，展示边缘化如何恢复距离分布、处理前景混淆或保持子结构信号。曾用于校准的系统可以做展示，但不再计为独立验证。

**当前最主要的差距，已经从“有没有概率推断模块”转到了“光度与参考模型能否迁移，以及真实数据是否支持所声明的用途”。** v2.6 为这次整体开发提供了可靠起点。按上述范围完成后，下一次审查就可以围绕一套完整的 v3.0 结果判断主论文范围，并把剩余问题分成局部修正、受限适用域和确实需要新数据的部分。
