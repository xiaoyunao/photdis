# Photdis v3.17 · GD-1 成员与主序信号

这一轮先检验北天 LS 能在什么程度上看到 GD-1。沿用 v3.16
的六个角段、三个视星等层和归档 QRF。成员恢复、主序超额和
测距是三项不同的检验。

## 外部成员与参考尺度

Jarvis 等的 Zenodo v3 与 v4 压缩包均按发布方 MD5 校验。
两版本的 Table 1、修正后的 Table 3 和 Figure 3 等时线文件完全
相同。采用 v3 的 Table 3，并以 v3 的全精度 Table 7/8 坐标
做位置关联。v4 成员位置只有 0.001° 精度，用它直接做 1″
匹配会丢失一部分已经由 Gaia ID 确认的对象。两版本的成员 ID
集合相同，按 ID 使用 v4 的更新概率。六段内 161 个共享的
DESI/Gaia+PS1 身份在全精度坐标上的中位角距是 0.006″，95%
分位是 0.067″。DESI 组按公开的
后验概率分类，\(p_\mathrm{thin}>0.5\) 为窄流，
\(p_\mathrm{cocoon}>0.5\) 为宽包层；两者相加大于 0.5
但各自未过阈值时记为混合。Table 8 的 BHB 单列。
DESI 的光谱样本带天区、测光和运动学选样，计数描述的是
这个有外部证据的样本，不直接代表整个 LS 背景的污染率。
[DESI 论文](https://arxiv.org/abs/2604.20958) ·
[Zenodo v3](https://zenodo.org/records/19889980) ·
[Zenodo v4](https://zenodo.org/records/23599156)

另用 Tavangar 与 Price-Whelan 的 Gaia DR3、PS1 及可用运动学
信息模型样本，要求公开成员概率至少 0.9。其发布的沿流经度
与本项目坐标存在约 0.253° 的零点差，按 ICRS 坐标重新计算后
再做分段。这组成员可与 DESI 交叉核对；其中共享身份保持
可追踪，概率模型本身也用到测光和部分光谱资料。
[Gaia DR3 成员模型与数据](https://arxiv.org/abs/2502.13236) ·
[Gaia 样本归档](https://doi.org/10.5281/zenodo.15428120)

原生关联在 1″ 内优先选择唯一的相同 Gaia DR3 身份，其次
采用无 Gaia 身份冲突的唯一位置匹配。多解、身份冲突和无
匹配分别记账。原生形态、测光门槛、档案是否有 QRF，以及
是否进入当前条带实验逐级统计。非 PSF 仅进入形态排除账目。
同角位置的距离附表列出 Jarvis Figure 2 的曲线及 Table 1 的
线性插值、CFHT 以及 SDSS。BHB 是按恒星种类估距的尺度检查，
与经验主序曲线分开评述。各测光曲线的系统误差相关结构未知。
[原 CFHT 距离](https://doi.org/10.1093/mnras/sty677) ·
[原 SDSS 轨迹](https://arxiv.org/abs/0907.1085)

## 检测与背景设计

先逐源重建 v3.16 的全部合格原生点源，并与归档的 QRF 支持
身份逐一核对。旧配置使用 Koposov 天空轨迹及 0.8°–2.45° 侧带。
新配置把中心线替换为修正后的 DESI 轨迹，以 ±4.8° 与 ±5.8°
作远侧带，±6.8° 与 ±7.8° 作不参与背景估计的空白带。条带宽度
和原生测光门槛沿用 v3.16。面积按角段、侧带及星等上界取 DR11
随机面积，仍保留各层的深度差。旧、新配置同时改变中心和
侧带，二者差异描述实际分析方案的变化。

三层分别计算背景扣除后的二维 CMD 数密度。绝对星等使用
公布的 DESI 距离曲线对齐，主序检验使用 Jarvis Figure 3
给出的经验脊线和固定颜色半宽 0.10 mag，限制在
\(3.5\le M_r\le7.0\)。这里是在给定参考距离上探测等时线附近
的信号；预测的距离未用于挑选测光源。Figure 3 的 13 Gyr、
[Fe/H] = −2.08 Dotter 等时线另作物理对照来源，论文展示了它
和观测脊线的差别。北天原生和参考颜色的系统差异仍可能
影响窗口边缘的完备率。
[Jarvis 等的 CMD 定义](https://arxiv.org/html/2604.20958v1)

以两侧面积加权背景密度作线性横向插值，并查看各空白带的
标准化残差。要求两侧均有独立空白带，主序超额达到 3 倍计数
误差，且高于所有空白带的标准化偏差绝对值。该条件用于决定
是否需要解锁下一步距离拟合。空白带与目标共用背景估计，
分数只提供条件对照。累计 \(r<22\) 的全部原生样本需在冻结的
探索段至少 1 段、独立验证段至少 2 段通过；用于估计梯度时再
要求多个可靠距离峰。任何一项达不到都报告实际结果。
[预先固定的门槛](../configs/v3_17_gd1.json)

## 主序检测结果

六段的 163 颗 DESI 窄流成员、128 颗宽包层成员及 554 颗
Gaia+PS1 候选均按 Gaia ID 找到 DR11 原生 PSF。严格测光
质量保留 151、108 和 498 颗。通过质量的窄流与宽包层成员
分别有 15 和 6 颗落在 20–21 等，21–22 等两组均为零。
Gaia+PS1 候选在 20–21 等有 72 颗，21–22 等仅 1 颗。
最暗层的证据主要来自背景控制后的统计超额。原生 PSF 和
位置回查的保留率只约束这些外部参考，受参考目录本身的深度限制。
所有外部身份附近 0.04° 内均有北天随机点见到 grz 成像。
该局部覆盖代理保留与逐源匹配分开的台账。
[逐源回查](../manifests/v3_17/members_precise/members.csv) ·
[分段与条带](../manifests/v3_17/members_precise/retention.csv) ·
[成像覆盖](../manifests/v3_17/delivery_precise/member_summary.csv)

光谱成员的位置检查显示，旧的八条近侧带含 5 颗窄流成员和
72 颗宽包层成员。新方案的四条远侧带内有 5 颗宽包层成员，
没有概率超过阈值的窄流成员。这些数是 DESI 已发表成员在各
几何条带内的计数，条带总面积和光谱靶选覆盖不同。施加所有
原生实验条件后，宽包层仍在旧、新背景中分别保留 62 和 5 颗。

原配置逐源复现 175,328 个合格原生 PSF 及 142,098 个 QRF
共同源，后者的身份与 v3.16 逐一相同。修正轨迹加远侧带的
方案有 171,638 个原生源和 139,184 个 QRF 支持源。新方案
目标带三层源数依次为 8,766、4,524、6,904，QRF 保留
94.1%、80.6%、65.1%。只比较参考主序窗时，三层保留率为
92.5%、88.6%、81.3%，支持率损失随星等与 CMD 位置变化。

| 沿流中心 | 全原生累计条件分数 | 独立空白带最大绝对分数 | QRF 共同源累计条件分数 |
|---|---:|---:|---:|
| −32.5° | 5.20 | 1.38 | 5.07 |
| −27.5° | 5.30 | 2.04 | 5.29 |
| −12.5° | 3.13 | 2.87 | 3.14 |

全原生样本在这三段通过，−32.5° 与 −12.5° 是预先固定的
验证段。QRF 共同样本的 −12.5° 条件分数相近，但空白带最大
绝对分数升至 3.24，该段未通过。单独使用 21–22 等时，只有
−32.5° 一段通过，两种样本都能看见这段暗端超额。−27.5°
在最暗层的空白带波动大于目标，不能把累积显著性归给该层。
旧配置也有三段累计分数超过 3，但其近侧带均用于背景估计，
缺少新配置的独立空白对照。仅比较条件分数无法把变化单独
归因于宽包层污染。

## 过检测门槛后的距离对照

冻结的探索段 −27.5°、验证段 −32.5° 和 −12.5° 进入局部
距离检验。三段均使用修正后的天空轨迹、远背景带、相同的
原生测光筛选、原始 QRF 距离 PDF 和原 M13/M92 模板。
另外用 Jarvis Figure 3 的 Dotter 13 Gyr、[Fe/H] = −2.08
主序模型构造物理对照。其星等权重取自冻结的 M92 光度分布，
颜色取自公开等时线，未用三个 GD-1 角段校准。各模板在
5–14 kpc 内搜索，并考虑各观测星等层的有效窗口。评估既
包括与 QRF 同源的 CMD，也包括无需 QRF 支持的纯 CMD；
正式比较使用两段验证，探索段单列。

距离拟合阶段不会读取三个参考轨迹的距离，评分才使用它们。
进入距离实验的区间此前用 DESI 参考脊线检出，因而验证是
分段独立的流程检查，仍有基于文献尺度的检测选择。
仅有两个验证段可检验局部尺度；两端差除以角距离作为诊断，
预先要求至少三个可信验证距离峰才评价连续梯度恢复。

| 验证段 | DESI / CFHT / SDSS（kpc） | 同源 QRF 峰 | 同源 M13 / M92 / Dotter 峰 |
|---|---:|---:|---:|
| −32.5° | 7.65 / 8.78 / 8.05 | 10.125，偏远 32.3%（相对 DESI） | 8.125 / 8.125 / 8.125，均通过背景且在三标尺的 10% 内 |
| −12.5° | 8.78 / 9.63 / 9.07 | 12.125，未通过背景 | 9.375 / 9.375 / 9.125，均未通过背景 |

在全部原生源上，−32.5° 的 M13 与 M92 峰保持 8.125 kpc，
Dotter 峰为 7.875 kpc。这三个峰都超过背景门槛。Dotter 峰
在 DESI 和 SDSS 的 10% 内，相比 CFHT 偏近 10.3%。因此，
等时线参考能提供局部距离，但这次比较也真实受外部标尺差异
影响。−12.5° 的三个全原生 CMD 峰都为 9.625 kpc，最大
条件分数只有 1.78，且低于各自最强空白带。不能把这个与
CFHT 接近的候选峰计入距离验收。

已过固定主序检测的两段验证，最终只得到一段可靠 CMD 距离。
所有候选两端斜率的空间抽样区间都含零。GD-1 的沿流梯度仍待
验证，暂将现有结果用于局部 CMD 距离与纯测光信息量的讨论。

## 复现

在本机下载发布版压缩包与 Gaia MRT 后，用
`scripts/v3_17_references.py` 核验 MD5 并提取本轮用到的表，
将小型输入传到 NERSC 的 `data/v3_17/input/`。用
`scripts/run_v3_17.sh` 依次提交 `sample`、`members`、
`hess`、过门槛后提交 `distance`，最后 `delivery`。
全量原生逐源表和原长度的 Gaia 下载文件分别留在计算端与本机
下载目录。两张英文 Hess 图使用 v3.8 锁定样式。计算过程中
修复了原生成员回查缺少生产误差阈值的问题，并在同一关联半径
下改为只读取候选附近的原生行。两次试运行的日志和中间结果留在
计算端，最后验收使用全精度坐标产物。已有 v3.16 产物完整保留。
正式 NERSC 作业 61458202、61458501、61458711、61459081、
61459107 均正常完成，476 项回归测试通过。
