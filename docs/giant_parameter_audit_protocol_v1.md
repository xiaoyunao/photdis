1. 复用既有159关联系统、完全相同DESI可靠巨星条件，断言恰为120条光谱；按Gaia身份去重，最高SN_R行作展示，同时保留全部合格光谱行及原8颗K身份。不得扩展141个无DESI系统。
2. 导出TEFF/LOGG及误差、RV/误差、原始质量量、TARGETID/REF_ID、Gaia坐标/自行/星等、原始及适用域内校正丰度；阶段未知保留未知。只为这些身份定向读DR11，保留每种原生系统与唯一匹配/歧义，grz和W1资格独立。记录成员概率而不把成员概率代替类型。
3. 补Pal14固定源的Jordi2009 star1坐标/RV/成员与Caliskan2012参数及方法来源，计算位置分离，核对Gaia/DESI/DECam链及各测光体系；只做一颗星的图像/模型/残差审计。不同通带星等不能直接相减当零点。若做MIST有限检查，明确模型、AV=0、质量及太阳常数，不产生新的真值或修正。
4. 预定义描述性覆盖口径：以已冻结190目标中189个有效SPECDIS对象为光度/颜色参考，分别计算(g-r,r-z)、Mg、r的5–95%逐维盒；丰度用该层有效校正FeH的5–95%范围。报告各维及其交集，不把盒内等同联合流形支持，不以该盒筛选评分。报告原8颗K与窗外、冷于4200/暖于5000、原生系统、grz/W1、低消光/高银纬、历史系统角色的不同分母。
5. 历史角色分开登记：NGC5272/5024为RGB训练，NGC7006曾测试后开发，NGC5466/4147已检验/揭盲，NGC2419历史北方审计；其他在本通道首次盘点不等于项目全局未触碰。不得称新的最终测试集。
6. 保存完整去重表/原始光谱行/分层统计/覆盖图，判断窗外是否补充光度、颜色和丰度资源。无适当覆盖也有效；结束于本固定集合交付，不追求第三系统，不给窗外对象新距离。
7. 修正文案为已评估DESI通道（18/159系统）不足；说明Pal14参考CDF、宽分布与小参照误差不构成高显著模型失败；统一零点应写现有证据不支持估计或采用。历史数字及全部残差保留。
8. NERSC分配CPU执行，断言原8身份/测光不变、120行计数与逐系统原汇总一致、唯一身份及全部光度覆盖状态，核验22预测哈希不变。报告、证据、图、WORKLOG/PLAN/AGENTS及三端提交完成即结项。
