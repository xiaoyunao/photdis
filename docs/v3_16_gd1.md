# Photdis v3.16 · GD-1

本轮在真实的稀疏银晕恒星流上检验三种纯测光方法。问题是，北天
Legacy Surveys 的原生测光能否恢复 GD-1 的距离尺度和沿流变化，
以及增加 20–21、21–22 等的测光是否改善结果。

## 数据和实验设计

采用 Koposov 等（2010）的 ICRS 旋转矩阵与表 2 的天空轨迹。
在看到 LS 距离结果之前，固定六个互不重叠的 5° 区间，范围为
\(-40^\circ\le\phi_1<-10^\circ\)。目标区沿天空轨迹左右各 0.25°，
另外沿同一轨迹偏移 ±0.80°、±1.35°、±1.90°、±2.45°，形成八条
等宽背景带。对照带也轮流作为假目标，估计前景梯度和背景结构
能产生多大的假信号。靠近已知支流的背景信号也会进入这个比较。
[Koposov 等 2010](https://arxiv.org/abs/0907.1085) ·
[固定参数](../configs/v3_16_gd1.json)

限定北天原生 BASS/MzLS、\(b>30^\circ\)、\(E(B-V)<0.03\)。
从 DR11 随机表计算每个 1° 角块、横向带和视星等层的有效面积。
深度条件用代表色 \(g-r=0.6\)、\(r-z=0.2\) 的点源在该层上边界
达到 0.10 mag 理论误差定义；这是覆盖代理量。每颗星另有实际
三波段误差 <0.10 mag、原生 TYPE=PSF、拥挤代理和质量标志要求。
收集三层 \(r<20\)、\(20\le r<21\)、\(21\le r<22\)，分别拟合，
也报告累积加深结果。仅使用现有北天 QRF 有归档 PDF、且不属于
该模型训练或校准身份的对象。通过同一套目标区、背景区、颜色和
测光资格筛选后，将这批源同时交给三种方法。
六段均满足覆盖条件，最深层目标有效面积每段约 2.46–2.53 平方度。
在颜色、面积和质量条件下，共有 175,328 颗候选源，其中 142,098
颗有可复用的 QRF 后验，占 81.0%，构成三种方法的共同样本。
[覆盖与深度](../manifests/v3_16/footprint/area.csv) ·
[入选台账](../manifests/v3_16/sample/admission.csv)

三种方法用同一批原生源和相同的背景面积归一化。冻结 QRF 将
原有逐星 PDF 重新积分到 0.25 kpc 距离格，取带符号超额的峰。
传统 CMD 用 M13 高概率成员构造 \((g-r)_0,r_0\) 模板。深模板
采用 M92 原生低拥挤目标减背景 CMD，保留较暗主序。M92 的暗端
模板是统计星团超额，其中包含通过质量条件的星团掩膜区测光。
它的校准距离和模板样本来自已有归档。两个 CMD 在同样距离格
上移动模板，按目标与背景方差加权估计条件分数。各视星等层
保有各自曝光面积。按实测消光分布对模板应用观测星等截断，使
模板只在对应的视星等层参与归一化。两个 CMD 对照同时改变了模板星族与模板
深度，累积深度差分则在同一个模板内改变源的星等范围。

所有方法报告目标最大峰、背景带最大峰及近似条件分数。把
目标峰分数达到 3 且高于各可用假目标视为通过背景对照。这个
定义适合筛选结果；背景带共用部分数据，数量有限，无法从中
估计精确的全局假警报概率。分段距离和配对深度变化采用 256
次空间块重抽样。每个 5° 段重抽其中五个 1° 角块，三种方法和
不同深度在该段共用空间抽样，不同段独立抽样。区间未传播
光度零点、消光、模板年龄和金属丰度引入的系统误差。

## 参考距离的含义

主评分使用 de Boer 等（2018）表 1 的 CFHT/MegaCam 主序测光
距离。Koposov 等（2010）的 SDSS 拟合距离提供第二个光度尺度，
以分段中心线性插值，只用于查看零点对照。CFHT 与 SDSS 的星族
模型和光度校准假设可能造成共同或不同的偏差。标准烛光方面，
Dillamore 等（2022）用候选 BHB 与 RR Lyrae 交叉检查另一条
PS1/Gaia 测光轨迹，文献报告平均差小于 0.5 kpc。本轮没有逐段
的独立几何或标准烛光距离，10% 指相对 CFHT 参考尺度的验收。
CFHT 和 SDSS 距离表只进入评分程序。
[CFHT 测光距离](https://doi.org/10.1093/mnras/sty677) ·
[SDSS 测光距离](https://arxiv.org/abs/0907.1085) ·
[标准烛光交叉检验](https://arxiv.org/abs/2205.13547)

## 结果

三种方法均未同时恢复 GD-1 的分段距离与沿流梯度。累积到
\(r<22\) 后，结果如下。平均绝对偏差与斜率列均使用六段中全部
候选峰，因此也是评估假峰风险的诊断值。只有在同时满足背景
对照与 10% 标尺条件时，才计入最后一列。

| 方法 | 通过背景对照 | 平均绝对距离偏差 | 斜率（kpc/°，空间抽样中央 95%） | 同时通过两项 |
|---|---:|---:|---:|---:|
| 冻结 QRF | 4/6 | 30.6% | −0.074 [−0.142, +0.098] | 0/6 |
| M13 CMD | 1/6 | 19.7% | −0.003 [−0.075, +0.094] | 1/6 |
| M92 深 CMD | 1/6 | 20.2% | −0.010 [−0.077, +0.111] | 1/6 |

CFHT 六段斜率为 **+0.045 kpc/°**。各 LS 斜率区间均跨零。
在 \(\phi_1=-27.5^\circ\) 的同一段，CFHT 距离为 8.46 kpc，
M13 和 M92 模板分别给出 7.875 和 7.625 kpc，且均通过背景
对照。QRF 在这一段的峰是 10.875 kpc，条件分数 4.92，
尺度偏远 28.5%。QRF 其余三个通过背景的峰也都偏远超过 10%。
在另外两段，移开的背景带产生了比目标更强的 QRF 峰。
因此，沿流超额的存在和超额峰所在的距离需要分别检验。
[分段距离](../manifests/v3_16/score_supported/distance.csv) ·
[背景带](../manifests/v3_16/fit_supported/controls.csv) ·

### 暗端增加了部分 QRF 信号，距离仍无稳定增益

向 \(r<20\) 样本加入 20–21 等源后，QRF 通过背景的段数从
1 增至 3，继续加入 21–22 等后增至 4。两种 CMD 的段数从 0
增至 1，加入 21–22 等源后仍是 1。只用 21–22 等时，三种方法
均无一段通过背景对照。暗端扩展后的配对距离误差变化区间
均跨零。以 M13 为例，从 \(r<21\) 加深到 \(r<22\)，平均绝对
相对误差的配对变化中央 95% 区间为 **−7.3 到 +1.6 个百分点**。
在 \(r<22\) 上以 M92 替换 M13，变化区间 **−5.3 到 +5.0 个
百分点**，两者识别出同一段。这里的区间用同段配对空间重抽样
和文献各段的标称误差，未加入互相关的参考标尺系统误差。
[斜率与通过率](../manifests/v3_16/score_supported/gradient.csv) ·
[深度及模板配对变化](../manifests/v3_16/score_supported/depth.csv)

M92 模板在 \(M_r\ge6\) 的归一化质量为 18.3%，M13 为 17.9%。
这次使用的 M92 深端约束只略多，最暗处来自统计超额。结果
说明这两套实际可用模板的差别不足以改变 GD-1 的验收，后续
需要用独立深测光确认主序模板及其光度函数。共同样本还限定于
QRF 已有支持的区域，CMD 在 QRF 支持外可能利用的测光信息
不在这次结论内。

## 决策与复现

目前保持 GD-1 为验证对象。扩到更远恒星流之前，先用独立成员
核验可达到的主序深度，再用等面积、多条独立背景区验证在较暗
源中有无真实主序超额。QRF 在已确认贫金属矮星上的证据仍有
单独价值。当前的恒星流结果支持保留旧目录和模型。

入口为 `scripts/run_v3_16.sh`。在 NERSC 分别执行
`gd1 coverage`、`sample`、`fit` 和 `score`。逐源文件、原始
覆盖与中间空间抽样方案保留在
`/pscratch/sd/y/yunao/photdis_pipeline/data/v3_16/`。正式拟合与
评分目录为 `fit_supported` 和 `score_supported`。独立段重抽样
之后修正了 CMD 星等层的有效支持。该修改保持源、QRF 结果与
原有验收规则。绘图采用共用 v3.8 样式，图中空心点表示未通过
背景对照的候选峰。
NERSC 覆盖、逐源联结、最终拟合与评分均正常结束。474 项本地
测试与交付哈希核验通过。
