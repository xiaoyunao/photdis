# baseline v1：分支、数值与深度的固定对照

2026-11-03。基线494b12c，完整需求见[Pro评审](pro_review_494b12c.md)。保留v0全部代码、模型和产物；新产物只写data/baseline_v1。沿用14场入口、身份、空间切分、标签优先级和训练精度，不扩大星团或模型族搜索。

## 1. 数值传播

从各DECam母表按光学误差四档、最高可用A/B/C及v0支持/多解状态固定抽取最多20个每格，合并后固定最多3000颗（若超过按确定性身份随机顺序截取），抽样不使用距离残差。对可用模型比较原IID 8/32/128次及随机数字移位Sobol 32/128次，参考为独立数字移位Sobol512次。每个源、波段和draw索引固定，跨模型/分块共用扰动；量化采用箱内CDF线性反演。

分低误差(<.03)和其余层，在合并可用模型中，选择32或128 Sobol：对参考的95百分位绝对差，95%下端/中位/上端分别≤.10/.03/.10mag，且多解状态变化≤5%。不合格时使用128并标记该误差层未收敛，不继续搜索；输出两独立移位的128差异。固定光度、sigma_g=.2解析反例比较8/32/128 IID及Sobol，明确它不是实际目录覆盖率。

## 2. 光度分支

先对v0全部有距离参照的演化/过渡对象测量参考Mg±.5mag质量、参考CDF及中位严重错误，包含未触发多峰标志者。新增同一QRF族的dwarf/evolved/transition条件模型，参数与v0一致，训练身份只来自原train且类别可靠。类别未知的约43%训练对象保留在冻结宽QRF中。

每组训练一个固定二次颜色logistic门控（标准化仅train；C=1；不搜索）。部署只用颜色及模型状态。自然训练比例门控与除以训练类别比例的等比例敏感性各一套，后者不解释为银河类别概率。宽模型叶内未知标签权重u保留为回退；其余权重分给三个条件分布。某分支名义颜色支持不足或训练不足100时，该权重转回宽分布。对同一次测光扰动，先组合分支再变换共享g，避免独立积分门控和光度分布。

保存三种部署候选：数值修订wide、natural混合、balanced敏感性。另用已知正确粗类别得到oracle诊断，不纳入部署成绩。A/B/C及A_on_B/A_on_C/B_on_C使用v0相应冻结训练身份；同星对照仍保持相同训练/测试身份和扰动。类内模型支持与错误率逐类报告。

## 3. 选择和研究质量层

仅cal比较候选：宏平均各粗类别|Δμ|>1（每类至少30）的下降为主；同时矮星和整体尾率较wide不得上升超过2百分点，整体median|Δμ|不得增大>.05mag。未通过则保留wide。每个波段配置分别作同一规则；B/A及C/已采用低层在cal共同支持对象上比较各类尾率、矮星/整体护栏及整体median|Δμ|，不以test决定升级。

固定质量网格为预测W95≤1/2/4/8mag、最大分支权重≥.5/.7/.9、同源可用模型中位数跨度≤.25/.5/1mag、最大光学误差<.03/.06/.12/.25及supported状态。逐项和固定组合给出保留率/各类错误/区间；仅cal中N≥200且各已支持类N≥30、每类尾率≤10%的组合可标“cal研究质量层”，选保留率最高者。若无合格组合则明确无此层，不发明可靠目录。真实参照不足的亮度/精度区间另标未验证；所有内部记录保留。

## 4. 固定通量降质

从三个test场各粗类别（含未知）最多100个高精度、有效距离标签的源，以固定种子抽取；五波段原始有效通量/方差完整性单独报告，WISE不足不删除光学模板。按18–20/20–22/22–23/23–24的实际母表对象选噪声环境，每源每档2次；原始sweep提供通量逆方差和质量字段，包括负WISE测量。模板按目标r0同比例变暗，参考μ加相同位移；计入缩放后的原模板噪声，只按差额增加五波段独立通量噪声，同次g用于颜色和最终μ。保留无法降噪比例。

使用原derive_photometry重新判断grz S/N与clean、WISE资格和冻结路由。以最终测得r分层，注入目标档另列。比较v0与数值修订/所选分支流程，报告拒绝原因、分支、偏差/尾率/区间和研究质量层保留率；不以降质结果反调模型。重复观测按原始源聚类bootstrap。它是已有模板的压力检验，不声称暗端真实族群等同亮端。
