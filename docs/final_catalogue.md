## P0a · 筛选和全天覆盖

从两套原生 sweep inventory 提取 2,126 个源文件。原始行数
可以包含两个巡天的重叠观测。输入文件大小、修改时间和
原始 v3.9 逐行台账的校验值绑定在一起，先用台账保留边界、发布
编号与形态筛选，再按原阶段的 r 流量转换、银河纬度和消光
重算科学域。逐行检验原台账的域内标志。

1. 北天域要求 |b| > 30°、0 ≤ E(B−V) < 0.03 和观测 r < 23。
2. 南天新域在高纬采用 20 ≤ r < 23，在低纬低消光窗采用 r < 20。
   高纬、低消光且 r < 20 的 PSF 单列为原亮端对应的观测范围。
   实际补回的是冻结 v3.5 原有 QRF 支持源。
3. 报告纬度、消光和星等失败的全部重叠，以及按同一顺序分配
   的首次失败。南天的纬度定义的是适用星等窗。低纬本身可
   符合南天域。非有限星等归入星等失败。

归属与 PDF 部分重读全部 28,917 个实际分区。每个 PDF 通过
原生 ID、TYPE 和预测表行号与测光表对齐。科学层保持原始
2,281,023 个核心对象，研究层仍单列。全天图对三个样本使用
一个 Aitoff 投影和一套实际源坐标落点栅格。灰色巡天背景来自
独立 DR11 随机点的 grz 成像面积，完整 PDF 面密度使用未遮掩
面积。南天高纬亮、暗目录共享一份覆盖。灰色边缘以固定
HEALPix 单元表示。光学误差、拥挤或分类选择造成的稀疏
在源分布里可见，面积归一化后的计数仍有星族和限星等依赖。

距离层图按原始 PDF 中位数绘制，完整 PDF 区间质量另存同一
组等面元底表。日心 XY、XZ、YZ 统一展示中位距 10 kpc 内的
全预测和核心科学层。X 朝向银心，Y 朝向银经 90°，Z 朝向
北银极。图面是选中对象的空间分布，解释实际密度需同时使用
测光选择和面积。

## P0b · 选择独立的测距基准

从北天和南天低纬窗冻结工作父索引取原生 PSF，限 18 ≤ r < 20、
严格三带测光、角色 4 留出天区和合格 SpecDis 或 SPDist。
准入光谱框架只依赖观测和谱距。方法覆盖统计显示 QRF 是否
提供距离。发布 Gaia 目录先查唯一 Gaia 源号。比较有效距离
时使用冻结的位置核验标志。
每个比较单元要求两种方法都有有效值。独立于分类评分、
距离 PDF 概率门槛和 Photdis 的预测距离，从谱距侧分箱。
原先 F12 给出了使用作业样本后的条件性能。

误差分别按 SpecDis 和 SPDist 报告。两套谱距的标定可能相关。
在弱 Gaia 子样本单列光谱矮星、光谱贫金属矮星和中间重力星，
主图重点显示 Photdis 与 BJ photogeometric。四个公开方法和
各自区间有效数均保留在配对与覆盖底表。68% 区间得分为参考
中心是否落入报告区间，受参考误差影响。
[原选样和对手数据说明](release_readiness.md)

## P1 · 星族混入的条件前向检验

用原生测光和冻结选样对观测模板进行前向检验。每个模板保留
类别、谱距、去消光 r 星等、光谱金属丰度、位置、QRF 距离、
真实是否通过工作门槛和是否进入预测 2–5 kpc 层。按北天或
南天低纬窗，18–19 或 19–20 等，及三个 g−r 色段分层。对
已有参考的模板，未知金属丰度单列或保持基线权重。

三种固定情景为经验分布、盘相对丰富和晕相对丰富。后两种改变
巨星绝对星等分布、已有光谱金属丰度的相对权重，以及薄盘、
厚盘和压扁晕的相对空间权重。巨星 LF 斜率和金属丰度参数
取已有 v3.6 假设。只在现有模板支持上调整分布，对比同一
测光和选样所产生的类别计数、严重错距。按天区块重抽样和
512 次联合计数模拟传播有限模板的不确定度。

模板来自非留出天区，验证使用独立留出天区。SpecDis 和
SPDist 分开检验。每格至少要有 50 个模板和 50 个验证对象
才计算区间。测试两套参考的实际类别数量、总数和严重错距数
是否落在 95% 预测区间内。要求每个来源在两个原生域的区间
检验覆盖率均至少达到 90%，才认为情景能在这些参考框架内
迁移。非恒星不由恒星光度函数预测，使用合格 Redrock 控制
统计独立报告。光谱靶选、参考质量及 QRF 支持参与分母，整个
测光目录的污染率还取决于这些选择的可识别程度。
[原 LF 模型假设](v3_6_result.md) · [星族误差与已知混入](release_readiness.md)

## 实测比较 · 测距优势来自哪里

观测量定义的谱距框架含 **49,308 个候选源**，其中 **48,714**
个有 Photdis 模型支持。所有 49,308 个有唯一原生 Gaia 键，
目录存在记录和有合格位置关联的有效距离分别计数。

关键对照采用缺少可靠 Gaia 几何距的暗端光谱矮星，由谱距定义
2–5 kpc。两种方法使用同一批星，保留预测落出 2–5 kpc 的对象。

| 参考 | 同星数 | Photdis 偏差 / NMAD | BJ 光度几何偏差 / NMAD | >1 mag 错距，Photdis / BJ | 68% 参考中心覆盖，Photdis / BJ |
| --- | ---: | ---: | ---: | ---: | ---: |
| SpecDis | 9,355 | −2.07% / **9.77%** | −1.06% / 13.27% | 0.33% / 0.84% | 76.11% / 73.69% |
| SPDist | 8,927 | +1.92% / **10.38%** | +3.32% / 14.06% | 0.17% / 0.50% | 77.11% / 73.29% |

移除原有距离筛选后，Photdis 的散布比 F12 有所增大，对 BJ 的
散布优势仍可在两套参考中重复。进一步限定到有可靠金属丰度的
普通矮星，SpecDis 和 SPDist 的 Photdis 散布分别为 8.79% 与
9.21%，BJ 为 12.17% 与 12.63%。偏差和区间覆盖也依赖参考来源。
以北天和南天空域分别比较时，光谱贫金属矮星和中间重力星应单独
评价。仅 2–5 kpc 的光谱贫金属矮星，在两套参考下，Photdis 中位
距离仍偏远约 25%–30%，BJ 的偏远量相近。这表明普通矮星的优势
与较强的分支系统误差可以同时存在。

| 南天低纬窗 SpecDis | 29/32 | 28/32 | 26/32 |
| 南天低纬窗 SPDist | 29/32 | 29/32 | 27/32 |

分子为落入 95% 预测区间的类别及错误计数。经验模板达到这
四个参考框架的核验条件，两个加入物理权重的固定 LF 情景
出现跨域不一致。经验重放验证的是光谱框架内的选择响应，
真实测光母表的人口比例依然受光谱入选概率限制。

例如在北天 SpecDis 的已标验证格中，6,158 颗通过工作门槛
且预测在 2–5 kpc 的恒星里，直接检出 **14 个巨星、117 个
中间重力对象、217 个严重错距对象**。这些类别可以重叠。
三级权重下，巨星预测各格中位数之和依次为 6、9、114，
严重错距相应为 187、205、514.5。这是先验敏感性的量级，
各格区间和实际计数另见底表。同一观测框架的合格 Redrock
非恒星控制另有北天 9 个、南天 7 个进入近层。非恒星控制、
光谱巨星和严重错距使用各自的分母。公开结果保留这些条件量，
当前数据尚无法识别整个核心样本的真实污染率。

PDF 是发布覆盖，2–5 kpc 光谱矮星的独立比较承担距离精度
