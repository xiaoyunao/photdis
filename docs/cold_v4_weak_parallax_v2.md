# 弱视差前向检验 v2：对观测选择条件化

2026-10-28。保持 `cold_v4` 森林与已锁定的 WISE20 路由不变，
对唯一、合格的 DESI 冷矮星、`grz_clean`、Gaia 有效天体测量但非
高精度锚点，保留修正视差／形式误差 `<10` 的对象，包括负视差。
本版用森林叶节点在训练 `M_g` 标签上的**原始权重**定义离散条件
分布，映射为正模型视差并与 Gaia 高斯形式误差卷积。它没有把
CQR 扩展的区间端点解释成完整概率分布。完整结果在
[v2 清单](../manifests/cold_v4_weak_parallax_v2.json)。

因为样本按观测修正视差 `Y<10 sigma` 选择，PIT 使用
`F(Y)/F(10 sigma)`。这只处理显式视差上截断；DESI 靶选与 Gaia
质量选择仍决定研究总体。与旧路由的比较限定于**同一批星**。

| 天区 | 数量/负视差 | 历史五端点近似低 PIT | 森林原始低 PIT / 该截断下预期 | 条件 PIT <0.05 | 模型均值−观测视差中位数 |
|---|---:|---:|---:|---:|---:|
| RA205–215 开发 | 607/5 | 5.6% | 6.3% / 6.0% | 5.4% | +0.019 mas |
| RA150–160 原最终 | 202/1 | 9.4% | 9.4% / 9.0% | 5.9% | +0.040 mas |
| RA220–230 原最终 | 222/0 | 9.0% | 9.9% / 7.4% | 7.2% | +0.041 mas |

表中是 WISE20 结果；旧清洁路由在三个场选择**同样的星**，只是
部分由 C 回退至 B，条件 PIT 低尾比例在显示精度内相同。RA0–10
没有合格 DESI 匹配。原始低 PIT 的正确零假设依每星
`F(10 sigma)` 而变，不能统一用 5%。条件化后两块原最终场约为
12/202 与 16/222，样本仍有限；+0.04 mas 的中心差没有因路由
改变而消失，也不能从此直接推算距离统一零点修正。

本模型的森林离散分布含 Gaia 标签噪声与训练样本选择效应，尚未
经过独立的分布校准。视差误差使用 Gaia 形式随机误差；零点系统
误差、天区相关和 DESI/Gaia 的其余选择没有进入本条件 PIT。
后续可在更大且明确选择函数的冷矮星样本上重复前向检验。

[旧 v1 报告](cold_v4_weak_parallax.md)及其结果清单保留作历史记录；
其中未经条件化的低 PIT 与 5% 的直接比较已由本版替代。
