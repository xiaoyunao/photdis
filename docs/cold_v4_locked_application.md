# 冷主序 v4：锁定清洁 WISE20 路由后的真实候选范围

2026-10-28。把[开发场锁定](../configs/cold_v4_deep_policy.json)的 `grz_clean` + 所用 WISE 波段 S/N≥20 路由，应用到三块原 v4 最终场的 DR11 PSF 测光母样本，同时对相同场的严格 Gaia 冷矮星和 DESI 标签重复检查。距离森林、颜色盒与支持域没有改动。逐项计数见[实际候选与 Gaia 清单](../manifests/cold_v4_locked_application.json)和[DESI 类型清单](../manifests/cold_v4_locked_type.json)。

| 三场合计 | 原最高可用路由 | 原路由且 `grz_clean` | 锁定清洁 WISE20 路由 |
|---|---:|---:|---:|
| 候选数 | 443,280 | 398,387 | **395,629** |
| A (`grz`) | 251,212 | — | **249,654** |
| B (`grzW1`) | 85,717 | — | **79,418** |
| C (`grzW1W2`) | 106,351 | — | **66,557** |

锁定路由比原路由少 47,651 条：44,893 条因光学图像质量不清洁而移出，另有 2,758 条在提高 WISE S/N 后找不到可支持的低波段回退层。锁定候选中 **222,424** 条还满足其实际所用层的严格光度质量；其余通过图像清洁条件，但所用波段形式误差高于严格训练门槛。按实际 `r` 分段，锁定候选为 `14–18`: 30,395，`18–20`: 92,408，`20–21`: 74,668，`21–22`: 81,422，`22–26`: **116,736**。本轮噪声校准仅覆盖 `r=18–22`；尤其 `r≥22` 的候选不能继承该区间的覆盖结论。

严格 Gaia 冷矮星在三个最终场仍分别有 4,991/4,784/2,681 颗通过新路由，所选 A/B/C 身份与原严格结果相同。对这批星，**未用新深度 CQR 的直接森林**在 RA150–160 场 A/B/C 的 95% 距离模数覆盖是 91.2%/84.0%/94.0%，B 仅 75 星。这组检查与原 CQR 后的严格场结果是两种不同区间，不应混用。

DESI 条件标签中，RA150–160 和 RA220–230 场的合格冷矮星分别有 **573/984** 与 **630/1,187** 颗通过锁定路由；冷巨星为 **0/10** 与 **1/12**，已知 QSO/星系为 **13/1,419** 与 **10/1,687**。后两类多数落在 A 层。RA0–10 场没有匹配的 DESI 标签。这些比例的分母是 DESI 已观测且通过本次标签质量条件的对象，不能直接换算成测光候选纯度。

当前锁定路由只定义一条**冷矮星假设下**的距离候选路径。针对新规则和目标深度的距离区间是否可用，取决于另一块独立天区的最终模拟；`r≥22`、类型不确定和光度质量较低的对象需要单独的适用标记。
