# 冷主序 v4：独立场深度区间校准

2026-10-28。在 RA35–45、Dec−35–−25 的独立校准场使用 500 颗未参与 v4 拟合与规则选择的高质量 Gaia 冷矮星模板；每颗在每个目标 `r` 层只产生**一次**共享五波段测量。目标噪声环境从该场 `grz_base` 母样本抽取，不要求 WISE 检出。路由已在[开发场](cold_v4_policy_development.md)冻结为光学 `grz_clean` 加所用 WISE 波段 S/N≥20，仍允许在对应 2/3/4 维支持域内回退。[完整校准清单](../manifests/cold_v4_deep_calibration.json)。

区间在**最终距离模数**上校准，使用同一次带噪测量的 `g` 和颜色。split-CQR 先按目标深度、所选层、`r-z` 训练三分位、所用波段最大形式误差是否大于 0.10 mag、支持半径比是否大于 0.8 分组；少于 80 个独立源的细组依次回退到深度×层×颜色、深度×层、深度全体。每个亮度层内一个模板源只出现一次，重复模拟不被当作独立校准星。

最暗层的 B 只有 63 个独立源，C 没有选中，因此 B 使用该亮度层的全体偏移，C 在此层没有校准。校准场自身的覆盖是 split-CQR 的训练结果；独立最终场的覆盖、尾部与源聚类区间才用于判断能否对应用样本给出该深度的区间。
