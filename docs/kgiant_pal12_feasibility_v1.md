# Palomar 12：一次限定范围的独立参照可行性检查

2026-11-02 登记；在读取该团 DR11 逐星测光、DESI 参数之前固定。
此补充只落实 Pro 的独立标尺要求，不改变已冻结的 K 巨星模型协议、
训练样本或评价分数，也不启动新的训练天区搜索。

选择理由：Pal 12 的丰度约 −0.8，较接近选中 K 巨星主体；已有 Gaia 成员表，
位置落在 DECam DR11。Musella et al. 的模型 CMD 拟合得到
μ0=16.3±0.1、E(B−V)=0.03±0.01，采用的 [Fe/H] 为 −0.96 至 −0.66。
这套距离依赖年龄、丰度、红化与恒星模型，不能称为几何真值。
该方向存在 Sagittarius 背景，成员资格与演化阶段必须分开。
[原论文 §3](https://arxiv.org/abs/1709.08509)；
[2021 勘误](https://doi.org/10.1093/mnras/stab348)仅纠正文中光度转换斜率笔误，
作者明确说明结果不变。本检查不使用该转换，而使用实际 DECam 测量。

固定步骤：

1. 使用现有 Vasiliev–Baumgardt 2021 的 Pal_12 成员，保留 P≥0.5，
   以 P>0.9 单列核心；Gaia 64 位 ID 精确匹配 DR11 G3 REF_ID。
2. 仅读取包含该团的 sweep-325m025-330m020.fits；报告未匹配对象、
   原始重复与去重数量，按 grz 质量优先保留唯一 Gaia 身份。
3. 保留既有 gr/grz/WISE 质量条件。低消光仍为目录 EBV<0.03，
   W1 S/N≥5；不因结果差而放宽。逐层报告光度、饱和及掩膜损失。
4. 与 DESI DR1 MWS 精确身份匹配，采用既有可靠恒星参数质量条件、
   logg+σlogg<3.2 与 4200≤Teff<5000。没有光谱不等于非巨星；
   颜色或参考绝对星等不替代独立阶段标签，RGB/RC/HB 保留未知。
5. 画成员 CMD，并报告 Mg<0.5 和 r16–18 的实际覆盖。
   μ=16.3 只用于可行性图示与亮度清点，不用于选出训练星或拟合。
6. 结束条件是给出已有证据的数量与适用域判断。无足够合格 K 参照时
   明确缺口，不把普通成员整团套入 K 巨星距离模型，不继续追加星团。
