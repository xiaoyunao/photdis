## 测量质量的准确含义

三颗星通过预先固定的grz_clean规则，但规则没有使用RCHISQ，形式误差由通量逆方差传播，
没有加入测光标定底限。[DR11官方定义](https://www.legacysurvey.org/dr11/catalogs/)
中的RCHISQ是源轮廓加权、归一化的模型残差统计量；不直接等于通量偏差。
不增设事后RCHISQ门槛，不把误差乘sqrt(RCHISQ)。

| 星号 | RCHISQ_r | FRACMASKED_z | σg / σr / σz，mag |
|---|---:|---:|---|
| 1272 | 70.10 | 0.269 | 0.000789 / 0.000615 / 0.000442 |
| 1282 | 123.68 | 0.248 | 0.000614 / 0.000434 / 0.000293 |
| 1515 | 63.68 | 0.217 | 0.000837 / 0.000649 / 0.000477 |

因此应称“通过固定测光规则，亮端颜色及系统准确度尚未独立验证”。
固定三身份的图像/模型/残差检查及下一轮批量参照结果见
[批量参照报告](kgiant_reference_batch_result_v1.md)。
文献颜色温度与DESI参数不是同一标度；下一步优先按联合颜色、参考光度、丰度、阶段、
亮度与测量质量判断覆盖，而非仅按“更暖”选取系统。
