### 2. “Mean … PSFs” 的具体含义

原来的色条表达的是：

> 在一个宽距离区间内，对多个距离模数节点的 CMD 选中源面密度取加权平均。

其中：

- **PSF** 是目录中的 `TYPE=PSF` 形态标签，表示按点源模型拟合的源。
- **mean** 是沿距离模数节点的平均，权重由节点单元与距离区间的重叠宽度决定。
- 最终单位是 **源数／平方度**。

这个平均有实际作用：同一个源可以进入多个距离模数节点，宽 bin 包含的节点数也不同，平均后的通道具有可比较的尺度。FoS 同样在各距离通道内平均天空密度图。:chatgpt-content-reference{index="1"}

原标签把目录术语和计算过程都放在图面上，读起来容易误解。我已将色条改成：

**CMD-selected source density [deg⁻²]**

## 五、给 Codex 的下一阶段顺序与判断标准

Prompt 已将工作压缩成三个科学任务。

### 第一项：交出正确 RGB，并用两个真实区域验证固定 CMD

先从现有 cube 生成总览 RGB 和五张 bin 内部 RGB，然后提取 Pal 5 与 Sgr 小区域。

预先固定模板、距离、目标区和背景区，比较：

- 当前 strict 选样；
- 仅改变消光上限；
- 固定 \(g,r\) CMD 选择；
- 加回 \(z\) 条件后的损失；
- MS/TO 与包含更亮演化分支的接受区。

**成功证据**是：实际覆盖存在，目标减背景的 CMD 超额对应预期序列，空间超额在多个既定角向段上与轨迹一致，距离响应峰接近外部参考尺度。参数固定后，结果决定采用哪套选样并扩展天空范围。

### 第二项：用最简单的物理标尺检验老星族迁移

先处理转折点分支，再比较 QRF、同标签网格、固定理论序列，以及一个简单校准序列。

在预先指定的系统上拟合一个零点；确有颜色趋势时再加入一个预先固定的小颜色项。至少一个系统留作本轮标定后的迁移检验，所有已使用系统保留开发历史。

**成功证据**是：在信息量充分的独立系统／相位组中，尺度偏差进入预先设定的约 10% 范围，置信区间、共同参考尺度敏感性和颜色趋势相互一致。若效果集中在某一化学或相位范围，就据此明确适用域。

### 第三项：分离金属丰度统计中的条件化

保持同一人群、支持集和统计量，逐项改变平衡变量；以参考绝对星等作为物理结果，结合 Gaia 观测空间和星团共同尺度检验。

**成功证据**是：能够指出每一项统计测量对应的人群和物理问题，并用外部尺度判断其光度差异。这样得到的结论才能支撑对 halo 距离层和化学选择的解释。

这一轮的新结果已经让论文的科学重心更清楚：**三带测光可以在特定人群中给出精密距离；它在老星族上的绝对尺度、演化分支混合和选样响应，需要由真实序列与已知结构共同约束。** 下一阶段最值得投入的是上述几个小而明确的真实数据实验，它们会直接决定论文最后能够提出多强的科学结论。
