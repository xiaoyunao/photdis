## 一、首先要修复一个确定的推断错误

### 1. 共享 \(g\) 的交叉协方差符号反了

问题在 [`density_v2_3.py` 的 `conditional()`](https://github.com/xiaoyunao/photdis/blob/569d6ff/src/photdis/density_v2_3.py)。

目前代码对颜色与“有效绝对星等”的交叉协方差使用：

```python
v[2, 0] - e[:, 0]
```

其中 `e[:, 0]` 已经是 \(\sigma_g^2\)。这一项应为 **加号**。

可以直接从正向观测模型推导。定义观测误差为“观测值减真实值”：

\[
g_{\rm obs}=M_g+\mu+\epsilon_g.
\]

因此：

\[
\mu=g_{\rm obs}-(M_g+\epsilon_g).
\]

用于从观测 \(g\) 转换到距离模数的随机量应是

\[
T=M_g+\epsilon_g.
\]

而观测颜色为：

\[
\boldsymbol c_{\rm obs}
=
\boldsymbol c_{\rm true}
+
\begin{pmatrix}
\epsilon_g-\epsilon_r\\
\epsilon_r-\epsilon_z
\end{pmatrix}.
\]

若本征的颜色—光度协方差记为 \(V\)，则：

\[
\boxed{
\operatorname{Cov}(T,\boldsymbol c_{\rm obs})
=
V_{Mc}+(\sigma_g^2,0)
}
\]

当前实现使用了减号。这个交叉协方差随后同时进入**条件均值和条件方差**，所以受影响的不只是一个误差条。

### 2. 我用一个能够直接求解的例子确认了问题

取一个本征离散度趋近零的恒星模板：

\[
(g-r,\ r-z,\ M_g)=(0.5,\ 0.2,\ 5),
\]

等价于：

\[
(M_g,M_r,M_z)=(5,\ 4.5,\ 4.3).
\]

观测为：

\[
(g,r,z)=(18.2,\ 17.5,\ 17.3),
\qquad
\sigma_g=\sigma_r=\sigma_z=0.1.
\]

在平坦距离模数先验下，三个波段分别给出距离模数 \(13.2、13.0、13.0\)，联合解应该是它们的等权平均：

\[
\mu=13.0666667,\qquad
\sigma_\mu=\frac{0.1}{\sqrt3}=0.057735.
\]

我实际调用当前代码，得到：

| 计算方式 | 距离模数 |
|---|---:|
| 三波段正向似然的解析解 | **13.066667** |
| 当前 XD 实现 | **13.333333** |
| 使用正确加号的条件公式 | **13.066667** |

当前代码的偏离约为其报告标准差的 **4.62 倍**。

我又使用非对角的本征协方差，通过直接的三波段高斯生成模型独立计算了均值和方差，也确认了同样的问题。所以上面不是只针对一个特殊极限的符号猜测。

### 3. 现有测试重复了同一个错误假设

[`test_shared_g_conditional_and_pdf`](https://github.com/xiaoyunao/photdis/blob/569d6ff/tests/test_density_v2_3.py) 中，期望值也使用了：

```python
cross = v[2, :2] - [.04, 0]
```

这验证了程序与所写公式一致，却没有验证公式与正向观测模型一致。

下一步应加入的有效测试，是：

- 已知绝对星等时，恢复三个波段加权平均得到的距离模数；
- 一般高斯本征分布下，与直接三波段生成式计算得到的均值、方差一致。

### 4. 这个错误可以在保留拟合结果的情况下修复

训练端 `observation_covariance()` 使用的是正确的 \(+\sigma_g^2\)，在参考误差与测光误差独立这一既定假设下，当前发现的问题集中于**预测条件化**。

因此，可以保留：

- 已拟合的 32 个成分及其权重、均值、协方差；
- 原来的训练身份和参考误差；
- 已收敛的 179 次 EM 结果；
- 同资格 QRF 对照。

然后重算候选的条件分布及所有依赖它的结果。[来源：密度模型实现](https://github.com/xiaoyunao/photdis/blob/569d6ff/src/photdis/density_v2_3.py)

**修复不保证 XD32 会变好或者通过验收。** 变化方向取决于颜色残差和本征相关结构，也不能承诺把覆盖率自动修回去。但在修正前，不能把当前结果进一步解释成“显式处理误差的条件密度方向已经失败”。

先把当前提交记录的结果列清楚。**下面 XD 一列均来自尚有上述推断错误的实现，应在修复后更新。**

| 指标 | 同资格 QRF | 当前 XD32 |
|---|---:|---:|
| 开发集总体相对 NMAD | 14.26% | 14.03% |
| 开发集总体严重距离错误率 | 9.654% | 9.447% |
| 开发集 68% 区间分数，越低越好 | 2.207 | 2.371 |
| 近端范围的参考近端完整率 | 77.11% | 85.04% |

| 贫金属矮星中位距离偏差 | +23.25% | +21.40% |

除注明 calibration 的一项外，上述均来自开发统计；近端指标按各模型自身的入选集合计算，不能称为同一批入选对象的逐星改善。[来源：v2.3 结果报告](https://github.com/xiaoyunao/photdis/blob/569d6ff/docs/v2_3_result.md)

按当前实现，报告拒绝采用候选是合理的：总体尾部的小幅下降，没有形成距离分布、近端选择和观测空间评分的一致改善。

但接下来的科学判断应分两步：

1. **先得到正确实现的结果。**
2. **再判断剩下的问题属于分布表示、参考误差、人口组成，还是现有波段的信息不足。**

这里还有一个报告已经正确提醒的区别：QRF 学到的经验光度分布包含参考误差，而 XD 尝试反卷积参考误差。把两者的原始距离区间直接与带噪参考点比较，不能要求完全相同的覆盖率。因此，**68% 点参考覆盖从 68.54% 降至 43.17%，不能单独作为真实距离后验失准的证明；也不能把全部下降自动解释成反卷积的合理结果。** 仍要结合参考误差卷积评分和适当选择条件下的 Gaia 观测预测检验。[来源：完整距离与参考卷积评分](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/development_distance.csv)

## 三、新身份验证有价值，但还需要处理一个明确的观测选择效应

### 1. 上轮提出的资格统计问题，确实修好了

本轮确认：

- 42,076 个保留新身份中，有 **173 个 chosen 距离评价参考**，包括 4 个 Gaia、169 个 SpecDis；
- 有 **3,596 个合格有符号视差观测**；
- 其中 **2,952 个 S/N<5**，**644 个 S/N≥5**；
- 有 **860 个负校正视差**。

这证明上轮把训练资格与评价资格分开，是必要且有效的。噪声基准也已经补上了均匀与设计组成对照，两项旧问题可以结束，不需要再重复要求。[来源：参考资格清单](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/reference_inventory.csv)、[噪声基准](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/noise_baselines.csv)

### 2. 但“没有参与训练”不等于“评价样本与观测视差无关”

这次保留新身份的方式，是排除以前已经使用过的训练、校准、评价身份。

其中历史距离训练资格依赖：

\[
\text{Gaia anchor}
\Longrightarrow
\frac{\widehat\varpi_{\rm corr}}{\sigma_\varpi}\ge20.
\]

再结合参考资格和测光误差要求，决定对象是否入训。因此，“没有被旧训练使用”这个条件，**间接依赖观测视差及其信噪比**。[来源：Gaia 锚点定义](https://github.com/xiaoyunao/photdis/blob/569d6ff/src/photdis/gaia.py)、[训练资格定义](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/baseline_v1_4_assemble.py)、[保留身份选择](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/v2_2_audit.py)

从当前资格表可以进一步确认：这批新身份中，所有 \(r<20\) 的合格视差对象都没有成为 Gaia anchor，处于观测校正视差 **S/N<20** 的范围。

当前预测程序却使用：

```python
snr_lo = -inf
snr_hi = +inf
```

计算无截断 PIT。[来源：v2.3 预测与视差评价](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/v2_3_run.py)

这就不能再自动要求这批被选择对象的原始 PIT 服从均匀分布。

### 3. 近端层的 PIT 已经提示这个问题的重要性

主报告主要展示全部 3,596 个视差对象。但在真正拟采用的 `near_scope` 中，QRF 的结果是：

- N = **711**；
- 负视差 **27** 个；
- PIT < 0.05 的比例 **22.08%**；
- PIT > 0.95 的比例 **3.52%**。[来源：新身份视差分层表](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/reserved_gaia.csv)

这个低尾很明显，必须解释。**但不能直接说它已经证明 QRF 的近端距离严重失准**，因为样本本来就缺少强正视差锚点。

只考虑最简单的选择事件 \(S=\{\widehat\varpi/\sigma_\varpi<20\}\)，正确的条件 CDF 应为：

\[
F(\widehat\varpi\mid S)
=
\frac{F(\widehat\varpi)}
{F(20\sigma_\varpi)}.
\]

即使原模型正确，经过这个截断后，未作条件化的原始 PIT 也会偏向低值。

实际保留过程还涉及 SpecDis、类别资格和历史身份使用，不能只加一个 \(20\sigma\) 上限就宣称全部解决。**下一步应重建保留资格的选择逻辑，明确哪些子集能做解析条件化，哪些需要通过前向模拟复现选择。** 仓库已有支持 S/N 条件化和选择后模拟的代码，可直接复用。[来源：现有视差选择检验工具](https://github.com/xiaoyunao/photdis/blob/569d6ff/src/photdis/baseline_parallax.py)

保留原始评分仍然有意义，它描述的是这批选定对象上的表现；但要把它用于绝对校准验收或目标人口推广，就需要处理选择。

## 五、远端结果还存在一个解释问题：两个模型的“巨星条件分布”并不完全等价

报告中，20–50 kpc 巨星参考的条件严重错误率从 QRF 的约 **7.29%** 上升到 XD 的 **27.86%**。这个结果值得关注，但除了推断符号问题，还有一层方法区别。

### QRF 保留了叶内类别与光度的对应关系

它的类别条件化来自训练对象的类别—绝对星等联合分布，能够保留“某个光度 bin 里的对象属于什么类别”。

### XD32 给每个高斯成分附加一个固定类别频率

XD 拟合的是：

\[
p(g-r,r-z,M_g).
\]

拟合完成后，为每个成分统计一个常数类别比例 \(f_{j,K}\)，再通过

\[
w_j(\boldsymbol c)\,f_{j,\mathrm{giant}}
\]

构造巨星条件分布。

这隐含了：**在同一个高斯成分内部，类别不再随颜色和光度变化。** 如果某个成分跨越多个光度支系，这个辅助标记可能无法恢复成分内部的巨星—矮星对应关系。[来源：类别频率构造](https://github.com/xiaoyunao/photdis/blob/569d6ff/src/photdis/density_v2_3.py)、[远端条件化实现](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/v2_3_far.py)

所以，当前“巨星条件分布变差”同时检验了光度密度和类别标记近似，不能直接归因为完整 PDF 丢失了巨星分支。

现有数字也能说明这个区别：在相同的 700 个 20–50 kpc SpecDis 巨星参考对象上，虽然上述条件尾部明显恶化，**完整 PDF 的参考误差卷积 log score 却从 −3.3081 小幅提高到 −3.2773**。这不证明候选已可用，但说明两个诊断并不是同一件事。[来源：远端条件统计](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/far_conditional.csv)、[完整 PDF 评分](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/development_distance.csv)

**修复推断后，远端最值得补的是一个不依赖辅助类别标记的比较：**

\[
P\!\left(
|\mu-\mu_{\rm ref}|<1\,{\rm mag}
\mid\mathrm{photometry}
\right),
\]

并同时保留参考误差卷积得分。在相同远端对象上检查完整 PDF 是否保留了近参考的概率质量，再去判断成分类别标记是否造成额外损失。

这一步使用已有 PDF 即可，不需要增加混合成分或另训分类器。

## 六、贫金属问题仍然真实存在，而且这轮提供了更有针对性的证据

本轮匹配了 2,055 个贫金属对象，在颜色、温度、参考来源及误差上寻找普通矮星对照。对照允许重复，只有 **354 个唯一身份**。

在总体、未按预测结果筛选的匹配比较中，QRF 得到：

- 贫金属对象中位距离偏差：**+25.10%**；
- 匹配普通矮星中位偏差：**−5.44%**。[来源：贫金属匹配结果](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/metal_poor_matching.csv)、[匹配设计](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/execution/metal_poor_matching.json)

**这部分不依赖 XD 的预测错误，足以说明贫金属条件距离尺度仍是你做银晕科学的主要障碍。**

不过，要保留两个解释限制：

第一，这仍是描述性匹配，尚未完全排除参考尺度随丰度变化等影响，不能全部归因于恒星本征光度关系。

第二，目前距离分层和近端选样分别作用于匹配两侧各自的参考距离与预测结果，因此分层后不一定还保留原来的配对集合。总体 2,055 对的结果，可以用于说明条件差异；分层结果需要明确哪些对被保留、哪些对被拆开。[来源：匹配分层实现](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/v2_3_diagnostics.py)

另外，当前候选的“贫金属条件 PASS”只表示通过了预设的特定判据，不能等同于银晕尺度修复。报告中的中位偏差略降，同时伴随着其他区间与尾部指标变差；这些都应在修复推断后重新判断。

## 七、给 Codex 的下一步，我建议限定为以下四项

### 第一项：修复条件化，并用独立正向模型验证

修正共享 \(g\) 项的符号，同时更新注释与测试。

测试的依据应来自三波段生成模型：

\[
\boldsymbol m
=
\boldsymbol M+\mu\boldsymbol1+\boldsymbol\epsilon,
\]

验证均值、方差和混合分布结果，而不是再次在测试里复制预测函数的表达式。

**完成标准：**已知 SED 和一般高斯本征分布两类独立解析检验均一致。

### 第二项：保留拟合参数，重算受影响的候选结果

沿用当前训练身份、32 成分、拟合文件和 QRF 控制，更新候选的：

- 条件均值、方差与完整 PDF；
- 距离分位数、\(q_{\rm near}\) 和 `near_scope`；
- 距离与视差评分；
- 近端选择规模、完整率和混入率；
- 远端条件与完整 PDF 诊断。

特别要注意：**模型文件哈希不变，并不意味着预测缓存仍然有效。** 当前分块缓存检查主要依据模型哈希和对象身份；修复推断时，应通过显式迁移或新的推断版本使旧候选预测缓存失效，避免重新读取旧结果。[来源：预测缓存逻辑](https://github.com/xiaoyunao/photdis/blob/569d6ff/scripts/v2_3_run.py)

修正前后的变化应按测光误差分层呈现，这样才能知道该错误实际解释了多少退化。

### 第三项：补齐新身份评价的选择条件

重建这批保留对象为何没有进入历史训练，包括视差锚点、参考资格和其他排除条件。

同时保留：

- 原始观测空间评分；
- 有明确选择模型支持的条件化评分；
- 必要时经过相同选择过程的前向模拟检验。

不要仅凭“保留了负视差”，就认为视差选择问题已经不存在。

这些身份现在已经被查看。此次明确公式纠错可以作为同一冻结实验的更正继续评价，但不能重新包装成一次全新盲测。

### 第四项：更新科学判断，突出真正改变结论的证据

更新报告时，重点处理：

- 把 SPDist 的新身份近端结果纳入主要证据；
- 区分完整远端 PDF 与成分级类别条件化；
- 明确贫金属总体配对与分层后配对的区别；
- 统一或说明前后应用覆盖计数的口径；
- 重新列出原预定 calibration 验收结果，并将新增选择条件化分析单独标明。

这一次的终点应该很明确：**在推断正确、评价口径清楚之后，判断这一个固定 XD32 候选是否值得继续。**

## 八、对项目整体进度和发表目标的判断

这轮已经形成了几项可以直接复用的基础：

- 相同 **266,774 个原生 PSF 训练对象**上的公平对照；
- 保留 **43,914 个无可靠类别的距离样本**；
- 修正后的噪声信息基准；
- 实际的新身份参考盘点与评价；
- 约 **84 万**的明确近端候选范围。

而且，重新限定 PSF 训练资格后，QRF 在同一开发集上的总体严重错误率基本保持原水平，说明这次数据入口清理没有破坏主要基线能力。[来源：训练入口效应](https://github.com/xiaoyunao/photdis/blob/569d6ff/manifests/v2_3/admission_effect.csv)

但当前仍不足以支持“新模型优于旧模型”或“近端应用目录已经得到代表性验证”的论文结论。对于你关心的银晕用途，贫金属尺度和远端分支概率仍需解决。

**下一步最有价值的成果，是完成这一个固定实验的正确复评，并据此确认近端可用范围和剩余失败机制。** 远端继续保留，尤其是已有条件结构的 20–50 kpc 支线；先把完整 PDF 与类别分解分清，才能判断后面应该改光度密度、处理人口选择，还是补充新的观测信息。
