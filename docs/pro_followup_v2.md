# 冷主序基线第二轮验证：最终距离、条件区间与类型选择

2026-10-28。原模型、原测试身份及 2026-10-28 第一轮结果分别锁定在 `c3637cb` 和 `d6371ce`；本轮的程序、图与小型结果清单单列为 v2。目录 `data/` 中的星表和模型只存放在 NERSC。

## 先修正统计口径

- 324 颗 PS1 一致的亮星恢复候选中，Legacy 残差中位数为 **+0.10852 mag**，PS1 替换后的中位数为 **+0.12332 mag**；两个中位数之差为 **+0.01480 mag**（PS1 减 Legacy）。逐星配对的 `Legacy−PS1` 残差差值中位数是 **−0.00062 mag**，NMAD **0.065 mag**。98/324 颗配对差值超过 0.1 mag。PS1 在这里检查亮星测光和恢复候选资格；正式距离模型仍只用 Legacy/WISE 颜色和 Gaia 视差标签。[旧实验清单](../manifests/followup_samefield.json)

## 共用五波段噪声：检验最终距离

[新版噪声程序](../scripts/noise_injection_v2.py)对冻结测试中同一批 **223** 颗 A/B/C 都可用的星，每颗每深度重复 8 次。每个重复从原 100 平方度场 **312,975** 条 `grz_base` 测光中抽取目标测量行，不预先要求 W1/W2 检出。三模型使用同一次五波段通量实现。目标的原始通量逆方差、掩膜和观测次数进入重新计算的输入层；同时改变 (g_0) 与颜色，以比较 (M_g)、最终距离模数 \(\mu=g_{0,\mathrm{noisy}}-\widehat M_g\) 和距离区间。重复模拟的区间重采样以原 Gaia 星为单位。[全结果](../manifests/noise_injection_v2.json)

| 模拟观测 (r) | A 输入/严格 | B 输入/严格 | C 输入/严格 | C 的最终 \(\mu\) NMAD / 95% 覆盖 |
|---|---:|---:|---:|---:|
| 18–19 | 100% / 96.0% | 87.0% / 85.7% | 83.1% / 77.9% | 0.279 mag / 93.8% |
| 19–20 | 100% / 97.5% | 82.1% / 75.0% | 67.9% / 54.0% | 0.345 mag / 93.5% |
| 20–21 | 100% / 95.6% | 65.8% / 43.7% | 39.6% / 19.3% | 0.452 mag / 90.9% |
| 21–22 | 100% / 49.3% | 42.8% / 6.8% | **11.9% / 1.1%** | **0.457 mag / 88.7%** |

`r=21–22` 的 C 区间上侧漏出率为 **9.4%**，原星聚类重采样给出的 95% 覆盖区间为 **84.7%–92.9%**。旧实验的 32.2% C 接受率来自已经具有 WISE 层的条件化噪声池；新版的 11.9% 以全部 `grz_base` 行为分母。亮端模板本身的噪声有时高于抽中的目标噪声：`r=18–19` 的五波段比例在 (g,r,z,W1,W2) 分别为 **5.9%、9.4%、22.9%、19.4%、13.1%**。程序在可实现时把模板方差从目标方差中扣除；亮端模拟仍按这个差额解释。[深度图](../figures/noise_injection_v2/01_shared_noise_final_distance.png)

## 只用应用端信息作中心与区间校准

原北、原南两个外场现在作开发样本；新 RA 205–215/Dec −10–0 场专用于校准。中心模型是对 `预测−Gaia M_g` 的正规化 Ridge 回归（\(\alpha=100\)，残差截到 ±1 mag），输入为 Legacy/WISE 颜色、观测 (r) 和测光误差。颜色分成三个开发集分位区间，每个颜色区间再按本区间开发星的 (r) 中位数分成亮、暗两组；新校准场六组每组 **177–248** 颗。组内用独立样本的有限秩 CQR 扩张 68% 和 95% 区间，参数锁定在[校准清单](../manifests/conditional_prepared_v2.json)。Gaia `BP−RP` 只用于结果诊断，不参与中心或区间校准。CQR 的有限样本覆盖依赖校准与应用样本的可交换性，跨天区由实测覆盖检验。[Romano、Patterson 与 Candès 2019](https://proceedings.neurips.cc/paper/8613-conformalized-quantile-regression.pdf)

|---|---|---:|---:|---:|---:|
| RA 230–240/Dec 5–15 | A | 25 | +0.044 → +0.011 | 0.324 mag | 76.0% / 96.0% |
| 同上 | B | 24 | +0.017 → +0.008 | 0.288 mag | 70.8% / 100% |
| 同上 | C | 24 | +0.061 → −0.007 | 0.272 mag | 66.7% / 91.7% |
| RA 50–60/Dec −30–−20 | A | 8,644 | −0.016 → −0.043 | 0.276 mag | 70.1% / 95.2% |
| 同上 | B | 8,227 | −0.023 → −0.026 | 0.252 mag | 69.6% / 95.5% |
| 同上 | C | 8,204 | −0.010 → −0.050 | 0.240 mag | 68.0% / **94.4%** |

第一块场的固定 E(B−V)<0.03 条件只留下 25 颗冷星；它仍计入正式结果。第二块场 105 个 nside=64 天空块给出的 C 模型 95% 覆盖重采样区间为 **93.9%–94.9%**。该场 C 模型的 Gaia 红端 `BP−RP=2.8–3.5` 有 **657** 颗，直接/中心后偏差为 **−0.079/−0.085 mag**，校准后 95% 覆盖 **90.6%**。A 与 B 红端也分别只有 **90.7%** 和 **92.3%**。最终距离相对误差 NMAD 在 A/B/C 为 **13.0% / 11.8% / 11.3%**。[最终清单](../manifests/conditional_final_v2.json)

## 类型标签与候选风险

DESI 质量、明确且唯一匹配、有限 (T_{\mathrm{eff}}\) 和 `logg` 才参与冷矮星/冷巨星标签；已知 QSO/星系另计；其余为光谱未验证。各场[类型清单](../manifests/type_diagnostics_dev.json)按观测 (r)、(r-z) 和天空位置分层，并给出按标签计算的选中率与 Wilson 区间。DESI 光谱目标与全体测光目标的选取方式不同，这些条件率用于评价颜色盒漏入与召回。

| 场 | 合格 DESI 冷矮星：盒/盒+支持 | 冷巨星：盒/盒+支持 | 已知非恒星：盒/盒+支持 |
|---|---:|---:|---:|
| 原北开发场 | 4,273/3,922（总 5,070） | 7/6（总 23） | 36/14（总 1,358） |
| 新校准场 | 1,474/1,346（总 2,044） | 14/9（总 32） | 69/19（总 2,041） |

原校准场只有 2 颗合格冷巨星，原南开发场没有 DESI 标签；两块原先登记的最终场也只有 25 与 66 颗合格冷矮星、零颗合格冷巨星。补充 RA 170–180 场有 512 颗冷矮星，其中 416/388 颗通过颜色盒/盒+支持；4 颗冷巨星均未进入；2,062 个已知非恒星中有 65/20 个进入。另一补充场没有 DESI 标签。[开发类型图](../figures/type_diagnostics_dev_v1/01_class_conditional_box_rates.png)和[补充类型清单](../manifests/type_diagnostics_supplemental.json)给出计数与 Wilson 95% 区间。当前候选表应标为“冷矮星假设距离”，附颜色盒、训练支持域和测光层级；类型风险保持显式标志。现有巨星标签的数量和选择方式不支持把盒内频率当逐星冷矮星概率。

## 当前科学判断

严格冷主序基线仍有可用的亮端距离精度，原基线已经在同一批 1,230 颗拟合星和 223 颗测试星上做了固定叶节点 A/B/C 消融。新版噪声检验把 W2 的深端接受率和最终距离区间误差量化了。条件校准在三块大样本最终场的整体 95% 覆盖为 94.4%–96.2%，但中心修正使整体偏差变大；**红端是三个输入层共同的未解决区域**。深端 r=20–22 的 95% 区间和 W2 可用率也需要单独处理。亮星 PS1 恢复层继续作为诊断样本；APOGEE 继续辅助检查巨星。

下一轮方法工作应集中在红端的星族/金属丰度混合、源模板之外的独立深端距离标签，以及有明确选择函数的类型概率校准。现阶段不给红端或深端的测光候选发布名义 95% 的逐星区间。
