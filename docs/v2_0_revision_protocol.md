## 执行与目录

```bash
# NERSC 登录后，仅提交分配计算节点的任务
sbatch --parsable scripts/run_v2_0_revision.sh
```

脚本依次执行异常审计、既有55组图重绘及温度／流程补图、975张组合图、最终清单核验。
总计1050张图。各阶段写入 `data/v2_0_revision/`，原始冻结逐星表和旧图集保留。
`combinations`使用8个独立绘图进程，按轴组合分发，每个组合内部统一5类别的坐标与色标。

输出的每面板核对 `plotted + outside + missing == eligible`。
CMD参考坐标M=m₀−μ_ref、预测坐标M=m₀−μ_phot，残差图在参考坐标上。
统计量signed=median(ε)、absolute=median(|ε|)，两者单位均为百分比。
稀疏误差格为1–19个对象的灰叉，计数图保留所有非空格。

## 异常诊断的证据边界

逐星表使用完整十进制字符串存储长ID，同时输出JSON保持类型。原始MWS行号缺失时填空和状态，不访问数组末行。
原生测光定位先核对冻结checkpoint，再用LS ID定位原始sweep行，读取可取得的RCHISQ及质量字段。
Gaia精确ID关联补充49颗的BP/RP和解类型／IPD／非单星字段，并在原生REF_EPOCH比较位置。
未知光谱类别逐条解码质量失败，FeH有效性不替代既有Teff／logg类别质量判据。

白矮星仅为候选解释。程序以观测BP−RP<1.5、M_G>10及Legacy M_g,ref>10
标记低光度CMD证据，阈值是本轮解释性诊断，未经过白矮星目录确认。
位置间距>1角秒、RUWE≥1.4、重复源或IPD多峰>10%另列质量／匹配疑点。
所有条件保存为证据，异常区本身不充当类别标签。PDF个例取49颗中最小的4个Gaia ID，
用冻结模型及Sobol128复现原5分位数至1e−6，并保存参考μ±0.5mag内的PDF质量。
