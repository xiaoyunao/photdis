# Photdis v3.15

这一轮完成两项对照。第一项让 M5 与 M68 共用同一套 M30
模板，检验星团间距离差异是否来自上一轮不同的模板和质量条件。
第二项用同一批训练星和同一批留出星，检验增加通带能否帮助区分
光度分支并改善单星距离。

## 同样的 M30 模板仍给出不同的星团距离偏差

两团采用同一套 DECam 测光误差门槛、颜色和视星等范围、CMD
网格、QRF 支持要求以及 CLUSTER 掩膜与低拥挤条件。目标区和背景
区分别按有效面积归一化。资格按原生 DR11 TYPE=PSF 核验。冻结
99 颗兼具成员、掩膜外、低拥挤及观测 r<21 条件的 M30 模板星，
并与包含 1,077 颗星的旧模板交叉比较。目标区采用原划定的几何，
使用共同的筛选规则，两个星团各自的背景与实测深度仍有差异。
外部距离只用于评分。M30 的距离用于固定模板绝对星等尺度。

## 增加 i 或 WISE 后，蓝色中重力星的距离仍明显偏近

固定 v3.14 已有的北天 68,319 个、南天 14,336 个留出 PSF。南天
\(i\) 要求原生干净测光且星等误差不超过 0.10 mag，WISE 要求
W1、W2 均为合格测量且信噪比至少为 5。北天这批原生数据没有
合格 \(i\)。实际配对留出样本为北天 WISE 58,915 颗、南天 \(i\)
12,940 颗、南天 WISE 11,221 颗。每组的两种颜色视图使用同一批合格训练星和
留出星。训练距离优先采用高质量 Gaia，合格 SpecDis 补充。测试
中的距离与光谱类别用于评分及单列的真分支诊断。每支保留颜色
邻域的经验绝对星等分布，按邻域类别频率混合。各通带对照使用
的留出母样本不同，表中只比较同一行内的变化。

中重力比较得到同样的主要结论。北天 2–5 kpc SpecDis 中重力星

普通矮星在同一蓝色距离层的 NMAD 约 15%–16%，加入额外通带
后变化很小。北天有 1,264 颗已知金属贫乏矮星进入共同距离比较。
冻结 QRF 的中位偏差为 −3.3%，NMAD 为 12.5%。加入 WISE 后，
经验混合模型的偏差从 +3.1% 变为 +2.3%，严重错距率同为 1.3%。

## 下一项科学检验

保留北天金属贫乏主序星的冻结 QRF 基线。后续逐星应用首先需要
估计普通矮星和中重力转折星混入的程度，并按独立参考检查距离尺度。
对光度分支仍有简并的中重力对象，科学分析应传播宽或多峰的后验。

群体方向可以选一段低拥挤、已有独立距离梯度和天空轨迹的银晕结构。
在看距离结果前固定源、背景、距离验证窗、模板和比较方法。用同一批
原生 LS 源比较冻结 QRF 的 PDF 叠加、传统 CMD 滤波，以及明确
使用深层原生主序测光的模板。记录不同深度与金属丰度假设下的恢复
误差和控制区假信号，检验 LS 额外测光对结构距离、梯度或密度的
实际贡献。该独立实验是后续工作的范围。
