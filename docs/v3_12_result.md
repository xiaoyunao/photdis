# Photdis v3.12

这轮将问题拆回两步。先看 LS 原生测光本身在同一批恒星上能提供多少距离信息，
再看不同选样能保住多少真实的星团信号。生产 PDF 和样本继续按原版本存档。

## 可靠主序星有可用的远端信息

用每个原生通带系统各自的 g−r 拟合绝对 r 星等中位关系。
每 0.05 mag 一格，至少 30 颗可靠矮星才有训练支持。插值不用光谱金属丰度、
Gaia 或视位置作为应用输入。训练优先采用 Gaia 几何参考，缺少 Gaia 时用
合格 SpecDis。关系宽度取训练格内的稳健散布，设 0.12 mag 下限。
星等超出支持时保留缺失标记。在留出天区，简单关系和 QRF 使用相同 LS
行和参考距离；留出恒星的结果逐参考源报告。这是 LS 原生版的经验基线，
借鉴了 [Ivezić 等对颜色–绝对星等关系的检验](https://arxiv.org/abs/0804.3850)。

下表的分母为经光谱认定的可靠蓝矮星，去消光 g−r < 0.5，SpecDis 参考距离 5–10 kpc。
偏差和严重错距率均按照固定参考对象计算，严重错距指距离模数相差超过 1 mag。

| 方法 | 北天保留 | 北天偏差 / NMAD / 严重错距 | 南天保留 | 南天偏差 / NMAD / 严重错距 |
|---|---:|---:|---:|---:|
| 简单颜色关系 | 4,329/4,329 | −2.6% / 14.6% / 3.0% | 903/913 | −3.4% / 15.2% / 3.1% |
| 冻结 QRF，同颜色支持 | 4,329/4,329 | −5.9% / 14.7% / 5.7% | 903/913 | −8.1% / 15.3% / 4.2% |
| 原硬选 | 156/4,329 | −31.8% / 19.3% / 39.7% | 89/913 | −19.9% / 18.9% / 19.1% |
| v3.11 硬选 | 558/4,329 | −12.9% / 19.8% / 14.2% | 245/913 | −8.3% / 19.2% / 9.8% |

这个全样本中位值掩盖了金属丰度依赖。北天 5–10 kpc 可靠蓝矮星中，
简单关系在 [Fe/H] < −1.5 的 2,240 颗星上偏远 2.1%，在
−0.8 ≤ [Fe/H] < −0.3 的 476 颗星上偏近 16.0%。南天对应为
+12.3%（124 颗）和 −7.2%（429 颗）。这些分层保留了参考选择
和光谱误差的影响。2–5 kpc 参考矮星的 QRF 散布在未硬选时为
10.4% 和 9.5%，在原硬选后为 8.4% 和 8.6%。

中间重力、偏蓝、温度至少 5500 K、log g 至少 3.7 的光谱对象可用来探查
转折区。这个代理样本包含演化状态邻近的恒星。未经选择，简单关系对其
中位偏差仍为北天 −28.1%、南天 −26.4%，严重错距率为 27.0%、22.5%。
冻结 QRF 在同一颜色支持范围内约低估 32%，严重错距率为 36% 和 32%。
因此，可靠矮星的远端结果不能直接用于整个转折区域。

同一训练身份、同一标签的分类输入对照中，北天撤去显式视星等后，
远蓝矮星入选从 558 降为 466。南天去天空特征时从 245 增至 254，
同时撤去显式视星等和天区特征时增至 275，仍低于 50% 目标。
南天联合删特征后，留出中重力混入由 112 增至 142。模型仍可通过
测光误差、波段可用性等获得间接的观测条件信息。
软矮星权重保留 82% 和 79% 的参考有效星数。若把权重整体缩放，使校准
巨星和中重力的期望混入数不超过旧组合切，留出的有效保留为 9.9% 和 12.7%。
这个全局缩放不改善拟合或星族区分能力。南天留出的巨星混入仍超过旧切。

## 星团信号和距离尺度

M92、M13 采用原来的目标环、背景环和有效面积。汇总完整 QRF PDF，再计算
单位面积的目标减背景。参考距离窗口为 ±1 kpc，寻找全局峰时覆盖 1–20 kpc。
成员用 Vasiliev 与 Baumgardt 的 Gaia EDR3 星团表，按唯一 Gaia 身份
匹配且成员概率高于 0.9。这里的成员保留以实际匹配的测光支持样本为分母，
不代表对所有物理成员的完整度。误差使用模板权重平方加总的条件 Poisson
近似，保留空间密度波动与选择函数的局限。

M92 在参考窗口里的超额每平方度从未硬选的 826 降为硬选的 2，软权重保留 660。
M13 分别为 4,191、37 和 3,334。软权重恢复的是结构信号，距离尺度仍偏远
19% 和 16%。简单颜色关系在两团的峰位更远。这说明可靠蓝矮星在光谱
验证中的进步尚未转换为星团距离尺度的改进。

### 独立验收 M30

M30 在任何新拟合前锁定。新训练和校准排除中心 2°，最终 11,426 个
原生 PSF 的身份均与冻结南天 QRF 训练及两套历史分类训练和校准无重叠。
这是单独的南天验证视线，采用同样的 r < 20 和三带误差门槛，允许
E(B−V) < 0.08。使用 DR11 随机表计算两环的有效面积 0.3612 和 3.1812 平方度。

| 方法 | 峰位置 | 距 8.49 kpc ±1 kpc 的超额，deg⁻² | 匹配成员有效保留 |
|---|---:|---:|---:|
| 未硬选 QRF | 9.875 kpc | 413 | 667/667 |
| 原硬选 | 2.125 kpc | −0.006 | 5/667 |
| v3.11 硬选 | 2.375 kpc | −4.4 | 3/667 |
| 软矮星权重 | 10.125 kpc | 261 | 454/667 |
| 简单颜色关系 | 11.875 kpc | 284 | 663/667 |

未硬选 QRF 和软权重的参考窗口超额，在条件计数误差下分别约为
19.4 和 18.9 倍标准差。全距离峰却比参考远约 16% 和 19%，超过
预先设定的 10% 距离验收目标。颜色关系约偏远 40%。这次检验区分了
保留结构信号与校准结构位置两件事。成员权重与背景权重逐方案公开，
没有把目标光谱混入率外推为母目录污染率。

## 采用决定

可靠蓝矮星的纯测光距离有实测支持，简单关系也足以作为今后的基准。
现有硬选择达不到 50% 保留，软权重在保住团信号的同时仍留有光度尺度
和混入问题。三套星团均表现出未硬选峰位偏远，蓝色中重力代理的单星
距离则通常偏近。它们对不同星族和选择敏感，无法据此设置统一距离修正。
转折群体未达预定尺度条件。本轮据此保留针对金属丰度的分层证据，
暂缓为该星族增加 grzi 或 WISE 模型，也暂缓采用任何新生产选样。

## 验收与复现

同星图和 CMD 直接复用 v3.8 锁定模板。简单关系生成的 CMD 自然
贴着训练颜色曲线，距离比较及独立结构验收才提供外部证据。
14 组 PNG/PDF 已检查。NERSC 验收 61408425 和原生形态审计
61408587 均以 0:0 完成。本地 472 项测试通过，并验证了颜色范围、
软权重距离统计和结构超额计算。

运行入口为 `scripts/run_v3_12.sh`。先在两侧分别运行
`reference north` 和 `reference south`，然后运行
`structure north` 和 `structure m30`。最终运行 `delivery`
和 `structure audit_m30`。公开成员表取自 Zenodo 4891252 的
`clusters.zip`。归档 MD5 为 `3a07093be9a1fcbfb0e3c545ca175c99`，
三团成员的 Gaia ID、天球位置和成员概率投影哈希保存在星团回执。
大型逐星与模型文件保存在 NERSC 的
`/pscratch/sd/y/yunao/photdis_pipeline/data/v3_12/`。
