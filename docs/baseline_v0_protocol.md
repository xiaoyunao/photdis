# 统一多星族 baseline v0 协议

基线60f65d5；完整需求见pro_review_60f65d5.md。目标是全流程和已有天区内部研究目录，而不是发布绝对标定完毕的科学目录。旧冷主序/RGB/K巨星结果不改，星团只作已有证据附件。

- 复用14场field_diagnostics，13个DECam场为主线；唯一北方场保留同结构母表及覆盖，标记无同系统模型，不能用DECam冒充北天预测。母样本沿用原文件的PSF入口、grz_base+grz_clean、|b|>30、0≤EBV<.03，不需要光谱/Gaia/WISE。保留每波段误差与WISE失败状态。
- 按Gaia身份去重（无Gaia时LS身份），跨场由最小场编号拥有。标签额外检查DESI身份冲突，不允许同一标签进入多分区。全部应用对象保留唯一身份规则，原始记录数与唯一星数分别报告。
- 整场划分在结果前固定：配置按既有三个registry顺序编号；train=0,1,2,3,7,8,11,12；cal=4,9；test=5,6,10；north=13。旧场已被查看，因此属于发展验证，不称最终盲测。未用测试集调参或决定路由。
- Gaia标签使用原astro_quality、zpt_valid、正校正视差S/N≥20、非已知污染源；宽人群不再要求冷主序。否则用唯一(TARGETID,SOURCE_ID)匹配、BINARY_FLAG=1、正DIST/DISTERR且误差小于距离的SPECDIS；保留SPDist既有有效域交叉参照。训练核心另要求grz各误差<.03；评价不施加该严格误差条件。Mg统一由Legacy g0−距离模数得到，不使用Gaia MG_NN代替。保留来源、误差和已知非恒星风险；非恒星证据不训练但仍进入完整应用/测试输出。
- 固定QRF：128树、叶最少32、最大深度20、max_features=.75、不bootstrap；A两种光学颜色，B增z−W1，C再增W1−W2。全样本A不要求WISE。叶内训练分布用0.1mag直方图压缩，范围包住训练标签并在两端各留3mag余量；与精确叶权重比较离散化误差，不改变模型族。训练光度标签误差仅作为来源诊断，不将经验分布宣称去卷积本征分布。
- 独立六模型：A(all)、B(W1)、C(W1W2)，以及A_on_B、A_on_C、B_on_C。相同训练身份比较A_on_B/B和A_on_C/B_on_C/C；测试也使用相同可用身份。保存全部主模型输出，再由cal上的距离模数绝对误差中位数决定B/A和C/B是否采用；样本不足100不升级。推荐顺序含支持域回退，不预设C最优。
- 用8次确定性同源同波段扰动传播输入测光误差；每次的g同时改变g−r和μ=g−Mg，训练参考误差不再重复加到预测。保存原始经验分布摘要、两最高平滑模式、间隔/权重及宽度；它们不是银河真实类别先验。用叶内已标注DESI粗类别计数提供经验类别分数，同时输出标签占比；未知保留未知，分数不是校准类别概率。
- 支持域：训练颜色标准化后的第十邻距离、训练留一99百分位及逐维范围。输出域外标志而不从完整性能表删除。cal仅给68/95区间CQR扩展及路由；raw分布、raw与校准覆盖分别保留，CQR端点不当完整PDF。
- 完整测试：无真实类型输入；Gaia/SPECDIS/SPDist分开评价，按r、最大光学误差、粗类别、支持域、来源分层，报告偏差/NMAD/|Δμ|>.5及>1/宽度/覆盖。负弱视差只作观测视差空间诊断，明确S/N选样效应，不用直接倒数或以残差中心推零点。
- 应用所有现有DECam母表，逐源A/B/C及推荐μ/距离分位数、模式、质量与支持/歧义/未标定标记；大文件/模型留NERSC。输出“internal_uncalibrated”，无可靠支持亦保留输出原因。train/cal区域不冒称独立测试。
- 主报告六组图：流量与WISE亮度/颜色/误差/天区覆盖，同星增益，全测试phot-d与Gaia/SPECDIS/SPDist及残差，同源CMD，精度—覆盖曲线，类型/多解分布；光谱目录共同Gaia依赖写明，暗端无参照标未验证。
- 验收：身份分区断言、覆盖守恒、所有母表行均有输出状态、数学小样本测试、实际产物核验、图检视；完整报告与初步目录即结项。性能差可作为结果，不再以局部星团校准阻塞。阶段提交与三端同步，完整执行记录写WORKLOG。
