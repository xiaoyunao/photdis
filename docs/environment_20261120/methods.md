# Frozen Photdis distances in six DECam fields

We used the imaging geometry available at the previous release to select six circular windows of radius 1.25 degrees. L219, L233, and L240 sample the southern edge of the low-latitude footprint. M240 and M037 sample two different mid-latitude reddening regimes. H240 supplies a high-latitude comparison in the same instrumental system. The field coordinates and count and precision criteria were set before running new QRF predictions. The low-latitude apertures straddle the 10-degree boundary, so source-level latitude is retained. Independent random-catalog geometry gives a footprint proxy for clean gr imaging. It does not measure grz completeness.

The census applies half-open native sweep boundaries, the DR11 DECam release and southern ownership convention, explicit TYPE=PSF, observed r between 14 and 23, finite nonnegative SFD reddening, the unchanged grz quality tests, and measurement errors below 0.10 mag in every band. The raw admission table separates missing morphology, non-PSF, domain, and photometric losses. Exact Gaia EDR3/DR3 source IDs are used only when unique in the qualified native parent, followed by the existing half-arcsecond position check. Strong geometric references require the frozen astrometric quality and parallax zero-point criteria and corrected parallax S/N of at least ten. Aliases shared by more than one native object are excluded. Absolute-magnitude and color envelopes at both zero and full-column extinction define conservative Gaia HRD proxies for some reference stars. Spectroscopic classification is used when available. The HRD envelopes are diagnostics, and neither these proxies nor the reference distances are inputs to QRF.

The frozen DECam QRF keeps its original support check, trained object identities, native grz features, and 128 identity-seeded Sobol perturbations. Explicit fit overlaps are excluded from evaluation. A separate historical-pool flag records earlier lineage overlap, and a sensitivity table excludes these identities as well. This is a fixed replay on selected fields. The precision check does not imply prospective validation against every previous Photdis product. Gaia, SpecDis, SPDist, and the supplementary APOGEE DR17 astroNN comparisons use distinct reference labels and denominators. The APOGEE supplement was specified after finding sparse DESI coverage and before reviewing any new residuals. Its alignments reuse the existing verified DR17 source inventory. The astroNN reference uses Gaia EDR3 during training. [SDSS documentation](https://www.sdss.org/dr19/mwm/astra/pipelines-in-astra/astronn/).

The catalogue totals count all precise sources and all nominally supported sources. Independent deterministic hash draws cap the application sample at 3,000 per field and quality references at 1,800 per field per provider. Application retention is estimated on the initial drawn objects, including unsupported draws in the denominator. It replays the existing southern v3.10 classifier and 2–10 kpc PDF mass rule. The r<20 domain and fainter pilot slices can be read separately from the magnitude bins. The result estimates the observed sample fraction passing the rule, not stellar-population completeness.

Comparisons use a common empirical mixture over coarse cells in corrected g−r, observed r, reference distance and population tag. Each shared cell contributes equally to the two arms with cell weight proportional to the smaller arm count. Cells need at least four sources on both sides. The targeted latitude, dust and crowding contrasts balance available bins of the other environmental variables. Each field versus H240 also has a joint environment contrast balancing only stellar observables. These are conditional associations. Full-column corrections can shift objects between color cells, and composition and depth can still differ within cells. The bootstrap resamples shared 0.30-degree Galactic coordinate blocks 600 times, including a common multiplicity for the same objects in the paired experiment. Effective sample sizes and contributing blocks appear with every contrast. An interval has resolution at the requested 0.10 mag only if each arm has effective N at least 60, at least eight blocks, and both 95% limits within 0.10 mag of the point estimate. These conditional block intervals do not measure field-to-field variance outside the six windows.

Distance scale is the median distance-modulus residual, with centered NMAD, the absolute-residual fraction above one magnitude, and central interval width and reference-center containment. The log score integrates the full piecewise-uniform QRF forecast against a Gaussian reference in distance modulus. Gaia reference width is the local parallax-to-modulus uncertainty at high S/N. CRPS uses the reference center and the complete forecast, evaluated with the analytic mixture of uniform bins. These summaries use separate columns and definitions.

Bayestar19 is an external map based on Pan-STARRS 1, 2MASS and Gaia. It cannot provide a strictly independent map reference for those surveys. [Green et al. 2019](https://arxiv.org/abs/1905.02734). We use its median reddening profile, its convergence and reliable distance flags, and the project's existing conversion between Bayestar and DECam extinction. On an identity-hash draw of up to 500 Gaia objects per field, we first compare against the frozen SFD PDF on exactly the same continuous interval defined by reliable grid centers. Each conditional QRF PDF must retain at least half its original probability inside that interval. The photometry-only iteration initializes at the restricted SFD QRF median. Each of at most nine steps queries the map at the current median, recomputes the unchanged QRF with the corrected grz photometry, and updates the modulus with half damping. It terminates when the median is within 0.02 mag of the query. Its output is a conditional QRF PDF evaluated at the converged extinction, so it does not integrate dust-profile or multiple-solution uncertainty. Scores are conditional on convergence and a reference inside map support. State counts record map misses, support failures, insufficient in-range mass, and nonconvergence.

A separate known-distance sensitivity uses the small-error Gaia distance to query Bayestar. We use it only to test distance scale and severe error sensitivity on the same stars and interval. Its PDF scores are undefined for independent validation and remain blank. The unrestricted SFD bias appears alongside the shared-support bias so that a shift caused purely by conditioning the distance range is visible.
