# Photdis v3.0 scientific figure atlas

Current atlas index; final population/catalog panels are added after actual production and visual inspection. Figures use English text and the established Pal 5 New palette and typography. Every plate has PNG (300 dpi), PDF, CSV and JSON provenance. Scientific metrics use the full qualified comparison, not the display clip.

For distance comparisons, each population/reference pair has its own joint x/y linear-distance 3-sigma display mask. Main distance, attached narrow percentage residual (−100 to100%) and central histogram share that pair-specific mask; Gaia, SpecDis and SPDist never share one cross-reference mask.
