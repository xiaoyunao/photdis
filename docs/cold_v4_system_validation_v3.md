# 宽双星与 Blanco 1：WISE20 同系统复核

2026-10-28。冻结森林和原始参考成员，用同一批宽双星、同一批星团
成员，比较旧清洁路由与锁定的 `grz_clean` + WISE S/N≥20 路由。
[逐项清单](../manifests/cold_v4_system_validation_v3.json)。

两种规则都保留 **456 对**宽双星。较暗成员减较亮成员的预测
距离模数中位差，旧规则为 **+0.0455 mag**（按独立系统重采样的
95% 区间 +0.0154 至 +0.0786），WISE20 为 **+0.0441 mag**
（+0.0141 至 +0.0774）。同一配对的规则差值中位数为 **0.000 mag**。
因此较暗成员偏远的相对趋势在当前路由下仍存在。亮度差与颜色、
恒星质量、测光质量及未分辨伴星相关，不能直接把这个结果当作
只依赖亮度的中心修正。

Blanco 1 的 **201** 个成员在两种规则下团内距离模数 NMAD 均为
**0.244 mag**。这一统计量逐团减去了该团自身的预测中位数，
检验团内散布，**没有检验绝对距离零点**。单个年轻星团也不能
代表全部老年盘星或晕星族群。
