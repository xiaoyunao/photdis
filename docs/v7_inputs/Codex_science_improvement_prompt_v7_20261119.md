## 3. 五个固定、递进的对照

用同一三波段似然、原生测光系统转换、误差传播、绝对星等范围、消光约定和计算精度。固定原有 0.10 mag 灰散布，先比较未经新零点拟合的结果。A–E 沿用原解析共同振幅计算对应的平坦距离模数测度（flat μ prior）；参考星团距离只进入评价。沿等时线的 IMF 权重与距离先验分别定义，保持距离测度在五组之间完全一致。

| 对照 | Locus | 沿序列权重 | 分支 |
|---|---|---|---|
| A | 原 FOS MIST1.0，12 Gyr、[Fe/H]=−2.17 | 原弧长权重 | 原 phase 0 |
| B | 已有 MIST1.2 同年龄、同铁丰度对照 | 与 A 相同的弧长规则 | 相同物理范围 |
| C | 已有各系统年龄/铁丰度匹配 MIST1.2 | 与 B 相同的弧长规则 | 相同物理范围 |
| D | 与 C 完全相同的曲线和节点 | 预先固定的初始质量积分权重 | 与 C 相同 |
| E | 与 D 相同模型 | 与 D 相同 | 加入明确规定的主序后段 |

A→B 测量模型版本影响；B→C 测量当前固定年龄与铁丰度组合的影响；C→D 测量积分测度影响；D→E 测量亮度分支支持影响。逐项报告。

### 具体实施约定

- 使用已经归档的四个 MIST1.2 文件及原 FOS 模板。当前 MIST1.2 取 [α/Fe]=0、v/vcrit=0.4；这是固定控制。当前结果中年龄与 FeH 联合变化，按该组合解释。
- 现有 MIST1.2 表实际没有 phase 1，主序后从 phase 2、EEP 454 开始。先检查真实 EEP、初始质量、光度和颜色连续段，再固定 E 的范围。优先在原来的模型 3≤Mr≤8 范围内加入与主序连续的早期主序后段，以保持范围可比；报告实际加入的 EEP、初始质量和 Mr 范围。D→E 的解释范围就是这一已纳入的早期主序后段；更亮的 SGB/RGB 分支属于后续单独规定的范围扩展。
- 只连接原始相邻演化段，保留颜色多解。原生转换支持边界、相位缺口或不连续段分别处理。
- D 使用一个预先写明的固定 IMF 作为物理测度，例如在这组窄质量范围内采用标准 Kroupa 高质量段斜率并积分每个初始质量小区间。明确这只是固定的星族敏感性选择；星团质量函数、质量分离与成员选择另有影响。
- 积分权重对应初始质量区间的积分，不直接把模型文件中的点数当恒星数。核对重复或非单调初始质量段，保存处理规则及质量守恒。
- 单龄等时线上的 IMF×dM_init 已表达相应演化占据效应；保持这一测度定义，避免重复加入寿命因子。
- 对 C 与 D 使用相同物理节点及相同数值积分精度。只有积分收敛误差接近待比较效应时再细化；保留初始值和细化值。
- A 原值重放后保持封存。原 M13 灰零点只用于旧模型的已有参考图；B–E 的主比较均使用原始模型尺度。另可提供每组诊断中心化结果，明确其中心来自被评价组。
- 系统名称只用于选择这一机制实验预先登记的年龄/铁丰度曲线。将 C–E 标为已知系统参数条件下的模型比较。将其扩展为场星推断需要另行规定应用时的星族混合。
- QRF 对照保持原全 PDF。重放时使用原 float64 mag_grz/error_grz/identity；展示用 float32 列保留其原用途。

## 5. 科学判断与停止标准

先报告所有固定对照，再按下列逻辑作决定：

1. **几何主导：** B/C 在权重固定时改善同源尺度及评分，而 C→D、D→E 的变化较小。下一步集中于原生序列、元素丰度/大气/通带标定。
2. **权重或分支主导：** C→D 或 D→E 同时减小 lower-MS/turnoff 尺度差、改善配对 proper score，并保持支持。下一步集中于可观测条件下的星族权重和分支概率。
3. **局部、混合或不确定：** 变化依赖系统，评分与尺度方向不同，或统计区间覆盖零。保存该结果及对应的样本/模型范围，限定后续校准对象。

将 |组中位Δμ|≤0.10 mag 作为预先声明的实际尺度目标，分别列出各系统及序列区，而不通过事后平移满足它。把改善证据与目标达成分别记录。转折区 proper-score 差的配对95%区间、序列尺度差及成员支持共同参与判断；小样本给出其实际不确定度。

这一轮共五个固定对照。完成后给出证据决定，保持对照数量和参数不随正负结果增加。若提出经验校准，明确下一次校准系统、迁移系统、自由度和独立参考条件；单纯对现有三个系统逐个调零点无法评估可迁移性。
