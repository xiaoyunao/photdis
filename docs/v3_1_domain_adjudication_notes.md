This is a post-evaluation reporting note, not a new model, gate, source selection,
or validation protocol. The frozen use-domain and paired-screen protocols remain
authoritative. The synthesis requires all 102 sky-transfer outcomes, all 32
structure states and their actual posterior/count report, all 64 response probes,
the full radial recovery, frozen external evaluation, high-q counts, and exact
3540-object mode inventory. Missing stages cannot be silently omitted.

The evaluated main candidate already fails its registered ensemble numerical
gate. Therefore every occupied candidate cell has the primary disposition
`failed_main_numerical_gate`; empty candidate cells are `outside_candidate`.
No cell can be promoted to calibrated or to a scientifically accepted ambiguous
domain by stable per-object modes, a passing relative mean guard, a reference
being present, or an underpowered reference comparison. This fixed-product
report fails closed if supplied with a different accepted main candidate.

Retain separate columns for empirical nonvalidation, source-qualified precise
new-sky counts and the original fewer-than-20 reference rule, whole-sky paired
screens, native fine-audit coverage, and model multimodality. A dominant numerical
failure must not hide those other limitations. Mode posterior responsibilities
allow conditional model exploration; they do not confirm physical binaries or
establish calibrated multimodal inference. The high-q identities remain fixed.

Global response/importance support, radial recovery, common-scale residuals and
structure results remain linked evidence with their actual shared uncertainty.
Do not assign a global ESS to a local cell as an empirical calibration measure.
The seen NGC288 application uses a supplied scale prior and cannot certify the
new candidate or replace the independent NGC1261 scale comparison. Missing
references remain missing, Gaia remains in signed observation space, and
correlated teachers/common-system members are not independent replications.

The generated source tables are an evidence join, not the final written
scientific adjudication. The integrated result must inspect and cite the actual
outcomes, retain numerical/coverage/transfer failures, explain that no broadly
calibrated scientific-use domain has been established, and visually verify the
English summary map before marking the domain deliverable complete.
