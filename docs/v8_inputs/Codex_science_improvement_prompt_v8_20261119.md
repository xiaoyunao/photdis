## 3. 先用现有数据检查灰光度假设的适用范围

### 3.1 两色几何

对三个系统的完整原始母样本，利用已有E曲线、观测两色及完整共享r协方差，输出：

- 到原始物理线段的最小两色chi-square，以及沿局部切线/垂直方向的残差；
- 残差相对于报告测光误差的分布，按固定观测颜色分箱；
- E支持与超出支持的源数及位置，保持全部父样本可见；
- 若存在多个相近交点，保存其分支和权重，在既有CDF/PDF资料上解释。

原有固定参考Mg上的水平颜色残差与垂直亮度残差是相关投影。灰校准会沿相同的两色曲线重新映射亮度，从而改变固定Mg处的颜色。判定真正的两色垂直失配应使用上述距离独立的几何与误差，而不把固定Mg的投影差直接当成正交颜色差。

现有supported turnoff的预测平均颜色残差很小（例如M5约−0.002/+0.004 mag），同时还需查看分布、协方差和被支持条件排除的成员。这里使用现有数据完成一个紧凑诊断，不开展新的模型族扫描。

## 4. 唯一新候选：E上的两参数灰光度修正

对每个原模型节点j和每个原生波段b，使用

M'_(b,j) = M_(b,j) + a0 + a1 [c_j − c_*]，

其中c_j为该节点原来的内禀原生(g−r)颜色；枢轴固定c_*=0.30 mag。三波段使用同一个修正。拟合自由度只有a0和a1。

冻结以下量：

- E的原节点身份、初始质量区间、IMF权重、相位标签和邻接关系；
- 原来入选的3≤Mr≤8模型节点集合及北天转换支持，校准后保留同一集合；
- 两色似然、误差传播、0.001 mag误差下限、0.10 mag灰散布；
- 平坦距离模数测度、原颜色支持条件，以及全部PDF模式与尾部。

这一结构具有明确的不变性：节点颜色、颜色似然、归一化节点权重、支持状态和后主序概率质量保持原值；节点条件模数均值改变为mu'_ij=mu_ij−a0−a1(c_j−c_*)。用一个小的真实数据重放核对这些恒等关系。校准不重算弧长，不依照修正后的Mr再次裁剪节点，不为不同系统拟合新的常数，也不额外伸缩PDF宽度。

原生颜色坐标在南北通带不同；应用到M13时按预定的原生定义直接迁移，并把这一通带迁移单独解释。模型节点颜色是修正的自变量；每个源的带噪观测颜色用于似然和选样。

## 5. M5内部预测检验与共同距离不确定度

在任何新拟合前，用固定种子或原生ID哈希冻结两个成员折，按预先固定的观测g−r箱维持覆盖。每次只用一折拟合a0/a1，预测另一折，最后合并全部留出预测。所有数据质量、相位框和支持条件提前固定。

使用完整E混合分布拟合。写出实际拟合目标；M5的共同距离模数作为一个系统级量，与一个外部参考约束共同进入校准。若使用似然形式，应为

L(a0,a1,mu_M5) ∝ R_M5(mu_M5) × product_i p_i^cal(mu_M5 | photometry_i)，

或其对共同mu_M5的一次积分，而不是为每颗成员重复加入独立的系统距离测量。可以利用灰零点与共同距离的平移关系进行等价而高效的传播，并保存证明与数值重放。用成员重采样和共同参考抽样传播参数不确定度，跨方法/颜色区间复用同一次抽样。

每个折保存参数、协方差、训练源和留出源身份、拟合目标值及实际颜色覆盖。先交付交叉预测统计，再以全部预定M5校准成员拟合一次冻结的最终a0/a1，用于M30/M13迁移。这里的最终全M5拟合遵循同一个已声明模型。

把以下两种分布及其科学用途明确分开：

- 受控光度映射实验的主表使用参数点拟合下的条件PDF：M5使用相应训练折参数，迁移使用最终全M5参数。固定0.10 mag灰散布，参数估计不确定度进入共同重采样的尺度、评分和宽度区间。每次重采样重新拟合，M5训练与留出评价复用同一个M5参考距离抽样；M30/M13各使用自己的系统参考抽样，并在方法间复用。
- 外部系统迁移同时保存对校准参数不确定度边缘化的预测PDF及其评分、宽度。这组结果用于讨论实际迁移预测的概率校准。一次参数抽样在全部目标成员间共享；独立目标系统的参考核在评分时卷积一次。原点拟合结果与边缘化结果分别列名，记录增加的宽度及其来源。

M5留出成员与训练成员共享同一个系统距离，内部检验保持上述共同参考的条件定义。若另展示M5参数边缘化结果，须从训练、留出和共同距离的联合模型推导对应诊断；同一M5参考误差只沿其共享关系传播。已有V8评分仍保留原定义和版本。本轮受控光度变化、参数估计误差与目标参考误差各有独立的记录。

对比同源的原E、留出/迁移校准E和原QRF。原始模数结果作为主比较；中心化结果仅作诊断。记录每个目标在校准颜色范围以外节点上的概率质量：M5留出源使用对应训练折的实际范围，外部迁移使用最终全M5范围。用于汇总颜色重叠与外推程度的阈值在查看新评分前登记，分别报告各组人数和结果。

## 6. 固定迁移与可选的一次独立系统检验

### 6.1 已研究系统迁移

冻结M5参数后应用于M30和M13。M30检验更贫金属星族，M13检验北天通带；两者都有既往开发历史。保持它们原有已声明的年龄/FeH曲线；新的校准参数由M5提供。

### 6.2 独立系统：先选择和冻结，再一次评价

为建立一次前瞻检验，在读取其距离残差前，按以下条件盘点最多两个候选：

- 已有原生Legacy覆盖、PSF和低拥挤成员数量；
- 与M5的通带、丰度和校准颜色/亮度范围接近的程度；
- 成员目录、外部年龄/丰度与距离参考的公开来源；
- 全项目训练、标定、开发、前轮图表及既往评价中是否使用过这个系统或其成员；
- 距离参考各组成的来源及共享误差，包括几何、运动学、变星/水平分支或等时线成分与本项目的依赖。

以这些条件选定一个最有解释力的候选，冻结成员资格、适用区域、模型参数、参考分布和评分顺序。第一个独立系统优先检验接近M5域内的迁移；更贫金属或更暗的对象对应另一个明确的外推问题。项目此前提出的NGC5053可参与盘点，其科学角色属于贫金属和较深范围，参考距离的来源也需要按组成核实。

只有M5留出与固定迁移结果表明这项两参数校准值得继续时，才对选定系统进行一次完整预测评价。若两个候选都缺乏足够的适用成员或参考独立性，交付实际盘点结果，保持本轮结论在现有系统范围内。若进行独立评价，参数和选样保持冻结，记录全部结果后结束这一分支。

已知系统年龄/FeH条件下的预测继续明确其条件；向未知场星应用需要另行规定星族混合。

## 7. 指标、成功标准与科学决定

各系统和固定相位/颜色区间同时报告：

- 原始母样本数、支持数、同源比较数和观测/模型颜色覆盖；
- 中位模数残差及共同参考95%区间、去中位NMAD；
- turnoff-minus-lower_MS尺度差及其配对区间；
- 完整PDF的W68/W95，原始参考中心包含率及明确的参考卷积CDF诊断；
- 原始平均边缘log score、CRPS及同源配对变化的95%区间；
- 全部分支质量、校准颜色范围外的概率质量；
- 单独的诊断中心化结果。

维持预先声明的实际尺度目标：未经评价组再平移的|median Delta mu|≤0.10 mag。分别记录尺度目标是否达到，以及相对于E和QRF的预测收益。改善证据需要结合log score、CRPS、序列尺度差和区间宽度。宽区间造成的高包含率应与其距离分辨能力一起解释；少数尾部失败保留在完整统计中。

本轮结束后在以下决定中选择，并指出直接证据：

1. 光度校准具有迁移价值：M5留出和外部系统的原始尺度/相位差改善，完整评分支持改善，宽度代价明确；若完成独立系统，单独报告其结果。
2. 主要是M5域内收益：保留适用颜色、通带和星族范围，论文据此陈述受限的经验校准。
3. 两参数假设不足：如尺度、评分、分布宽度或跨系统方向相互冲突，交付失败和具体机制线索。由此选择下一科学问题，例如额外星族信息或分支范围；本轮保持两个参数，不追加模型、散布项或逐系统调零点。

这一轮完成后应给出明确的论文科学范围建议：哪些距离应用已有真实证据，哪些星族/亮度范围由本轮实验限定，以及是否值得继续追求统一的老星族校准。运行规模本身不作为科学进展。
