# Photdis v2.6：逐星后验、目录人数与响应迁移

本轮完成Pro对39e6e4f的A–D开发与实际计算。逐星星族×距离联合概率、共享总体参数的目录人数后验已接通；原192套目录和QRF预测不变。响应对照明确指向独立模板迁移问题。扩大独立源并边缘化响应后，人数恢复改善，但不足以宣称区间已经校准。贫金属源条件校准结果随VAC来源变化，不采用统一修正，也不替换现有部署。

## 1. 输出及估计目标

- 192套×128对象，共24,576个模拟观测；测试经验SED仍只有224个独立真实源，重复观测不增加真实标定证据。全部native TYPE=PSF。
- 每星20组分联合概率（4参考星族×5日心距离节点），每套8192个共享theta的潜在人数抽样、完整20×20人数协方差。远端15/30kpc分支保留。
- `r_ij ∝ eta_j R_jb`，每次抽样共用同一theta，随后按各对象观测格抽潜在组分。人数与实际realized标签计数比较；总体比例另与设计truth比较。没有用总体比例×N代替本目录人数。
- 更大模板及响应不确定度只在reference_like、ordinary_dominated、giant_rich入口的原36套目录上做受控比较。其他156套保留原响应逐星结果；无全面组合扩跑。

已知响应及同模板独立噪声对照表现明显好于cal→test迁移。当前证据支持有限模板/组内SED迁移失配，而不是仅由原先theta积分点数或四参数族不能包含注入真值造成。它不把每个固定真参数处的Bayesian区间覆盖要求成精确95%。本轮没有以这些12次结果调阈值或选模型。

可达范围：80个设计×域×距离格真值均在当前响应/参数边界的数值范围内，范围外0个。三个组分赔率的线性分式极值约化到8角点，再对距离倾斜做一维数值极值；非形式区间证明。单格可达也不保证完整五格向量可同时恢复。

## 4. 响应不确定度与有限真实源

嵌套校准模板256→768→2048，固定身份哈希次序，均不与224测试模板或QRF拟合源重叠。已知参考类和缺标签模板均保留；最后一级含256个缺标签源，其软归属仍是经验核，不是经过校准的真实类别。每源每距离256次噪声，128次子集单独检查；这些噪声次数不能充当独立标定源数。

最大模板库用16个按独立源指数权重构建的响应，定义显式的有限经验响应先验。联合后验权重按目标观测似然的证据积分计算，允许目标数据反馈响应；不是等权平均16个已归一化后验，也不是cut后验。theta先验/四参数族/选择不变。有限响应先验并不等于完整连续Bayesian-bootstrap积分。

| 设计 | 2–5kpc设计真比例 | 响应边缘化总体均值 | 总体95%区间覆盖 |
|---|---:|---:|---:|
| reference_like | 42.07% | 40.09% | 8/12 |
| ordinary_dominated | 43.25% | 41.44% | 10/12 |
| giant_rich | 35.29% | 31.66% | 11/12 |

原2^18/2^17网格区间端点最大变化2.34个百分点；入口2–5kpc最大0.228个百分点。不能把所有补集尾端区间称为充分收敛。
响应后验ESS范围2.76–12.14（最多16）；8/16响应先验组分最大均值变化1.24个百分点，theta半网格最大0.176个百分点。响应先验离散性仍限制精确区间声明。

贫金属/other的颜色–Mg范围和每观测格响应差、逐星真实组别到后验组别的软分配矩阵均已输出。这里才允许讨论模拟对象的概率转移；不能仅靠总体比例差就宣布单颗真实恒星被误分类。增大模板、改变响应及边缘化同时发生，收益不能全部归因于其中一项。
