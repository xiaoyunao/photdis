# Photdis v3.7 目录使用说明

本说明用于 v3.5 的 DECam、低消光、$|b|>30°$ 原生 DR11 PSF
目录。取已发布主选，要求 QRF 支持且名义 SED 无数值标记。$r$ 为观测星等，
颜色为去消光 $(g-r)_0$，距离层使用目录的 QRF 中位数。区间左闭右开。W1
状态 2 表示受污染而屏蔽，状态 4 表示显著测量。

| 证据 | 可以在目录中直接执行的条件 | 建议用法 |
|---|---|---|
| 直接几何参考 | $16≤r<18$，$0.8≤(g-r)_0<1.4$，W1 为 2 或 4，中位距离 <2 kpc | 亮红近端分布。计数时保留完整 PDF，说明 Gaia 参考误差与已知区间覆盖不足。 |
| 有条件的谱距参考 | $16≤r<18$，$(g-r)_0<0.5$，W1 为 2 或 4，中位距离 2–5 kpc | 适用于和已标记谱距矮星相近的比较。两个谱距库的残差 NMAD 约 11%–12%，但 Gaia 几何匹配星约一半在 2 kpc 以内。整体分层计数需传播前景误入。 |
| 已知失效 | $18≤r<20$，$(g-r)_0<1.1$，中位距离 2–10 kpc。重点为 $0.5≤(g-r)_0<0.8$ | 参考中有大量暗蓝近邻被放至更远。用作错误分支诊断，按颜色、W1 状态及 PDF 做对照。 |
| 已知失效 | $14≤r<18$，$0.5≤(g-r)_0<0.8$，中位距离 <5 kpc | 已发现光度分支混叠和已标记矮星低估。慎用单星距离及窄距离层。 |
| 缺少适合推荐用法的直接参考 | 上述条件之外的模型支持星 | 保留 PDF 和质量标记，用于有条件的分布比较。5–10 kpc 的整体弱视差支持仍适用于该距离层的统计证据，逐星和星族校准需由相应参考判断。 |

在亮红近端条件下，四个颜色和 W1 分区合计有 746,281 颗合格 Gaia 匹配星，
其中 746,271 颗的 Gaia 参考距离也在 2 kpc 内。各分区的残差 NMAD 介于
10.7% 和 13.4% 之间，68% 区间与 Gaia 中心相符的比例约为 54%–64%。
这些数字对应能得到相应 Gaia 几何参考的对象。

执行规则见 [配置](../configs/v3_7_use_domains.json) 和
[数组接口](../scripts/v3_7_domain_rule.py)。完整材料含每个可观测分区的参考数、
按参考距离的分配和误差，以及逐个 W1 状态的统计：
[按预测距离的参考证据](../manifests/v3_7/use_domains/observable_domains.csv)。
表中的匹配参考受来源的亮度、位置、视差和光谱入选限制。底表沿用各来源的参考
质量条件，保留发布选样中的名义 SED 数值标记对象。上面的实用规则额外屏蔽这类标记。
