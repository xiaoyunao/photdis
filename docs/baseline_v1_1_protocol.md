# baseline v1.1：回退与权重实验

2026-11-03，基线97c2775；来源：[完整评审](pro_review_97c2775.md)。
本文件与configs/baseline_v1_1.json在新成绩计算前登记。使用现有14场、
原身份与空间切分。保留v0/v1全部产物，Sobol128及其未通过的分层收敛标志。
本轮终点是参照实验、风险覆盖结果和采用决定，不重做全量目录。

## 1. 同回退oracle分解

冻结六套v1模型：A/B/C及A_on_B/A_on_C/B_on_C。对各自完全相同的
cal/test参照对象，使用同一身份、同一次五波段扰动。并列wide、直接oracle、
oracle_support、oracle_full、natural、balanced。真实类别只进入oracle诊断。
oracle_support只把真实类别的域外质量转至宽模型；oracle_full再保留原始
未知标签份额u。未知真实类别仍使用宽模型，不赋予虚构类别。
支持判定沿用v1对名义颜色的判断，避免同时改变两项机制。
按真实类别、参照来源、波段报告u、支持失败、支持回退质量、最终宽质量
及距离偏差/严重错误/区间。损失用同对象差值描述，不强作可加因果百分比。

## 2. 唯一新增方案：类别和光度监督的四分支门控

部署专家继续使用冻结v1三类QRF和宽QRF。门控为固定二次颜色特征softmax，
输出三条件分支加宽残余的四个权重。宽残余是模型分量，不是第四种物理类别。
名义域外分支权重转给宽分布；未知标签份额不再直接决定这个权重。

监督证据来自训练区内部四折空间交叉拟合：留出[0,7]、[1,8]、[2,11]、[3,12]。
每折按原参数在其他训练场重建宽/条件专家，仅用于产生该折监督证据。
不使用cal/test重建专家或训练门控。每个训练场×粗类别（含未知）最多随机
抽1000颗作证据；保存身份、入选率，按逆入选率恢复原训练人群权重。
相同训练集合的波段对照共用证据身份、折分及随机数。训练标准化仅来自train。

令L_ik为训练留出星参考光度与专家k的相容密度，目标为加权平均
`-log(sum_k w_ik L_ik) - I(known_i) log(w_i,class)`，加固定0.001系数L2。
类别项系数为1，不搜索比例/正则化/模型族。已知类别的监督权重与其抽样权重
一致；未知类别利用光度项，不能丢弃。优化至固定容差/最多1000次，记录收敛。
宽模型证据必须是留出预测，禁止使用含自身标签的冻结全训练宽模型证明自身。

测光积分保持共享g：每次扰动的专家PDF按相同delta_g移至有效Mg，再与
参考距离模数误差卷积。参考Mg由观测g与距离组成，不能再独立重复加入g误差。
这是一项有噪声教师相容性目标；经验专家本身含教师散布，非标签误差去卷积。
保存原始/支持回退后的权重及证据，所有部署权重只由测光计算。
新增门控条件于名义观测颜色，拟合和评价都将其与同一套已边缘化的专家
似然组合；不在评价时改成另一种逐扰动门控。旧natural/balanced仍沿用
v1逐扰动定义，以便精确复现原对照。

## 3. 评价与采用

六套模型均报告相同训练/测试对照，Gaia、SPECDIS、SPDist分别评分；优先
Gaia、其次SPECDIS用于固定cal决定。现有test明确为发展验证。
分粗类、亮度、光学误差、WISE可用性报告中位偏差、NMAD、|delta_mu|>1、
分支误入、68/95覆盖及全宽、对数预测密度。区间针对带噪参照，不是绝对校准。

只有cal各粗类N>=30，三类宏平均严重错误至少下降2百分点，且矮星/整体
严重错误增加不超过2百分点、整体绝对残差中位数增加<=0.05mag、各类95%
覆盖下降<=2百分点、各类中位95%宽度<=旧值1.1倍、整体平均对数密度下降
<=0.02，才推荐该配置替换。无测试后调参、无因失败追加模型搜索。
保留v1波段路由作同星比较，避免把门控改进与路由变化混淆。

## 4. 预测状态与覆盖

分别保存：旧叶内已知标签份额、条件于已知标签的最大分数/熵、新四分支
分数/熵、支持造成的宽回退质量、最终宽分量、距离区间、多解与配置间分歧。
这些均不自动解释为银河真实类别概率。
固定状态由预测最大权重分支（含宽残余）、最大分数<0.5/0.5–0.8/>=0.8、
68%宽度<=0.5/0.5–1/1–2/>2mag、支持标志定义，分别报告边缘与联合表。
每组风险包含其混入的所有真实类别；无参照者不能当作正确预测。
cal样本不足30的组不作可靠性判断；test只评价既定组，不反向选择边界。

每个DECam场从唯一光学母样本均匀抽2000源（不足则全取），固定身份后
计算同星v1/新门控。按场规模加权给出母样本状态保留率及抽样不确定性，
与参照保留率并列；不得称为全部九百万行的实际新版目录计数。

## 5. 真实观测视差检查

复用已备Gaia匹配、零点和质量信息，保留可用弱/负视差，在观测空间把
预测距离分布转换为真视差并卷积逐星视差误差。固定训练外test场；按r、
WISE、颜色及观测S/N分组，后者必须使用相应截断条件的预测CDF和模拟。
若母样本/参照准入另有视差选择，明确条件化或限定检验范围，不能只处理
分组阈值而忽略准入。保存有效数、缺失与排除原因。该检验不是全部暗端验证。
模拟重用固定身份和选择规则，不据结果重训或修正距离。

执行补充（新成绩前）：Gaia按test场×观测S/N（负、0–5、5–10、10–20、
>=20）×WISE可用层，每格均匀抽最多200颗并保存入选权重。母样本仍为每场
2000颗独立均匀样本。视差PDF用每个Mg箱8点Gauss–Legendre积分，对固定
前256颗以16点复核；每颗256次相同S/N条件的混合截断模拟。分组结果按
抽样权重恢复已匹配Gaia人群；模拟未加入共享模型/Gaia系统误差，因此
仅为给定经验PDF的条件检查。风险曲线固定为最大分数>=0.5/0.8、W68
<=0.5/1/2mag且名义支持的6组组合，不以test寻找边界。

## 数值复现验收补充

实际核验发现旧oracle/natural/balanced的部分float32累加与新float64
质量转移存在舍入差，稀疏CDF附近少数分位点超过最初工程检查的3e-5mag。
24项只读对照审计：最大CDF差4.0187e-7、最大分位点差0.00041025mag，
各配置P99均小于5.97e-7mag；旧wide逐值一致。保存完整reproduction_audit。
因此复现检查改为同时限制CDF差<=1e-6、最大分位点差<=0.001mag、P99
<=1e-5mag；不是修改科学采用门槛，也不改变模型、预测或旧目录。
