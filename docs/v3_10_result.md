# Photdis v3.10 科学结果

本轮使用 v3.9 的原生测光和冻结距离 PDF，检验哪些 2–10 kpc
对象适合组成以矮星为主的工作样本。候选分类器、分支 PDF、覆盖
面积和观测选择见[运行协议](v3_10_protocol.md)。

## 同星光谱距离

对 `r<20`、三带严格测光质量及合格光谱矮星，在同一颗星上
同时读取 Photdis、SpecDis 和 SPDist。用 SpecDis 划分 5–10 kpc
时，北天有 3,429 颗，南天低纬窗有 2,675 颗。其中分别有
2,730 和 2,078 颗也落在 SPDist 的同一距离层。

| 同星对照 | 北天 | 南天低纬窗口 |
| --- | ---: | ---: |
| SPDist 相对 SpecDis 中位差 | −8.15% | −7.66% |
| Photdis 相对 SpecDis 中位差 | −5.35% | −7.65% |
| Photdis 相对 SpecDis 相对残差 NMAD | 13.98% | 14.59% |

这组参考本身带有可见的尺度差，判断测光偏差时须明确距离
标尺和入层条件。两种参考各自分箱的完整对照留在底表。

## 工作样本在 2–5 和 5–10 kpc 的表现

两个有明亮验证的扩展域共导出 **1,272,142 个工作样本候选**。
其中北天 931,707 个，南天低纬窗 340,435 个。索引中的距离仍
采用冻结 QRF 全 PDF。下表用留出天区的 SpecDis 矮星检验同一
选样前后的距离表现。

| 天区与参考距离 | 支持内 → 入选 | 中位距离偏差变化 | NMAD 变化 |
| --- | ---: | ---: | ---: |
| 北天 2–5 kpc | 19,750 → 12,143 | −3.58% → −3.52% | 10.38% → 8.40% |
| 南天低纬 2–5 kpc | 6,163 → 3,952 | −3.25% → −2.37% | 9.53% → 8.64% |
| 北天 5–10 kpc | 4,684 → 340 | −6.42% → −27.11% | 15.06% → 22.12% |
| 南天低纬 5–10 kpc | 976 → 146 | −8.31% → −14.32% | 15.10% → 18.26% |

SPDist 同样支持 2–5 kpc 的结果。降低矮星分数到 0.65 能
找回一部分 5–10 kpc 参考矮星，远端仍有系统偏差。保留整个
工作索引供复查，2–5 kpc 结果拥有更强的直接验证，5–10 kpc
仍按研究候选解释。各参考库的误差和抽样不同，这些统计只描述
对应的留出参考。

### 实际结构示范

M92 和邻近对照环带的有效三带深度面积分别为 0.330 和
2.194 平方度。先保留所有严格质量且有 QRF 预测的对象时，
目标环带在 7.5–9.5 kpc 的 PDF 加权面密度为约 949 每平方度，
控制环带约 124 每平方度。加入矮星选择和距离条件后，两值
降到约 5.60 和 6.78，预期距离附近的超额消失。未加类别选择
时的信号主要来自 `(g-r)_0<0.5`。这次真实对照揭示了选择对
蓝色星团族群的损失，工作样本在此测试里未恢复星团距离。
[M92 距离层与颜色对照](../manifests/v3_10/science/m92_distance.csv)

## 暗端错支与白矮星

固定 2,003 个南天暗端 Gaia 近源，其中 1,424 个的原生产距离
模数误差超过 1 等。1,344 个满足 Gaia 与 Legacy CMD 的低光度
筛选及 Gaia 图像质量条件。按同一 Gaia 源号与发表的白矮星表
交叉核对，找到 1,308 个高概率候选和 26 个光谱确认的白矮星，
其中 25 个发生严重测距错误。

抽查的六个高误差低光度源在 DR11 切图中均为紧凑源。另有部分
比较对象附近有邻星，其中一个大位置偏移样本靠近亮源和条纹
残留。这些对照支持低光度分支解释，同时保留个别匹配或测光
误差的可能性。暗端远矮星的光谱参数重新接回。南天 5–10 kpc
的 44 个 SpecDis 与 34 个 SPDist 矮星的中位 [Fe/H] 分别为
−1.33、−1.27，距离中位偏差约 +22%。按颜色和金属丰度分层后
样本更小，现有数据只能限定这种偏差，难以单独分离金属丰度与
训练分布迁移的贡献。

## 实际生产模型的南北接缝

核验全部 1,951,902 对已确认同源观测。529,249 对两侧都有距离
PDF，109,562 对只有北侧有，667,598 对只有南侧有，645,493 对
两侧均无。两侧都有 PDF 时，北天距离中位数相对南天低 4.40%，
配对 NMAD 7.35%。北侧 68% 区间中位宽度比南侧大约 0.078 等，
四个距离层的概率差异以总变差计平均为 0.102。分层保留星等、
颜色、接缝侧别和距离层迁移，供空间统计核对。多峰统计采用
同一原生 PDF 波峰规则。

## 三维消光

统一地图与 DECam 标度后，在原 311 个 PSF 的共同可靠区间仍有
60 个 Gaia 对照。相对同区间 SFD 的预测评分增益由 +0.597
升至 +0.723 nat，距离模数 NMAD 由 0.538 降至 0.465 等。

随后在三个实际低纬视场处理 103 个原生 PSF。26 个共同支持
Gaia 对照中，三维消光平均评分增益 −0.012 nat，NMAD 从
0.565 变为 0.608 等，各视场的变化成负、正、近零三种结果。
同等条件下的光谱覆盖和拥挤样本都很少。现证据支持保留逐视线
研究结果，使用范围仍需按视场及可靠距离区间解释。
