# Photdis 论文正文材料

Legacy Surveys 南区的测光覆盖为研究太阳近邻到内晕的恒星提供了大样本，
但不同光度分支在有限的宽波段颜色上会重叠。本文研究这些测光在什么条件下
可以给出有用的距离。目录按 DR11 south 原生 DECam PSF、高银纬、低消光、
观测 r<20 及测光支持条件构建。11,246,209 颗源有完整测光距离分布，
其中 7,672,431 颗通过原主选。有效成像面积为 6,616.12 平方度。
距离预测和选样在应用时只采用目录测光。

直接距离比较显示，测光距离与参考距离的吻合程度随距离、颜色和参考星族而变。
在主选、高质量参考且排除现 QRF 训练星的口径下，2–5 kpc 的谱距矮星
相对距离残差 NMAD 约 9%，同距离层的全类别 Gaia 几何匹配约 19%。
这些参考样本覆盖不同的星族和星等；三套参考在同一颗星上的比较可进一步
分辨参考尺度和样本组成的作用。图 2 直接显示参考距离、测光距离及残差，
图 3 将相同对象的两个绝对 CMD 并列，保留光度分支错置的证据。

按 QRF 中位距离分层的逐星天图展示足迹内的实际源位置。在距离中位数 0–10 kpc
内，支持目录有 10,656,011 颗星。近端主要覆盖相对低光度星，远端受到
星等限制，更多集中在较亮主序和转折附近。图 4 和图 5 用于显示样本分布，
其中起伏也受成像覆盖、星等、测距和星族选样影响。

对参考距离为 5–10 kpc 的矮星，降低矮星评分门槛并保留近端概率门槛，
在 SpecDis 和 SPDist 分别多找回 4,132 和 1,937 颗对象。
测光距离模型在此比较中固定。入选样本距离偏差减小的同时，
近邻、远端巨星和 Redrock 标记的非恒星对象误入增加。按预测的 5–10 kpc 分层，带符号 Gaia 弱视差
提供了额外总体检验。与宽距离基线的比较使用相同的弱视差入选条件，
并保留负视差。

解释距离层计数时，按中位距离选出的对象列表有可定义的混入比例。
对完整 QRF PDF 加总则报告各距离层期望计数。把 SED 对前景的预测按
QRF 给定的远层概率加权，可描述两模型的分配差异。把该加权量从 PDF
加总计数中再减一次会重复计算距离不确定性。
