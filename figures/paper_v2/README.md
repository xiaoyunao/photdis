# Photdis scientific figures, v2

All eight science plates use the shared Pal 5 / v3.8 style. Each PDF has a
matching 300 dpi PNG. The two-column layout is the reference width.
The [physical-width preview](aas_width_preview.png) shows a 7.1 in and
3.5 in rendering of every PDF at 120 ppi. Use two columns for the paired
sky maps, multi-panel distances, trends, CMD and migration plots. Small
axis and colorbar labels become difficult to read at one column.
